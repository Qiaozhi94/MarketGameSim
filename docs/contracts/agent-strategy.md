# 代理策略合同：从信息集到订单意图

**适用范围**：跨规格实现合同（当前交付规格 002）  
**状态**：Stable（变更须记 ADR 并评估既有实验可比性）  
**创建日期**：2026-08-01  
**支撑需求**：002 / FR-009—FR-013；PRD / PR-008—PR-011  
**关联**：[事件 Schema](event-schema.md)、[退化状态](degenerate-states.md)、
[指标字典](../product/metrics-dictionary.md)

## 0. 本文为什么必须存在

002 规格定义了因子库与加权信号（P-1），但没有定义**信号如何变成订单**。这中间的
每一个选择——因子如何标准化、历史不足时取什么值、信号如何映射到方向与数量、挂单
挂在哪个价位、旧单撤不撤——都会直接决定厚尾、波动聚集、因子收益与崩盘频率。

**不把它们定死，实验结论就只是实现者选择的结果。** 本文把整条管线写成确定函数：

```text
information_set
  → raw factors          §2
  → normalized factors   §3
  → belief signal        §4
  → target position      §5
  → order intents        §6
  → admission            §7
```

同一信息集 + 同一 RNG 状态**必然**产生同一组订单意图。任何实现自由度都是缺陷。

## 1. 信息集边界

`AGENT_OBSERVE` 事件确定该代理本次可见的内容（事件 Schema §4.4），**只含**：

| 内容 | 说明 |
|---|---|
| 盘口 | `best_bid`、`best_ask`、买卖各 k 档深度（`k = 10 tick`） |
| 最近成交 | 价、量、主动方向 |
| **已完成**的 K 线序列 | 只到上一根完整 K 线（`bar_ns = 60 秒`，指标字典 §1.9） |
| 自身账户 | 现金、持仓、冻结、保证金占用、担保比例、未成交挂单 |

**当前尚未收盘的 K 线不可见。** 若允许代理读取进行中的 K 线，它就能看到本根内已发生
的价格变动并抢先反应——这是前视偏差，会凭空制造动量效应，而动量恰好是被检验的因子
之一（002 / P-1）。

代理**不可见**：其他代理的身份、持仓、信念权重、未来订单流（订单流预知者后移至
M4），以及全局撮合中间态（A-002）。

## 2. 原始因子

全部在**已完成 K 线**与当前盘口上计算。记 `C[-1]` 为最近一根完整 K 线的收盘价。

| 因子 | 公式 | 所需历史 |
|---|---|---|
| `momentum` | `ln(C[-1] / C[-1-N])` | N+1 根 K 线 |
| `reversion` | `(anchor − last) / last` | 无（锚随成交更新） |
| `herding` | `(主动买量 − 主动卖量) / 总成交量`，最近 W 根 K 线 | W 根 K 线 |
| `book` | `(bid_depth_k − ask_depth_k) / (bid_depth_k + ask_depth_k)` | 无 |
| `noise` | 每次决策独立抽取的标准正态 | 无 |

`anchor` 为该代理自己的内生 EWMA：每笔**可见成交**按
`anchor ← α·price + (1−α)·anchor` 更新，`α = 1 − 2^(−1/τ)`，τ 以成交笔数计
（指标字典 §1.5）。锚是**逐代理**状态，半衰期各异，不是全局量。

## 3. 缺失值与冷启动

### 3.1 缺失一律取 0，不取 NaN、不跳过

| 情形 | 取值 |
|---|---|
| K 线不足 `N+1` 根 | `momentum = 0` |
| K 线不足 `W` 根 | `herding = 0` |
| 窗口内总成交量为 0 | `herding = 0` |
| 尚无成交（`last` 未定义） | `reversion = 0`，且 `anchor` 保持初值 `initial_price` |
| 两侧簿皆空 | `book = 0` |
| **单边簿**（一侧深度为 0） | `book = ±1`（满偏），**不是缺失** |

取 0 表示「该因子此刻无信号」，代理不因它下单；取 NaN 会污染加权求和，跳过则会
悄悄改变权重归一化的分母，使同一 `w` 在不同时刻含义不同。

单边簿给满偏是刻意的：一侧无挂单是**极端失衡的真实信息**，不是数据缺失。这也让
`book` 因子在流动性枯竭时给出最强信号，与退化状态 §1.2 的语义一致。

### 3.2 冷启动期

`anchor` 初值为配置的 `initial_price`；订单簿初始为空。

**冷启动期内代理照常下单**，缺失因子按 §3.1 取 0。此时唯一有信号的通常是 `noise`
与 `book`——市场由噪声驱动启动。若要求所有代理等到历史齐备再下单，则永远不会有第一
笔成交（无成交 → 无 K 线 → 永远等待）。

冷启动期定义为**前 `max(N_max + 1, W_max)` 根 K 线**（当前配置为 61 根 = 61 分钟
逻辑时间）。该期间的数据**必须从统计检验中剔除**，作为 burn-in 记入运行元数据。
不剔除会把「因子尚未生效时的噪声市场」混入结论。

## 4. 标准化与信念信号

### 4.1 固定尺度截断，不用滚动标准化

各因子量纲不同（`momentum` 是对数收益，`book` 已在 `[−1,1]`），必须先归一：

```text
normalized_i = clip(raw_i / scale_i, −1, +1)
```

| 因子 | `scale` | 依据 |
|---|---|---|
| `momentum` | `"0.01"` | 1% 对数收益视为满信号 |
| `reversion` | `"0.02"` | 2% 偏离视为满信号 |
| `herding` | `"1.0"` | 原始值已在 `[−1,1]` |
| `book` | `"1.0"` | 同上 |
| `noise` | `"1.0"` | 标准正态截断至 `±1` |

**明确排除滚动 z-score 标准化。** 两条理由：一是它需要滚动窗口的均值与标准差，引入
额外的历史依赖与冷启动问题；二是**崩盘时标准差爆炸会把信号压缩到接近 0**——恰好在
最需要反应的时刻使所有代理失灵，这会人为地抑制杠杆连锁，而连锁正是旗舰问题的研究
对象。固定尺度虽然粗糙，但行为可预测，且不随市场状态自适应。

### 4.2 信念信号

```text
signal = Σ wᵢ · normalizedᵢ        权重满足 Σ|wᵢ| = 1，故 signal ∈ [−1, +1]
```

`w` 在运行开始时从 Dirichlet 分布抽取后**固定不变**（002 / D-3、FR-009）。抽取后
按 `Σ|wᵢ| = 1` 归一化。

## 5. 目标仓位

信号解释为**目标仓位占最大可承受仓位的比例**：

```text
max_position = floor(equity × leverage_cap / mark)      单位：min_quantity 整数
target_position = round(signal × max_position)
```

- `leverage_cap` 为该代理抽到的杠杆档位（1x / 3x / 10x）；
- `signal = +1` → 满多头，`−1` → 满空头，`0` → 空仓；
- `equity` 与 `mark` 取本次观察时刻的值；`mark` 未定义时（无成交且单边簿）**跳过本次
  决策**，不下单。

这一步是整条管线中经济含义最强的一处：它使**杠杆档位直接放大信号的仓位后果**，
从而让「初始杠杆分布是否足以产生连锁」成为可测量的问题（旗舰问题）。

## 6. 订单意图

```text
delta = target_position − current_position
```

- `|delta| < min_quantity` → **不下单**（避免无意义的碎单）；
- `delta > 0` → 买入 `delta`；`delta < 0` → 卖出 `|delta|`；
- 单笔数量上限 `max_order_qty`，超出则**只下上限那一笔**，剩余部分留待下次决策——
  不自动拆单（拆单是大资金执行者的能力，后移至 M4）。

### 6.1 挂单价格与激进度

一律使用**限价单**。价格由逐代理抽取的 `aggressiveness ∈ [0, 1]` 决定：

```text
买单价 = best_bid + aggressiveness × (best_ask − best_bid)
卖单价 = best_ask − aggressiveness × (best_ask − best_bid)
```

- `aggressiveness = 0` → 挂在同侧最优价，**必为 maker**；
- `aggressiveness = 1` → 挂到对侧最优价，**立即成交，必为 taker**；
- 中间值 → 挂在价差内部，改善盘口。

**maker / taker 的分化由此自然产生**，不需要单独的「代理类型」。这也使 maker 返佣与
taker 费率的不对称（ADR-005 §3）能真实影响不同代理的收益。

`aggressiveness` 在运行开始时抽取并固定，它是代理的**执行能力维度**（A-003）。

盘口不可用时的退化：
- 单边簿——缺失一侧用 `last ± spread_fallback`（配置项）替代；
- 两侧皆空——跳过本次决策，不下单。

### 6.2 撤单：全撤重报

**每次决策先撤销自己全部未成交挂单，再按上述规则重新下单。**

理由是确定性与无状态：保留旧单需要判断「旧单是否仍然有效」，而该判断本身又是一组
自由度（价格偏离多少算失效？挂了多久算过期？）。全撤重报没有这些自由度。

代价是撤单率偏高，且每次决策都产生撤单事件。这一点已知并接受：撤单率是被观测的指标
（指标字典 §3.3），报告须声明它受本规则影响，**不得解读为代理的策略特征**。

## 7. 准入与对齐

订单在提交前按顺序检查，**任一不通过即丢弃该意图，不重试、不降级**：

1. **tick 对齐**：买单价格向下取整、卖单价格向上取整至 tick 整数倍——朝**不利于自己
   成交**的方向取整，避免取整意外制造更激进的报价；
2. **数量对齐**：向下取整至 `min_quantity` 整数倍；取整后为 0 则丢弃；
3. **保证金检查**：按 002 / P-2 计算下单后的担保比例，低于 `maintenance_ratio` 则
   拒绝（不允许主动开到立刻被强平的仓位）；
4. **预冻结**：按 ADR-005 §4 冻结名义金额与手续费上界。

被拒绝的意图仍写入 `ORDER_ARRIVAL` 事件（`accepted = false` 与 `reject_reason`），
因为「代理想做什么」与「交易所允许什么」的差异本身是研究数据。

## 8. 做市商：唯一的例外

库存型做市商**不使用信念信号**（§2—§6 不适用），行为独立定义：

```text
skew  = inventory_skew_k × (current_position / max_inventory)     ∈ [−1, 1]
bid   = mid − half_spread − skew × half_spread
ask   = mid + half_spread − skew × half_spread
```

- 双边各挂 `quote_size`，每次决策全撤重报（§6.2 同样适用）；
- `skew > 0`（持仓偏多）时整体报价下移，**更容易被买走、更难买入**，从而回归中性；
- 库存达 `max_inventory` 时停止该方向的报价；
- 担保比例低于维持线时停止双边报价，只挂减仓方向。

**与信念代理共享**：§1 信息集边界、§6.2 撤单规则、§7 准入与对齐、保证金与强平。
**不共享**：因子、信号、目标仓位映射。

做市商是市场里唯一的持续流动性提供者，其参数（`half_spread`、`max_inventory`、
`inventory_skew_k`）直接决定簿的厚度，因而**必须作为杠杆连锁实验的敏感性维度**——
做市商越薄，同样的强平量造成的价格滑落越深（002 / A-005）。

## 9. 确定性要求

所有随机抽取必须使用 KR-004 的语义键派生：

```text
(master_seed, agent_id, mechanism, decision_index, draw_index)
```

`mechanism` 取值至少包括：`belief_weights`、`half_life`、`aggressiveness`、
`leverage_tier`、`momentum_lookback`、`herding_window`（以上为**建仓期一次性抽取**），
以及 `noise_factor`（**每次决策抽取**）。

按语义键而非调用顺序派生，使配对对照中「同一代理在同一决策序号上的噪声」保持一致，
即使两组的行为已经分叉（002 / KR-004）。这是配对实验效力的前提。

## 10. 本合同的已知局限

以下几点是**刻意的简化**，不是遗漏。它们都会影响结论，因此必须在报告中声明：

| 简化 | 影响 | 何时重新评估 |
|---|---|---|
| 固定尺度而非自适应标准化 | 极端行情下信号饱和，代理反应「钝化」 | M3 稳健性检验 |
| 全撤重报 | 撤单率偏高，簿的瞬时深度波动被放大 | 若撤单率显著影响深度指标 |
| 目标仓位线性映射信号 | 排除了阈值型、金字塔加仓等真实行为 | M3 替代行为映射 |
| 不自动拆单 | 大额调仓一次性冲击簿 | 大资金执行者引入时（M4） |
| 融资利息为 0 | 长时间持仓无成本 | 实验时长显著延长时 |

**M3 的稳健性检验必须至少替换其中一项**（PRD §15），以确认旗舰结论不依赖单一行为
映射——报告已指出，只在单一映射下成立的结论是实现的性质，不是市场的性质。
