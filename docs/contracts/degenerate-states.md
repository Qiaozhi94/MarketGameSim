# 退化状态行为定义

**适用范围**：跨规格实现合同（当前交付规格 001）  
**状态**：Stable（跨规格实现合同；变更须记 ADR 并提升 `schema_version`）  
**创建日期**：2026-07-29  
**支撑需求**：001 / FR-007、FR-018、SC-005；PRD / KPI-005  
**关联**：[001 规格](../../specs/001-belief-testing-laboratory/spec.md)、[指标字典](../product/metrics-dictionary.md)

## 0. 原则

加密式制度（001 / D-1）不引入涨跌停或熔断，允许崩盘、暴涨与流动性枯竭自由涌现。

**「允许极端」不等于「未定义」。** 本文为每种退化状态指定确定行为，使仿真产出**有
研究价值的极端样本**，而不是未定义状态、异常终止或静默的错误状态。

「未定义的量」（如单边簿下的 `mid`）与「未定义的状态」是两回事：前者是合法且必须
被记录的观测结果，在日志中以 `null` 表达、在分析层才成为 NaN
（[ADR-001](../adr/001-numeric-and-serialization-contract.md) §6）；后者是
本文要消除的对象。

## 1. 订单簿退化

### 1.1 空订单簿上的市价单

**市价单按 IOC（Immediate-Or-Cancel）语义处理**：能成交多少成交多少，剩余数量立即
撤销并记录。对手侧完全为空时，等价于全额撤销。

不采用「转为限价挂单」——那会静默改变订单类型语义，使代理的实际行为与其声明策略
不符，破坏行为归因。

撤销的剩余数量记入 `unfilled_market_quantity` 统计量，作为流动性枯竭的观测指标。

### 1.2 单边订单簿

一侧无挂单时：

- `mid` 与点差**未定义**：日志写 `null`，分析层读取后映射为 NaN（指标字典 §3.1、
  ADR-001 §6），不得以 0 或前值填充；
- 该状态持续时长计入 **`one_sided_book_ratio`**（单边簿时间占比）；
- 未实现 PnL 的标记价按指标字典 §3.1 退化为 `last`。

## 2. 价格边界

### 2.1 下界

**价格下界为 1 tick，不允许 0 或负值。**

价格为 0 会使对数收益成为 `-inf`，污染全部统计检验。触及 1 tick 的运行**标记为
崩盘发散样本**并继续运行至结束（不提前终止），以便观察触底后的行为。

### 2.2 上界

**不设硬性价格上限**，但设发散判定阈值（§4）。上行发散通过阈值识别，而非通过限价
截断——截断会改变动力学本身。

## 3. 代理退化

### 3.1 破产

代理的可用现金与可用持仓均不足以支撑任何合法新订单时，标记为 **`INACTIVE`**：

- **不从仿真中移除**。已挂在簿上的订单继续有效，直至成交或被撤销；
- 不再产生新的订单意图；
- 账户快照继续记录，其最终状态可观察；
- 状态转换事件写入日志，破产时刻可追溯。

不移除代理的理由：移除会改变市场参与者构成，构成一个未声明的处理变量，污染对照
实验的内部有效性（methodology §9.2）。分流 RNG（KR-004）保证保留 INACTIVE 代理
不会扰动其他代理的随机流。

INACTIVE 代理数量与占比须随报告输出。

### 3.2 钱包可短暂为负，随即核销

永续账户模型下**不存在「现金」**，只有钱包余额与合约仓位
（[账户与保证金合同](margin-and-account.md)）。杠杆的本质是「名义价值 > 钱包」，
不是负现金。

`wallet_units` 在**穿仓瞬间可以为负**（强平成交后已实现亏损超过钱包），随即由核销
两步分录归零（账户合同 §5.1）。这不违反守恒——负钱包也是钱包，C1 在核销前后都成立。

**挂单占用保证金，不占用名义金额。** 冻结额 = 初始保证金 + 手续费上界（账户合同
§3.3），远小于名义金额——这正是杠杆可行的原因。ADR-001 §4 的「冻结全额名义金额」
是现货语义，已被本合同取代。

### 3.3 卖空

**永续合约天然支持做空，与做多完全对称**：`position_units` 为负即空头，保证金计算
用 `|position|`（账户合同 §3.2），无需融券、券源或借贷。

这是选择永续的收益之一。禁止卖空会使下跌只能由多头平仓驱动，杠杆连锁的动力学被
人为削弱。

### 3.4 穿仓与强平失败

| 情形 | 行为 |
|---|---|
| 保证金率恰好等于维持线 | **不触发**强平（闭区间安全侧）；低于才触发，与 §5「边界值本身合法」一致 |
| 强平单部分成交 | 剩余数量在下一事件继续尝试，**不放弃、不转限价**；每次尝试重新判定 |
| 强平单无对手方 | 按 §1.1 的 IOC 语义全额撤销，账户保持 `PENDING_LIQUIDATION`，下一事件重试 |
| 权益跌破 0（穿仓） | 账户转入 `LIQUIDATED`，负权益记入交易所风险账户，守恒等式仍精确成立 |
| `LIQUIDATED` 账户 | 不再产生任何订单意图；已挂订单**全部撤销**（与 §3.1 的 INACTIVE 不同——INACTIVE 只是无力新开仓，挂单仍是其真实意愿；穿仓账户已无偿付能力，其挂单若成交会进一步扩大风险账户损失） |

**穿仓不提前终止运行**，与发散样本同理：它是有研究价值的极端结果，须完整保存并计入
排除率统计（§4）。

### 3.5 强平重试的调度语义

强平单部分成交或无对手方时须重试。重试**不是自发的**，必须有明确的调度来源：

| 规则 | 内容 |
|---|---|
| 谁创建重试 | **不创建独立的重试事件**。待强平账户在**每次 `mark` 变化后**被重新评估 |
| `mark` 何时变化 | 只有 `TRADE_SETTLE` 能改变 `mark`（代理策略 §3.3），因此重试由市场上的**任何一笔成交**驱动 |
| 时间如何前进 | 由后续成交事件自然推进，不引入人工时间步 |
| 无其他成交时 | 账户**保持 `PENDING_LIQUIDATION` 并停留**。**这是刻意的实验制度**：新限价挂单进入订单簿但未成交时，不触发重试——挂单不改变风险 mark（代理策略 §3.3），因此「有新流动性」这一信息在本模型中不可观测。该选择须在报告中声明 |
| 公平性 | 强平单与普通订单在同一 `ORDER_ARRIVAL` 队列中按全序键排队，**不享有优先权**，不会饿死普通代理事件 |
| 自然终止 | 保证金率恢复至 `target_bp` 以上，或仓位归零（含穿仓核销） |

**「无成交则停留」需要一条防线**：若市场彻底无成交且存在待强平账户，运行会陷入
无进展状态。该情形由 EV-3（连续无成交时长 > `T_idle`）捕获并终止运行，标记为
流动性枯竭的经济终点。

由此**不需要 `LIQUIDATION_RETRY` 事件类别**，`priority_class` 冻结清单不变。

### 3.6 连环强平

一次强平成交推动价格，可能使其他账户跌破维持线，从而触发下一轮。**该连锁不得被
限速或打断**（001 / D-2）——限速是研究者注入的隐藏变量，且恰好抑制了要观察的现象。

必须定义的终止条件：连锁在**没有新账户跌破维持线**时自然结束。若出现全市场账户
连续强平至订单簿单边清空，该运行标记为 **EV-4 杠杆连锁崩溃**（§4.1）——它是**有效
结果**，进入终点部分统计，不排除。

`chain_depth` 逐层累计并随每次判定记录（事件 Schema §4.2.2），是 US-4 测量连锁规模的
唯一依据。


## 4. 样本分类：技术无效 vs 经济终点

### 4.0 两类终止必须分开（方向重置后的关键修正）

原判据把价格触底、大幅偏离与连环强平一律标记为「无效样本」并排除出统计——那是
**旧方向**的口径：当时研究价格形成，崩盘是干扰项。

新方向的旗舰问题就是**崩盘本身**（杠杆连锁能否自发产生自我强化的下跌）。继续排除
它们，等于把研究对象扔掉，并使推断条件化于「市场幸存」，**系统性低估尾部风险**。

因此把终止分为两类，处置完全不同：

| 类别 | 含义 | 处置 |
|---|---|---|
| **技术无效** | 实现异常、日志损坏、引用完整性失败、未定义领域状态、确定性哈希不一致 | **排除**，并作为缺陷报告；排除率是工程指标 |
| **经济终点** | 崩盘、穿仓、连环强平、流动性枯竭、价格触界 | **有效结果**，不排除；它们是被研究的现象 |

含经济终点的运行**按两部分报告**（PRD §12）：

1. **终点部分**：经济终点的发生概率、发生时刻分布、严重度（跌幅、强平账户数、
   连锁深度）；
2. **条件部分**：条件于「未发生终点」的连续市场指标（厚尾、波动聚集、点差、深度）。

只报第二部分等于只统计幸存者。两部分都必须出现在验证报告中。

### 4.1 经济终点判据（实验开始前声明，不得事后调整）

满足以下**任一**条件，该运行标记为**经济终点样本**（有效，不排除）：

| 编号 | 条件 | 对应失效形态 |
|---|---|---|
| EV-1 | 价格触及下界 1 tick | 崩盘至下界 |
| EV-2 | `\|ln(P_t / P_0)\| > K` | 大幅单向偏离 |
| EV-3 | 连续无成交时长 > T_idle | 锁定 / 流动性枯竭 |
| EV-4 | 连环强平致订单簿单边清空，且无新增挂单 | 杠杆连锁崩溃（§3.5） |

**技术无效判据**（排除）：

| 编号 | 条件 |
|---|---|
| TI-1 | 引用完整性检查失败（001 / SC-006） |
| TI-2 | 相同种子重跑的事件摘要哈希不一致（001 / SC-002） |
| TI-3 | 守恒等式 C1 / C2 在任一事件后不成立（指标字典 §5） |
| TI-4 | 领域层出现未定义状态或内核异常终止 |

- **K = ln(10) ≈ 2.303**（DS-001）。即价格涨破 10 倍或跌破初值的 1/10 即判定发散。
  取 10 倍而非 100 倍：EV-2 要识别的是**失控**而非「幅度大但有界」，一个工作正常的
  模型不应出现 10 倍级别的单向漂移。**该值须由数据校准**——M2 须报告各参数点
  `max|ln(P_t/P_0)|` 的分布，若大量外观正常的样本贴近阈值，说明 K 偏紧，应调整并
  重新预注册。
- **T_idle = 运行总时长的 5%**（DS-002）。采用相对量而非绝对秒数，使判据在不同运行
  长度下保持一致含义。

EV-1—EV-3 对应 001 / D-4 的三种内生锚失效形态；EV-4 是杠杆连锁特有的终点，
不属于自指失效（§3.5）。

**注意**：内生锚失效（锚的参数选得不好）与杠杆连锁崩溃（研究对象）在外观上都表现为
价格崩塌，但成因不同。区分依据是强平成交量占比与 `chain_depth`——前者接近 0、后者
为 0 时，崩塌来自锚失效而非杠杆连锁。该区分必须在报告中给出，否则旗舰问题的结论
可能建立在参数产物上。
周期振荡不在此判定——它产生的是有效但含人造周期的样本，由收益自相关检验识别
（指标字典 §6）。

### 4.2 报告要求

- **经济终点发生率与技术无效率必须分别随每份验证报告输出**；
- 经济终点发生率本身是一项结果，反映该参数配置的脆弱性，不得作为「数据清洗」略去；
- 有效样本量下降时须相应提高种子数量以维持统计功效；
- **事后调整判定标准以获得更好的统计结果，等同于选择性报告**（methodology §9.3）。

### 4.3 样本处置

两类样本**都运行至结束并完整保存**。

- **经济终点样本**：进入终点部分统计（§4.0），并从条件部分的连续指标中剔除——
  剔除的是**指标计算**，不是样本本身，两者都要报告；
- **技术无效样本**：不进入任何统计，作为缺陷线索归档。

## 5. 其他边界情况

| 情形 | 行为 |
|---|---|
| 同价不同到达时间的订单 | 按到达事务的 `transaction_seq` 定序（KR-003） |
| 部分成交后撤销剩余 | 允许，撤销事件记录剩余数量 |
| 资金/持仓恰在约束边界 | 边界值本身合法（闭区间），超出一个最小单位即拒绝 |
| 撤销不存在或已成交的订单 | 拒绝并记录 `reject_reason`，不视为错误 |
| 数量为 0 或负的订单 | 准入校验阶段拒绝 |
| 价格非 tick 整数倍 | 准入校验阶段拒绝，不静默取整 |

「不静默取整」与「不静默转换订单类型」出于同一理由：任何静默修正都会使代理的实际
行为偏离其声明策略，让行为归因失效。

## 6. 参数取值

| 编号 | 参数 | 取值 | 说明 |
|---|---|---|---|
| DS-001 | K（对数偏离阈值） | `ln(10) ≈ 2.303` | 见 §4.1，须由 M2 数据校准 |
| DS-002 | T_idle | 运行总时长的 5% | 相对量，跨运行长度含义一致 |
| DS-003 | INACTIVE 代理的存量订单 | **不自动撤销**，保留至成交或运行结束 | 见下 |

**DS-003 的理由**：自动撤销是一条额外规则，会改变簿上流动性，构成未声明的处理变量
——与 §3.1 不移除破产代理是同一考虑。若 M2 观察到陈旧挂单显著扭曲深度指标，再作为
独立配置项引入并记录。

K 的校准要求已写入 M2 的基准市场验证协议（待制定）的输出清单。
