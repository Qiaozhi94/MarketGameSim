# 退化状态行为定义

**适用范围**：跨规格实现合同（当前交付规格 002）  
**状态**：Stable（跨规格实现合同；变更须记 ADR 并提升 `schema_version`）  
**创建日期**：2026-07-29  
**对应任务**：T000e、T007b　**支撑需求**：FR-012、SC-005、KPI-008  
**关联**：[ADR-009](../adr/009-agent-belief-space.md)、[指标字典](../product/metrics-dictionary.md)

## 0. 原则

ADR-007 的加密式制度不引入涨跌停或熔断，允许崩盘、暴涨与流动性枯竭自由涌现。

**「允许极端」不等于「未定义」。** 本文为每种退化状态指定确定行为，使仿真产出**有
研究价值的极端样本**，而不是未定义状态、异常终止或静默的错误状态。

「未定义的量」（如单边簿下的 `mid`）与「未定义的状态」是两回事：前者是合法且必须
被记录的观测结果，在日志中以 `null` 表达、在分析层才成为 NaN
（[ADR-005](../adr/005-numeric-and-serialization-contract.md) §6）；后者是
本文要消除的对象。

## 1. 订单簿退化

### 1.1 空订单簿上的市价单

**市价单按 IOC（Immediate-Or-Cancel）语义处理**：能成交多少成交多少，剩余数量立即
撤销并记录。对手侧完全为空时，等价于全额撤销。

不采用「转为限价挂单」——那会静默改变订单类型语义，使代理的实际行为与其声明策略
不符，破坏行为归因。

撤销的剩余数量记入 `unfilled_market_quantity` 统计量，作为流动性枯竭的观测指标。

### 1.2 单边订单簿

一侧无挂单时：

- `mid` 与点差**未定义**：日志写 `null`，分析层读取后映射为 NaN（指标字典 §3.1、
  ADR-005 §6），不得以 0 或前值填充；
- 该状态持续时长计入 **`one_sided_book_ratio`**（单边簿时间占比）；
- 未实现 PnL 的标记价按指标字典 §3.1 退化为 `last`。

## 2. 价格边界

### 2.1 下界

**价格下界为 1 tick，不允许 0 或负值。**

价格为 0 会使对数收益成为 `-inf`，污染全部统计检验。触及 1 tick 的运行**标记为
崩盘发散样本**并继续运行至结束（不提前终止），以便观察触底后的行为。

### 2.2 上界

**不设硬性价格上限**，但设发散判定阈值（§4）。上行发散通过阈值识别，而非通过限价
截断——截断会改变动力学本身。

## 3. 代理退化

### 3.1 破产

代理的可用现金与可用持仓均不足以支撑任何合法新订单时，标记为 **`INACTIVE`**：

- **不从仿真中移除**。已挂在簿上的订单继续有效，直至成交或被撤销；
- 不再产生新的订单意图；
- 账户快照继续记录，其最终状态可观察；
- 状态转换事件写入日志，破产时刻可追溯。

不移除代理的理由：移除会改变市场参与者构成，构成一个未声明的处理变量，污染对照
实验的内部有效性（methodology §9.2）。分流 RNG（KR-004）保证保留 INACTIVE 代理
不会扰动其他代理的随机流。

INACTIVE 代理数量与占比须随报告输出。

### 3.2 现金不得为负

FR-003 禁止超出可用现金的订单。**手续费必须在下单时预冻结**——否则 taker 单成交
后扣费可能使现金为负，破坏指标字典 §5 的守恒等式。

冻结额 = 订单名义金额 + 按 `max(taker_bps, maker_bps, 0)` 上取整计算的最大可能
手续费（ADR-005 §4）。实际成交为 maker 时，多冻结部分在结算时释放。费率为负时费用
项按 0 计——预冻结是上界估计，不得因预期返佣而少冻结。

### 3.3 卖空

MVP **不允许卖空**：卖单数量不得超过可用持仓。若后续实验需要卖空，须作为独立配置
项引入并重新评估守恒等式。

## 4. 发散与无效样本判定

### 4.1 判定标准（实验开始前声明，不得事后调整）

满足以下**任一**条件，该运行标记为无效样本：

| 编号 | 条件 | 对应失效形态 |
|---|---|---|
| DV-1 | 价格触及下界 1 tick | 下行发散（崩盘） |
| DV-2 | `\|ln(P_t / P_0)\| > K` | 上行或下行发散 |
| DV-3 | 连续无成交时长 > T_idle | 锁定 / 流动性枯竭 |

- **K = ln(10) ≈ 2.303**（G-001）。即价格涨破 10 倍或跌破初值的 1/10 即判定发散。
  取 10 倍而非 100 倍：DV-2 要识别的是**失控**而非「幅度大但有界」，一个工作正常的
  模型不应出现 10 倍级别的单向漂移。**该值须由数据校准**——M2 须报告各参数点
  `max|ln(P_t/P_0)|` 的分布，若大量外观正常的样本贴近阈值，说明 K 偏紧，应调整并
  重新预注册。
- **T_idle = 运行总时长的 5%**（G-002）。采用相对量而非绝对秒数，使判据在不同运行
  长度下保持一致含义。

三条判据恰好对应 ADR-009 §2 的三种失效形态：DV-1/DV-2 识别发散，DV-3 识别锁定。
周期振荡不在此判定——它产生的是有效但含人造周期的样本，由收益自相关检验识别
（指标字典 §6）。

### 4.2 报告要求

- **排除率必须随每份验证报告输出**，按 DV-1/DV-2/DV-3 分别统计；
- 排除率本身是一项结果，反映该参数配置的稳定性，不得作为「数据清洗」略去；
- 有效样本量下降时须相应提高种子数量以维持统计功效；
- **事后调整判定标准以获得更好的统计结果，等同于选择性报告**（methodology §9.3）。

### 4.3 无效样本的处置

无效样本**运行至结束并完整保存**，仅在统计特征检验中排除。其事件日志用于诊断失效
形态，是参数扫描失效区标注的原始依据。

## 5. 其他边界情况

| 情形 | 行为 |
|---|---|
| 同价不同到达时间的订单 | 按 `seq` 定序（KR-003） |
| 部分成交后撤销剩余 | 允许，撤销事件记录剩余数量 |
| 资金/持仓恰在约束边界 | 边界值本身合法（闭区间），超出一个最小单位即拒绝 |
| 撤销不存在或已成交的订单 | 拒绝并记录 `reject_reason`，不视为错误 |
| 数量为 0 或负的订单 | 准入校验阶段拒绝 |
| 价格非 tick 整数倍 | 准入校验阶段拒绝，不静默取整 |

「不静默取整」与「不静默转换订单类型」出于同一理由：任何静默修正都会使代理的实际
行为偏离其声明策略，让行为归因失效。

## 6. 参数取值

| 编号 | 参数 | 取值 | 说明 |
|---|---|---|---|
| G-001 | K（对数偏离阈值） | `ln(10) ≈ 2.303` | 见 §4.1，须由 M2 数据校准 |
| G-002 | T_idle | 运行总时长的 5% | 相对量，跨运行长度含义一致 |
| G-003 | INACTIVE 代理的存量订单 | **不自动撤销**，保留至成交或运行结束 | 见下 |

**G-003 的理由**：自动撤销是一条额外规则，会改变簿上流动性，构成未声明的处理变量
——与 §3.1 不移除破产代理是同一考虑。若 M2 观察到陈旧挂单显著扭曲深度指标，再作为
独立配置项引入并记录。

K 的校准要求已写入 M2 的基准市场验证协议（待制定）的输出清单。
