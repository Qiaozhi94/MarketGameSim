# 外生价格锚：候选形态与取舍（草稿，待 owner 裁决）

状态：**草稿**，2026-09-24。不是决策，不构成任何实现承诺；裁决后应转为 ADR。
触发来源：0.4.1 的 E3/E4 被「市场在统计窗口打开前停止成交」阻塞，根因是装配里
**没有任何一方的供给随价格上涨而增加**（[实验报告 §8](../experiments/0.4.1-market-quality-baseline.md)）。

## 1. 问题陈述

当前四个策略族的价格参照**全部内生**：

| 族 | 参照 | 信息层 |
|---|---|---|
| `trend_following` | 过去 3/12～10/60 根 K 线 | I2 |
| `mean_reversion` | 过去 12 根 K 线收盘均值 | I2 |
| `market_maker_v2` | 最新盘口中价 | I0 |
| `sentiment_noise` | 无参照（keyed 随机情绪） | I0 |

内生参照会随价格一起漂移，所以价格涨到 66688 时**没有任何一方认为这个价错了**。
2026-09-24 的修复把稳定力的记忆从约 10 秒拉到约 8 分钟，停摆点从 ~3300 秒推到
~4000 秒，但参照系仍是内生的——价格走多远它就跟到多远，因此只延寿不治本。

**已排除的两个竞争解释**（2026-09-24 实测，见
[实验报告 §10、§12](../experiments/0.4.1-market-quality-baseline.md)）：

| 竞争解释 | 如何排除 |
|---|---|
| 稳定力的**记忆太短** | 参照从「增量成交带 20 笔」改为「12 根 K 线均值」后，价格仍单调涨 6.7 倍 |
| 稳定力的**规模不足** | 逆势方数量翻倍（9/9 → 6/12、4/14）、成交量涨 6 倍后，漂移速率几乎不变（每 600 秒仍规整地涨约 1000 点） |

两组实验合起来说明：**稳定力在记忆、速度、规模三个维度上都已不落下风，价格照样单调上涨。**
4200 秒时两族仓位几乎完全对开（+115,898,679 / −118,282,336）而价格仍在 2.86 倍——
它不是被打败的，是被说服的，因为它的公允价参照随市价一起涨。这是本文件的**事实基础**：
剩余的自由度只剩「参照本身是否随价格漂移」。

**所求性质（下称「锚性质」）**：存在一个不随市场价格移动的参照 `v_t`，且至少一方的
**供给（卖出意愿）随 `price/v_t` 的偏离单调增大**。当前均值回归族恰好相反——它越亏，
保证金闸口锁得越死，供给越少，最终被逼空反手买入。

**明确不是锚的东西**：[ADR-014](../decisions/014-historical-snapshot-fork-anchor.md)
的实盘快照分叉给的是**初始条件**，不是持续回复力；从 10000 起跑还是从真实价位起跑，
都不改变此后的单调上涨。本文件不讨论它。

## 2. 形态 1：基本面价值过程 + 价值投资者族

`v_t` 是一条外生随机过程（几何随机游走或 OU），对所有价值族可见；价值族按
`deviation = (price − v_t)/v_t` 建仓，`|deviation|` 越大目标仓位越大。

**属于人工市场的标准做法**（Santa Fe Artificial Stock Market、Farmer–Joshi 一类），
不是本项目发明的机制。

- **锚性质**：直接满足，且强度可由「价值族资本 × 偏离灵敏度」显式调节。
- **新增面**：一条外生过程（需要冻结参数与随机源口径，进 KR-004 的 keyed draw）、
  一个新族、运行头里的 `v_t` 参数与种子、信息层归属（`v_t` 是 I0 还是新的层？）。
- **与既有决策的冲突**：`ADR-011` 与 0.4.1 design §9 明确写了**不引入基本面/价值过程**。
  采纳本形态**必须先修订 ADR-011**，不能作为里程碑内的实现细节顺手加。
- **对研究问题的影响**：**最大**。价格会围绕 `v_t` 波动，于是厚尾与波动率聚集有多少
  是市场自己产生的、有多少是从 `v_t` 继承的，成为必须回答的问题。`v_t` 用随机游走时
  这个污染最小（游走本身无聚集、无厚尾），**建议若采纳则强制 `v_t` 为无聚集无厚尾的
  过程，并把「stylized facts 不得由 `v_t` 提供」写成显式判据**。

## 3. 形态 3：外部信号族携带价值观点（复用既有 I3 通道）

不新增机制：`world["external_decision_sources"]` 与 `agent/strategy_layer/external.py`
在 0.4.1 已交付并通过验收（AC-507/AC-508）。当前量化族消费的是一条**固定序列**
（`quant_family_run.fixed_signal_plan`，每 20 逻辑秒翻转方向），与价格无关，因此
**不提供锚性质**。改法是让信号携带价值判断，使委托量随 `price/v_t` 偏离增大。

- **锚性质**：满足，但**取决于信号内容**——锚性质由信号源保证，不由内核保证。
  信号源若退化（`SIGNAL_MISSING`/`STALE`/`INVALID`）会按既有规则降级为不动作，
  **锚随之消失且市场无从得知**。这是本形态最大的结构性弱点。
- **新增面**：几乎为零。接口、降级原因码、单向边界声明、artifact 自检都已存在并有测试。
- **与既有决策的冲突**：无。ADR-011 §决策 5 只禁止沙盘结果**回流** alphamill，
  单向消费外部信号正是既有设计。
- **对研究问题的影响**：**取决于信号来源**。若信号来自一条本地合成的 `v_t`，则与形态 1
  等价，只是换了注入路径；若来自真实行情或 alphamill，则引入了「沙盘价格被外部真实
  信息牵引」这一层，NFR-503 的 `engineering-demonstration` 定位需要重新审视。

## 4. 并排对比

| 维度 | 形态 1：价值过程 + 价值族 | 形态 3：I3 外部信号携带价值观点 |
|---|---|---|
| 锚性质 | 内核保证，始终在线 | 信号源保证，源退化则锚消失 |
| 新增机制 | 外生过程 + 新族 + 运行头参数 | 无（接口已交付并验收） |
| 决策冲突 | **必须先修订 ADR-011** | 无 |
| 可复现性 | 完全（keyed draw + 冻结参数） | 取决于信号源是否可重放 |
| 对 stylized facts 的污染 | 可控但必须显式判据隔离 | 取决于信号来源 |
| 工作量（粗估） | 一个里程碑 | 数天（主要是信号语义与判据） |
| 失败模式 | 锚太强 → 价格变成 `v_t` 的影子 | 锚静默消失 → 退回今天的单调上涨 |

## 5. 建议（供裁决，非决定）

**形态 1，但先修订 ADR-011。** 理由三条：

1. 锚性质必须由内核保证。形态 3 把「市场有没有锚」这件事交给一个可以静默降级的外部
   源——而降级路径是我们自己设计的、正确的行为（非阻塞、不报错），所以**锚消失时市场
   不会报警，只会安静地退回今天的失效形态**。这类"安静地失去一个保证"正是本仓库
   历史上反复吃亏的形态。
2. 形态 3 若用本地合成 `v_t`，在机制上等价于形态 1，却绕过了 ADR-011 的约束——
   那是**用注入路径规避一条明写的决策**，不应这样做。要引入价值过程就正面改 ADR。
3. 形态 3 的真正价值不在做锚，而在它已经交付的那件事：把外部策略接进同一条撮合与
   风控路径。把它改造成锚会污染这个定位。

**若采纳形态 1，建议同时冻结三条判据**（否则会重蹈「装上就过门」的老路）：

- `v_t` 必须是**无波动率聚集、无厚尾**的过程，且该性质由测试断言；
- stylized facts 的判定必须附带一条对照：**同一装配、同一种子、关闭价值族**的运行，
  用于分离「市场产生的」与「`v_t` 继承的」；
- 价值族资本与偏离灵敏度进运行头并冻结，**调整须留 git 痕迹与理由**，禁止为让门通过而调。

## 6. 前置条件：锚的强度参数必须被证明是 binding 的

**无论选哪个形态，落地前必须先产出一份 binding 诊断**：在目标装配上实测「哪个约束
实际决定了各族的仓位」，并证明锚的强度参数**改了会让行为变化**（可测）。

理由不是「口径洁癖」，而是已有的硬证据：MULT 补丁与现金基准补丁两次内存验证都与
未打补丁**逐位相同**（[报告 §8.6](../experiments/0.4.1-market-quality-baseline.md)），
这直接证明 `max_position_units` 这一层**当前完全不 binding**——实际决定仓位的是别处
（保证金闸口，或 `max_order_qty` 截断）。

由此推出一条比「选形态 1 还是形态 3」更要紧的结论：

> **任何把锚的强度表达成族层风险参数的设计，都会被静默改写。** 调 `risk_appetite_x1000`
> 或仓位上限，市场行为不变，因为那个约束根本不起作用——得到的是一个「参数存在但无效」
> 的锚。形态之争是设计取舍，这个是**旋钮没接线**。

因此前置条件的正确表述不是「先修 T1002」，而是：

1. 先做 binding 诊断（手段见 §8.6：内存补丁 + 逐位对比，改一个约束若输出逐位不变，
   它就不是约束）；
2. 锚的强度**挂在诊断出来的那个真实限制器上**。若诊断显示保证金闸口才是限制器，
   那强度就该显式挂在闸口口径上，**而不是在族层再加一个不起作用的参数**；
3. 修 T1002 只是达成该条件的一种方式，不是唯一方式。

**T1002 的风险提示**：修它会改变行为 → T215/H2 冻结证据必须重绑重盖；且它动的是 v0.1
冻结契约的语义，按 ADR-012/ADR-015 的先例必须 owner 裁决。因此它在 tasks.md 里记为
**已知缺陷 + 锚的前置条件**，而不是排进某个里程碑的实现任务。
