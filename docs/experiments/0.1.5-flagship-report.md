## 三终点正式结果

### crash

- 判定：`not-supported`
- 条件性结论：在冻结的代理结构、L×M 四 cell、两个目标模型与 128 个有效配对 seed block 范围内，崩盘家族 0/12 个预注册检验在 BH q=0.05 后支持处理效应；本结果是不支持预注册 H1，不等于接受 H0，也不得外推为现实市场无效应。
