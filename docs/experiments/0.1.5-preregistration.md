# 0.1.5 旗舰制度实验预注册

## 1. 研究问题与假设

在代理目标、偏好分布、初始零仓位和随机语义路径相同时，改变杠杆上限分布 `L`
与维持保证金率 `M` 是否改变崩盘、暴涨和流动性枯竭的发生率与严重度？

- 对每个终点家族和每个预注册对比，`H0: E[contrast] = 0`，`H1: E[contrast] != 0`。
- 不预设效应方向；无效应、崩盘/暴涨方向不对称和证据不足均是合法结果。
- 只有 `SPONTANEOUS + formal-research` 运行可用于本预注册的研究声明；
  `STRESS` / `BENCHMARK` 及旧产物不进入分析。

## 2. 处理因子的水平取值

| 因子 | low | high | 冻结理由 |
|---|---|---|---|
| `L` 杠杆上限分布 | `{2x:3334bp, 3x:3333bp, 5x:3333bp}` | `{10x:3334bp, 20x:3333bp, 50x:3333bp}` | 50x 约在 2% 回撤即可触发强平；将 3x—10x 之间拉开，避免处理强度过窄 |
| `M` 维持保证金率 | `300bp` | `700bp` | 上游扫描的强平失效边界落在 `[500,700]bp`，low/high 分置边界两侧 |

四个 cell 记为 `LL=(L_low,M_low)`、`LH=(L_low,M_high)`、
`HL=(L_high,M_low)`、`HH=(L_high,M_high)`。权重用 bp 整数且每个分布合计 10000；
余数 1bp 固定分配给数值最小的 tier。除 `L/M` 外，四 cell 配置必须逐字节相同。

## 3. 目标模型与偏好参数冻结

- 主模型：`risk_budget_linear_v1`。
- 稳健性模型：`risk_budget_threshold_v1`，冻结
  `theta_in=3000bp`、`theta_out=1200bp`、`k_x1000=600`。四 cell 和全部 seed 不得改参。
- `risk_appetite` 以 `x1000` 为单位，每个非做市代理在每次 run 构建时抽取一次：
  `int(Uniform[500,20000))`。它与 `L`、`M`、`leverage_tier` 独立，且相同
  `(master_seed, agent_id, "risk_appetite", 0, 0)` 在四 cell 共享同一抽样路径。
- 主模型与稳健性模型使用同一有效 seed 块。模型 ID 只改变目标映射，
  不得改变制度参数、偏好分布或初始状态。

## 4. 指标定义与判据

技术有效的每个 run 在三个家族都产生一个发生指示和一个无条件严重度；
未发生时严重度为 0，不做「仅对已发生样本」的条件筛选。

| 家族 | 发生指示 | 严重度指标 |
|---|---|---|
| 崩盘 | EV-1；EV-2 下行；EV-4 清空 bid 或双边 | `max_t(max(ln(P0/Pt),0))` |
| 暴涨 | EV-2 上行；EV-4 清空 ask 或双边 | `max_t(max(ln(Pt/P0),0))` |
| 流动性枯竭 | EV-3；EV-4 清空任一边或双边 | `max_continuous_no_trade_ns / run_total_ns` |

EV-2 阈值为 `|ln(Pt/P0)| > ln(10)`；EV-3 阈值为最长连续无成交时段
`> 5% * run_total_ns`。家族归属与重叠计数严格遵循
[退化状态 §4.1](../contracts/degenerate-states.md#41-判据表)；同一 run 可同时进入多个家族。
强平成交量占比、`chain_depth` 与技术无效率只作机制/质量诊断，不增加未预注册检验。

## 5. 估计量定义

以 seed 为配对/阻塞层级。对每个家族、模型和指标，先在每个 seed 内计算：

- `L_main = (Y_HL + Y_HH - Y_LL - Y_LH) / 2`；
- `M_main = (Y_LH + Y_HH - Y_LL - Y_HL) / 2`；
- `LxM = Y_HH - Y_HL - Y_LH + Y_LL`。

点估计是有效 seed 的块内对比均值。不确定性用整个四 cell seed 块重抽样的
10000 次 percentile bootstrap 95% CI（bootstrap seed `913201`）。双侧 p 值用块内对比的
100000 次 Monte Carlo sign-flip（seed `913202`），`p=(1+#(|T_perm|>=|T_obs|))/(B+1)`。
崩盘发生指示减暴涨发生指示的配对差与 95% CI 作为方向不对称的预注册描述量，
不单独产生 p 值。

## 6. 样本量与功效

主模型与稳健性模型共同需要 128 个有效的四 cell 配对 seed 块。二元发生率主效应的规划假设为：
双侧 `alpha=0.05`、功效 `1-beta=0.80`、配对不一致概率 `q=0.25`、最小可检测差值
`delta=0.125`。配对差的正态近似给出
`ceil((z_0.975+z_0.80)^2 * (q-delta^2) / delta^2) = 118`。冻结为 128 个有效块，
留出近 8% 余量且便于确定性分块。交互效应和经 BH 校正后的功效可能更低；
如信号不足，结论必须是「证据不足」，不得事后扩样。

## 7. seed plan

- 正式 seed 按升序冻结为 `30000..30127`（128 个）；技术失败预留 seed 为
  `30128..30143`（16 个）。
- 一个 seed 块包含四 cell 与 linear/threshold 两模型的 8 个 run。相同
  `master_seed/agent_id/mechanism/decision_index/draw_index` 语义键共享随机路径；
  `L/M` 、cell ID 与模型 ID 不得进入通用随机键。
- 每个 run 用相同配置与 seed 执行两次；第二次仅作 TI-2 事件摘要哈希审计，
  不是第二个统计样本。两次哈希不一致即整块按 TI-2 排除。
- 任一 run 命中 TI-1—TI-5 时排除整个 8-run seed 块，再严格按升序取一个
  预留 seed；不得只补某 cell 或某模型。

## 8. 排除规则与停止规则

排除仅限退化状态合同的 TI-1 引用完整性失败、TI-2 同 seed 重跑哈希不一致、
TI-3 C1/C2 守恒失败、TI-4 结构完整但 `terminated=ABORTED`、TI-5 日志结构损坏/截断。
判定顺序是先结构后语义；TI-4/TI-5 整份日志失效，不采信前半段。

按 seed 升序执行，达到 128 个有效块即停；若用完 16 个预留 seed 仍少于 128，
立即停止并报告「证据不足」。禁止因效应方向、p 值、CI 宽度、终点数量或外观追加/删除 seed。

## 9. 多重比较

崩盘、暴涨、流动性枯竭分别是三个 BH family，家族之间不合并。每个 family 含 12 个冻结检验：
`2 个模型 × 2 个指标（发生/严重度）× 3 个对比（L、M、L×M）`。对这 12 个双侧 p 值执行
Benjamini–Hochberg，`q=0.05`；同时报告原始 p 值、BH 调整值、效应量和 95% CI。
未在本集合中的诊断量只能描述，不得补做推断后改写为主要发现。

## 10. 校准区 / 验证区 / 实验区

| 区域 | `L` / `M` 参数 | seed | 用途与约束 |
|---|---|---|---|
| 校准区 | `L in {1x,4x,8x}`，`M in {400,600}bp` | `10000..10031` | 可反复调非制度扰动参数；结果不进入结论 |
| 冻结验证区 | `L=6x`，`M=500bp` | `20000..20063` | 只检查市场充分性门槛；一旦运行不得回调 |
| 信念实验区 | 本文 §2 的四 cell | `30000..30143` | 唯一可进入本预注册推断的区域 |

三区的 `L/M` 点和 seed 互不重叠。看到冻结验证区或信念实验区结果后，
任何参数、指标、排除、样本量或分析方法变更都必须生成新版本预注册，
且旧运行不得进入新版本正式结论。
