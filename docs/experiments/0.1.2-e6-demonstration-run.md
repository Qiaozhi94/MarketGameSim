# E6 达标示范运行——KPI-005/007/010/011 联合验证

**性质**：这**不是**一次预注册的信念检验研究（没有走 `ExperimentProtocol` 三区
流程，也不产出可外推的信念结论）。`evidence_class = engineering-demonstration`，
不得用于建立旗舰研究声明。它是 0.1.2 退出条件 E6 要求的"在真实研究
运行下"证据——证明 KPI-005/007/010/011 各自的产出机制不仅存在、有单测，而是
能在一次真实（非 BENCH-001 性能基准、非 `bench/leverage_seed.py` 人工预置杠杆
账户）的配对实验上一起正确运行。

**运行日期**：2026-08-09　**原始结果**：
[`0.1.2-e6-demonstration-run.json`](0.1.2-e6-demonstration-run.json)

## 配置

- 参与者：2 个做市商 + 20 个散户（真实决策循环，非人工预置仓位）
- 单维度对照（方法论 §10.5）：`leverage_tier` control=3x，treatment=10x，
  其余全部字段逐位相同（`check_paired_parity` 静态校验 + `check_shared_
  randomness_parity` 动态校验均通过）
- 5 个随机种子（`[1,2,3,4,5]`），`max_transactions=30000`
- 通过 `run_paired(control, treatment, seeds, treatment_field="leverage_tier", ...)`
  跑出，`build_study_report` 汇总两组各自的报告

## KPI-007：条件性结论

```
在参与者结构 2x做市商+20x散户、参数区间 leverage_tier 3x(control) vs
10x(treatment) 与 5 个随机种子（control）/5 个随机种子（treatment）下，
处理对经济终点率的效应量为 +0.0000（95% CI：[+0.0000, +0.0000]，
不显著（置信区间跨零））。失效条件未声明——本结论只在预注册的参数区间内
成立，不得外推。
```

方法论 §10.2 要求的形式（结构 S、参数区间 R、种子数 N、效应量、置信区间、
失效边界）全部出现，不是"有效/无效"二元判断。**效应量为 0** 是因为本次
30000 事务的运行规模下双组均未触发任何经济终点（`endpoint.rate` 均为 0，
`technical_invalid_rate` 均为 0）——诚实的空结果，不是机制失败。

## KPI-010：非单路径

两组各用 5 个独立随机种子（不是单次运行），`endpoint_rate_effect.n_control=5`、
`n_treatment=5`。`control_config_hash`/`treatment_config_hash`（E3）可反向核对
这条结论确切来自哪一份配置。

## KPI-005：市场验证矩阵

两组每个种子都产出了完整的六项声明（`fat_tails`、`return_autocorrelation`、
`volatility_clustering`、`price_impact_nonlinearity`、`spread_depth_regime`、
`liquidation_chain`），本次全部为 `NOT_APPLICABLE`——30000 事务对应的逻辑时长
远不足指标字典 §2 要求的 2000 个采样点（Δt=1 秒），且两组都未真正触发强平。
**`NOT_APPLICABLE` 是 KPI-005 明确认可的三种声明之一**（PRD §11.2："逐项声明
...为通过/失败/不适用"），不是声明失败——诚实报告"样本不足、无法判定"本身
就是达标，不需要为了凑出 PASS 而故意扩大规模。`endpoint.rate` 与
`technical_invalid_rate` 已按 KPI-005 第二分句要求分别报告。

## KPI-011：零和恒等式声明

两组 5×2=10 次运行，`residual_units` **全部为 0**——恒等式不只是声明，而是
在每一次真实运行上重新验证过确实成立。以 control 组种子 1 为例：

```
封闭市场零和恒等式（PRD §13.4）：22 个代理扣除手续费/穿仓核销后的权益变动
之和为 -2400140000（最小单位），恰等于交易所收取费用与穿仓核销之和的负值
-2400140000（残差 0，验证一致时应为 0）——这是会计恒等式，不是研究发现。
有内容的问题是分布：6 个代理净亏损、5 个代理净盈利，具体到每个代理的金额
见 per_agent_pnl_units。
```

## 结论与限制

本次运行**不产出任何信念检验结论**——规模刻意保持小（几秒钟跑完），只为
验证四项 KPI 的产出链路在真实数据上闭环，不是要证明"3x 和 10x 杠杆对崩盘率
有没有影响"。真正的信念检验需要走 `ExperimentProtocol` 的三区流程、预注册
样本量，并且很可能需要远大于 30000 事务的规模才能让市场验证矩阵产出非
`NOT_APPLICABLE` 的判定——这是 0.1.3（模型稳健性）与后续正式研究运行的范围，
不是本次示范的目标。
