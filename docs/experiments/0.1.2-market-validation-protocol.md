# 0.1.2 基准市场验证协议（T002 预注册，KPI-005 判定依据）

**状态**：冻结。变更须记录理由并评估对已产出 KPI-005 矩阵的影响，不得为让某次
运行"通过"而回头放宽本文档的数值。
**对应**：PRD §12（市场验证框架）、方法论 §9.3/§10.1、指标字典 §2/§3/§6。
**实现**：`src/market_game_sim/metrics/validation.py`（`build_market_validation_matrix`）。

## 1. 范围

本协议只覆盖 PRD §12 逐项列出的 6 个特征，对应 KPI-005。§9.3 提到但 §12 未列出的
"内生锚稳定参数区间"属于 0.1.3 参数扫描的产出（0.1.3 tasks T205），不在本协议
范围内。

## 2. 通用前提

- **采样**：全部统计特征使用指标字典 §2 的等间隔采样序列（`sample_market_series`，
  Δt = MD-001 = 1 秒逻辑时间），已按 burn-in 边界过滤。
- **最低样本量**：`n >= 2000` 个采样点（指标字典 §2）。不足时对应项判定为
  **不适用**，不得用不足的样本硬凑一个通过/失败结论。
- **前值填充比例**：若填充比例 > 30%，收益类统计检验（厚尾、自相关、波动聚集、
  点差-波动率相关性）整体判定为**不适用**，附填充比例作为证据——指标字典 §2 已
  声明此时"统计检验不可采信"。价格冲击与强平连锁两项不依赖等间隔序列，不受此
  规则约束。
- **显著性水平**：单项检验 α = 0.05。
- **多重比较**：本协议同时检验多个假设，家族按"拒绝原假设 = 判定通过"的方向
  分为两组分别处理（详见各项），复用 `experiment/stats.py::holm_bonferroni`
  的 Holm-Bonferroni 逐步校正，不单独发明第二套校正算法：
  - **组 A**（拒绝 H0 即通过）：厚尾、波动聚集、价格冲击非线性、点差-波动率
    正相关——这四项在同一次运行上联合做 Holm-Bonferroni 家族校正；
  - **组 B**（收益自相关，拒绝 H0 即失败）：判定方向相反（"不显著"才是通过），
    与组 A 的"拒绝=通过"语义冲突，不能混进同一个家族——单独在其内部的 5 个
    滞后阶数（lag 1–5）上做 Holm-Bonferroni 家族校正，只要任一阶数校正后仍
    显著即整体判失败。
- **检验实现**：全部使用渐近正态近似（`statistics.NormalDist`），不依赖 t 分布
  临界值表或 scipy——项目当前不引入 scipy 依赖，且 §10.1"够用即止"不要求小样本
  精确修正；`n >= 2000` 的最低样本量门槛下，正态近似的误差可接受。

## 3. 逐项判定规则

### 3.1 收益分布厚尾

- **统计量**：对数收益（指标字典 §3.2，取成交价而非中间价）序列的**超额峰度**
  `k = m4/m2² − 3`。
- **检验**：`z = k / sqrt(24/n)`（大样本下正态总体超额峰度估计量的渐近标准误），
  单侧检验 `H0: k <= 0` vs `H1: k > 0`。
- **通过**：`p < 0.05` 且 `k > 0`（显著肥尾）。
- **失败**：不满足上式。
- **不适用**：`n < 2000` 或前值填充比例 > 30%。

### 3.2 收益序列无显著线性自相关

- **统计量**：lag 1–5 的自相关函数 `ACF(r, lag)`。
- **检验**：白噪声下 `ACF` 渐近标准误为 `1/sqrt(n)`（Bartlett 公式），逐阶
  `z_lag = ACF_lag / (1/sqrt(n))`，双侧 p 值，5 个 lag 一起做 Holm-Bonferroni
  家族校正（见 §2 组 B）。
- **通过**：5 个 lag 校正后均不显著。
- **失败**：任一 lag 校正后仍显著。
- **不适用**：`n < 2000` 或前值填充比例 > 30%。

### 3.3 绝对收益自相关为正（波动聚集）

- **统计量**：`|r_t|` 序列 lag 1 的 `ACF`。
- **检验**：同 §3.1 的正态近似标准误 `1/sqrt(n)`，单侧 `H0: ACF <= 0` vs
  `H1: ACF > 0`。
- **通过**：`p < 0.05` 且 `ACF > 0`，且通过组 A 的 Holm-Bonferroni 家族校正。
- **失败**：不满足。
- **不适用**：`n < 2000` 或前值填充比例 > 30%。

### 3.4 价格冲击随订单规模非线性增长

- **前提数据**：`compute_price_impact` 产出的逐 taker 订单 `(quantity_units,
  impact_bp)`，只取 `impact_bp > 0` 的订单（符号翻转后的正逆价convention，
  §4 冲击定义）。
- **最低样本量**：`>= 40` 笔有效 taker 订单；不足判**不适用**。
- **统计量**：对 `ln(impact_bp) = c + γ·ln(Q)` 做普通最小二乘回归，取斜率 `γ`
  及其标准误 `SE(γ)`（残差方差 / `Q` 的离散度）。
- **检验**：`t = (γ − 1) / SE(γ)`，双侧 `H0: γ = 1`（线性）vs `H1: γ ≠ 1`。
- **通过**：`p < 0.05` 且通过组 A 家族校正（方向不限——γ>1 或 γ<1 都算"非线性"，
  报告中须注明具体方向）。
- **失败**：不满足。
- **不适用**：有效订单 `< 40` 笔，或全部订单规模相同（回归退化）。

### 3.5 点差与深度在合理范围且随波动变化

分两个子判据，均满足才算通过：

- **合理范围**（非假设检验，固定阈值）：
  - 相对点差 `spread_ticks / mid_ticks` 落在 `(0, 0.05]` 的采样点占比 `>= 95%`；
  - 买卖两侧深度（MD-003：距最优价 ±10 tick）同时 `> 0` 的采样点占比 `>= 95%`。
- **随波动变化**：滚动已实现波动率（MD-002：`W = 30` 个采样点）与同时刻
  `spread_ticks` 的 Pearson 相关系数 `r`；`t = r·sqrt(n−2)/sqrt(1−r²)`，单侧
  `H0: r <= 0` vs `H1: r > 0`；纳入组 A 家族校正。
- **通过**：合理范围两条 **且** 相关性检验通过。
- **失败**：任一条不满足。
- **不适用**：`n < 2000`、前值填充比例 > 30%，或点差/深度全程未定义（单边空簿）。

### 3.6 杠杆情形下的强平连锁规模分布

纯描述性报告，不做假设检验（PRD §12：只要求"透明报告"，不设通过阈值）：

- 强平触发次数、连锁深度分布（`chain_depth_counts`）、强平成交量占比
  （`liquidation_volume_ratio`）、破产次数。
- **通过**：产出的指标内部一致（`0 <= liquidation_volume_ratio <= 1`、强平成交量
  不超过总成交量、连锁深度分布中不含深度为 0 的记录）。
- **失败**：内部不一致（数据完整性问题，而非"市场不够真实"）。
- **不适用**：本次运行无杠杆代理或全程未触发强平——此时"强平连锁"这一特征
  对该运行不存在，不是"检验未通过"。

## 4. 与「够用即止」的关系

第一层门槛允许 6 项中出现失败或不适用（方法论 §10.1、PRD §12："MVP 不要求全部
通过"）。KPI-005 的验收标准是**矩阵完整产出且如实声明**，不是全部绿灯；一旦
矩阵生成，其判定结果不得因为某项"不好看"而回头修改本协议的阈值或方法重新计算
（§10.1："不得在看过第二层结果后回头放宽"）。
