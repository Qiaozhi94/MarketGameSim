# H2 Q-302/Q-304 参与者报酬预算证据

**证据 ID**：`H2-Q302-Q304-compensation-budget-v2`  
**状态**：`SUPERSEDED_BY_SCOPE_CLARIFICATION`  
**证据类别**：项目所有者预算决定与可复核算术；平台费用不在本证据范围内  
**日期**：2026-09-06

## 1. 冻结决定

本节是“招募 130 名外部真人”假设下的历史预算。项目所有者已确认不招募外部真人；当前
招募人数、参与者报酬和平台均为 `0 / $0 / 无`，以
[`H2-dual-track-contract`](H2-dual-track-contract.md) 为准。以下金额保留用于解释旧决策，
不得进入当前预算。

- 币种：美元（USD）。
- 每名完成者固定基础报酬 `$22.00`；综合绩效奖金为 `$0–4.40`，即基础报酬的 `0–20%`；
  单人最高报酬 `$26.40`。
- 8 名 pilot 参与者采用相同报酬标准，但永不计入正式样本。
- 最多 26 名分配前资格或理解检查未通过者按 `$2.00/人`支付筛选补偿，不领取完成报酬或奖金。
- 招募与支付平台固定为 Prolific；独立研究者按 `42.8%`平台费规划，基础报酬、奖金和筛出
  补偿均属于参与者报酬计费基数。
- 参与者报酬预算预留上限为 `$4,100.00`；加平台费后的需求为 `$5,854.80`，项目资金预留
  向上冻结为 `$5,900.00`。VAT、税费和汇兑成本另行核算，不能从参与者报酬中扣减。

## 2. 合理性边界

目标会话 90 分钟时，基础报酬折合 `$14.67/小时`；即使达到 105 分钟硬上限，仍折合
`$12.57/小时`。基础报酬本身已高于 Prolific 当前 `$8/小时`最低标准及 `$12/小时`建议
标准；绩效奖金不用于补足基础时薪。任务需要持续注意和多轮决策，因此采用高于建议线的
基础报酬，而不是依靠不确定奖金达到合理水平。

外部基准：[Prolific — How much should I pay participants?](https://researcher-help.prolific.com/en/articles/445266-how-much-should-i-pay-participants)、
[Who can post studies on Prolific?](https://researcher-help.prolific.com/en/articles/445104-who-can-post-studies-on-prolific)
与 [What is your pricing?](https://researcher-help.prolific.com/en/articles/445239-what-is-your-pricing)
（均访问并冻结于 2026-09-06）。Prolific 明确接受独立研究者；非机构邮箱账户需要平台人工
审核，且不能使用学术/非营利优惠费率。平台实际创建研究时若显示更高竞争价格或费率，必须
上调基础报酬和总预算，不得下调本证据中的金额。

## 3. 预算算术

机器可复核结果见 [`H2-power-feasibility.json`](H2-power-feasibility.json) 的
`compensation_budget`；运行
`python tools/h2_power_feasibility.py --check docs/experiments/H2-power-feasibility.json`
可同时校验功效和预算。

| 项目 | 算式 | 最高金额 |
|---|---:|---:|
| 130 名正式完成者 | `130 × $26.40` | `$3,432.00` |
| 8 名 pilot 完成者 | `8 × $26.40` | `$211.20` |
| 最多 26 名分配前筛出者 | `26 × $2.00` | `$52.00` |
| 参与者报酬小计 | `$3,432.00 + $211.20 + $52.00` | `$3,695.20` |
| 10% 预备金后需求 | `$3,695.20 × 1.10` | `$4,064.72` |
| 冻结预留上限 | 向上取整并保留 `$35.28`余量 | `$4,100.00` |
| Prolific 平台费 | `$4,100.00 × 42.8%` | `$1,754.80` |
| VAT/汇兑前资金需求 | `$4,100.00 + $1,754.80` | `$5,854.80` |
| VAT/汇兑前项目资金预留 | 向上取整并保留 `$45.20`余量 | `$5,900.00` |

## 4. 支付和变更规则

- 所有完成者获得完整 `$22.00`基础报酬，不因实验表现下降、破产、强平或数据是否支持假设而
  扣减；奖金只可增加报酬。
- 奖金公式、支付时点和筛选补偿条件必须在参与前披露，并在查看正式 H2 结果前冻结。
- 若 pilot 表明会话中位时长超过 105 分钟，或招募平台要求的基础时薪高于本证据口径，必须
  在继续正式招募前提高基础报酬并生成新版本预算证据。
- `$4,100.00`为参与者报酬专用预算；`$5,900.00`为按当前 Prolific 费率计算的 VAT/汇兑前
  项目资金预留。发布前须以平台 draft quote 复核费率；差额只能追加，不能挤占参与者报酬。
