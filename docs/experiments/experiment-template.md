**制度因子实验（如 0.1.5 旗舰）的必填清单**——下列每一项都必须在看到任何结果之前
写定。先跑再定的任何一项都会让"预注册"退化成事后叙述，而事后叙述无法区分"发现"

- [ ] 处理因子的水平取值（如 `L`、`M` 各自的 low/high 具体数值与选取理由）；

- [ ] 每个终点家族的**指标定义与判据**（含判据引用，如退化状态 §4.1 的 EV 归属表）；

- [ ] seed plan（生成方式、配对语义键、四 cell 如何共享随机路径）；
- [ ] 排除规则（技术无效判据）与**停止规则**（何时停止收样，不得看结果再决定）；
