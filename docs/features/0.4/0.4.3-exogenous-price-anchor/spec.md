# 0.4.3：外生价格锚——让市场质量与 stylized facts 达标

> Owner: TBD | Target: v0.4

## 0. 来源与意图

- **版本规格**：[`../spec.md`](../spec.md)。
- **前置里程碑**：[`0.4.1`](../0.4.1-ai-market-ecology/spec.md)（L2 策略层、四个原生族、
  市场质量与 stylized facts 度量、门禁前置有效性条件）。
- **架构决策**：[`ADR-011`](../../../decisions/011-market-engine-trader-layering.md)
  （§决策 2 明文禁止价值过程，**本里程碑必须先修订它**）、
  [`ADR-016`](../../../decisions/016-stylized-fact-validity-preconditions.md)
  （门禁前置有效性条件；锚的强度必须可证明 binding 且沿目标维度单调）。
- **选型材料**：[`exogenous-price-anchor-options.md`](../../../research/exogenous-price-anchor-options.md)。
- **实证基础**：[`0.4.1 实验报告 §13—§17`](../../../experiments/0.4.1-market-quality-baseline.md)。
- **功能类型**：runtime / validation。**规格模式**：full。**变更类型**：ADDED。
- **一句话意图**：给市场一个**不随价格漂移的价值参照**，使价格不再单调发散，
  让 0.4.1 移出的市场质量六项与 stylized facts 判据在**原口径下**达标。

## 1. 问题、目标与非目标

### 问题

0.4.1 的市场会单调涨到初值的 7 倍然后停止成交。根因已定位并排除了全部装配内替代手段：
**四类交易者判断「价格贵不贵」的参照全部取自价格自己的历史**，因此价格走多远，它们的
「公允价」就跟到多远——稳定力不是被打败的，是被说服的。

已排除的竞争解释（0.4.1 报告 §10、§12、§17）：稳定力的记忆太短、规模不足、行动频率
太慢、单笔委托量、噪声族容量。三个独立杠杆各自显著改善了成交量或市场寿命，**漂移速率
均未被实质改变**。

### 目标

1. 引入一条**外生价值过程** `v_t` 与消费它的价值投资者族，使供给随 `price/v_t` 的偏离
   增大，价格不再单调发散。
2. 使 0.4.1 移出的 **E3（市场质量六项达标）与 E4（stylized facts 达 SC-502 条数）在
   原判据、原门限、原口径下**达标。
3. 锚的强度参数必须满足 ADR-016 §4.1 的两条：可证明 binding，且可证明沿目标维度单调。
4. 分离「市场自己产生的」与「从 `v_t` 继承的」统计性质，使 stylized facts 的达标不是
   由锚直接提供。

### 非目标

- 不使用实盘行情数据——实盘快照分叉仍归
  [`ADR-014`](../../../decisions/014-historical-snapshot-fork-anchor.md) 与其里程碑。
- 不做多标的、不做横截面因子。
- 不修改 L1（撮合、账本、保证金、强平、事件 schema）的既有语义。
- 不产生任何研究声明；证据级别为 `engineering-demonstration`。
- **不调整 0.4.1 移出的任何判据、门限与口径**（受 0.4.1 Q-504「不可调」约束）。

## 2. 用户场景

### US-701：看到一个不会跑飞的市场（Priority: P1）

作为项目所有者，我希望市场的价格围绕某个水平双向波动而不是一路涨到停摆，
以便我相信在里面观察到的现象是市场行为而不是数值发散。

**独立测试**：纯 AI 市场运行完整测量窗口，断言价格倍数有界、窗口内出现双向运动、
窗口末仍有成交。

**验收场景**：

1. Given 装配含价值族，when 运行满测量窗口，then 价格未单调发散且窗口末仍有成交。
2. Given 同装配同种子，when 重跑，then 价格序列逐点一致。

### US-702：知道统计性质是市场产生的还是锚给的（Priority: P1）

作为项目维护者，我希望每次 stylized facts 判定都附带一条「关闭价值族」的同种子对照，
以便区分市场自己的性质与从 `v_t` 继承的性质。

**独立测试**：同装配同种子跑开/关价值族两轮，断言对照轮随报告落盘且两轮判定可比。

**验收场景**：

1. Given 一次达标运行，when 导出报告，then 对照轮的判定随之落盘。
2. Given `v_t` 本身，when 对其做同样的 stylized facts 检验，then 它不具备被声称由市场
   产生的那些性质。

## 3. 范围与边界

### 范围内

- 外生价值过程 `v_t`：形态、冻结参数、随机源口径（KR-004 keyed draw）、进运行头。
- 价值投资者族：按 `price/v_t` 偏离建仓，强度参数满足 ADR-016 §4.1 两条。
- 锚强度的 binding 诊断与单调性验证（复用 0.4.1 的 `metrics/binding_diagnosis.py`）。
- 「关闭价值族」的同种子对照运行及其随报告落盘。
- 承接 0.4.1 移出的 E3/E4 达标判定。

### 范围外

- 实盘行情数据与快照分叉（ADR-014）；多标的；任何研究声明；L1 合同修改。

### 边界场景

- `v_t` 的参数使价格被钉死（实测过的失效形态：0.4.1 §14，价格 1.6 小时只走 0.55%，
  波动聚集从 PASS 翻 FAIL、趋势族主动成交仅 4 笔）：必须判定为**锚过强**并如实记录，
  不得以「六项达标」掩盖异质性塌陷。
- 锚的强度参数被证明不 binding 或不单调：按 ADR-016 §4.1 视为设计缺陷，须换挂载点，
  不得保留一个名存实亡的参数。

## 4. 需求

### Requirement: 外生价值过程（`FR-701`）

- **FR-701**：系统应提供一条不由市场价格导出的价值过程 `v_t`，其参数与随机源冻结并
  进入运行头；同参数同种子必须逐点复现；`v_t` 本身**不得**具备波动率聚集与厚尾
  （否则 stylized facts 的达标无法归因于市场）。

### Requirement: 价值投资者族（`FR-702`）

- **FR-702**：系统应提供消费 `v_t` 的策略族，其目标仓位随 `(price − v_t)/v_t` 的绝对值
  单调增大；该族走与其他族完全相同的撮合、账本与风控路径；其强度参数必须挂在经诊断
  确认 binding 的约束上。

### Requirement: 归因对照（`FR-703`）

- **FR-703**：每次 stylized facts 判定应附带同装配、同种子、**关闭价值族**的对照运行，
  两轮判定随报告一并落盘。

### 非功能需求

- **NFR-701**：锚的强度参数必须**可证明 binding**（扰动后事件流变化）**且沿目标维度
  单调**（改它让价格倍数按方向变化），二者缺一即视为「旋钮没接线」
  （ADR-016 §4.1 的两种形态）。
- **NFR-702**：同装配同种子逐点可复现；`v_t` 参数与价值族装配进运行头。

## 5. 生命周期与不变量

```text
DRAFT       -> ANCHORED     v_t 与价值族可装配运行，价格不再单调发散
ANCHORED    -> ATTRIBUTED   关闭价值族的对照运行落盘，统计性质可归因
ATTRIBUTED  -> QUALIFIED    E3/E4 在原口径下达标
ATTRIBUTED  -> UNQUALIFIED  未达标：如实产出未通过报告，不得调门限
```

**不变量**：任何状态下都不得调整 0.4.1 移出的判据、门限与计算口径；锚过强导致的
异质性塌陷必须如实记录，不得以六项达标掩盖。

## 6. 成功与验收

- **SC-701**：市场质量六项达标——**判据、门限与口径全部引自
  [`0.4.1 spec §6 SC-501`](../0.4.1-ai-market-ecology/spec.md#6-成功与验收)，本 spec 不重新定义。**
- **SC-702**：stylized facts 达 SC-502 条数——同上，含 ADR-016 的前置有效性条件。
- **SC-703**：`v_t` 自身不具备波动率聚集与厚尾，且关闭价值族的对照运行随报告落盘。
- **SC-704**：锚的强度参数经诊断确认 binding 且沿价格倍数单调。

### 验收清单

- [ ] **AC-701** (`FR-701`, `NFR-702`): `v_t` 参数进运行头；同参数同种子逐点复现；
      对 `v_t` 自身做 stylized facts 检验，波动聚集与厚尾**不通过**（正反两侧断言）。
- [ ] **AC-702** (`FR-702`, `NFR-701`): 价值族目标仓位随偏离单调；强度参数的 binding
      与单调性各有一条实测断言；不 binding 或不单调时 fail closed。
- [ ] **AC-703** (`FR-703`, `SC-703`): 关闭价值族的同种子对照随报告落盘，两轮判定可比。
- [ ] **AC-704** (`SC-701`, `SC-702`): E3/E4 在原口径下的达标判定；未达标时如实产出
      未通过报告（两条路径都有断言）。
- [ ] **AC-705**: 锚过强（价格被钉死、异质性塌陷）可被检出并如实记录，不得判达标。

### 退出条件

| 退出 | 条件 | 证据 |
|---|---|---|
| E1 | **市场质量六项达标**（承接自 0.4.1 E3，判据一字未改） | 装配清单 + 市场质量报告 |
| E2 | **stylized facts 达 SC-502 条数**（承接自 0.4.1 E4，含 ADR-016 前置条件） | 跨种子质量报告集合 |
| E3 | `v_t` 与价值族可装配运行，同种子逐点复现，参数进运行头 | 运行头 + 复现测试 |
| E4 | 关闭价值族的同种子对照随报告落盘，统计性质可归因 | 对照运行报告 |

## 7. 测试、依赖与决策

- **前置依赖（阻塞）**：**T1002（策略层与账本的名义口径不一致）须先裁决**——
  0.4.1 §17.6 已证明两个「装配可调、不必动冻结契约」的强度挂载点均不可用，
  只剩账本保证金闸口，而它属冻结契约。
- **必须先修订**：[`ADR-011`](../../../decisions/011-market-engine-trader-layering.md)
  §决策 2 明文禁止价值过程；本里程碑的前提是该决策被正式修订，**不得绕开**。
- 复用：0.4.1 的度量、门禁、binding 诊断工具与经济等价证明机制。

## 8. 待确认问题

- [ ] Q-701: `v_t` 取什么形态？几何随机游走、OU 还是别的——0.4.1 §14 实测常数锚会把价格钉死且异质性塌陷，故常数已被排除；需在「不钉死」与「不发散」之间定参数。
- [ ] Q-702: `v_t` 对哪些信息层可见？它既不是盘口也不是成交，现有 I0—I3 没有它的位置。
- [x] Q-703: 锚的强度最终挂在哪个约束上？— **已由实测回答（2026-09-26）：不挂在任何容量约束上。** 三个候选（`max_order_qty`、噪声族仓位上限、账本保证金闸口）全部失败，且失败原因可从定义推出——容量约束的响应只取决于代理自己的持仓，不取决于价格相对目标的偏离，故在原理上无法产生「方向由偏离决定」的力；被触发时还会放大漂移（逆势方被迫平仓的方向必然顺势，见实验报告 §8.4、§18.5）。强度必须住在参照本身与价值族的响应函数里，`T1100`（原 T1002）的意义相应改为「让价值族的容量参数不被静默改写」。
