# 0.4.3：外生价格锚 - 设计

> Owner: TBD | Spec: `spec.md`

## 0. 输入与约束

- 行为真相源：[`spec.md`](spec.md)。判据、门限与口径全部引自
  [`0.4.1 spec §6`](../0.4.1-ai-market-ecology/spec.md#6-成功与验收)，本里程碑不重新定义。
- L1 合同不可改；`ADR-011` §决策 2 已由 `ADR-017` 修订（只许可恒定外生参照）；`ADR-016` §4.1 的两条强度前置必须满足。

## 1. 技术概要与影响面

新增一个恒定外生参照与一个消费它的策略族，全部落在 L2 策略层内。不改撮合、账本、保证金、
强平与事件 schema，因此可沿用 [`ADR-015`](../../../decisions/015-rebind-frozen-evidence-after-bookkeeping-fix.md)
的经济等价证明机制处理冻结证据。

影响面：`agent/strategy_layer/families/` 新增一族；`experiment/roster.py` 新增族与其
参数校验；`strategy_layer/protocol.py` 新增正交字段 `value_reference`（升
`PROTOCOL_VERSION`）；运行头新增 `value_process` 块；质量报告新增对照轮字段。

## 2. 架构与模块边界

`v_t` 是**世界状态**而非某个族的私有状态：它是运行头里冻结的一个常量（ADR-017 只许可
恒定形态，不需要随机源），对声明消费它的族可见。价值族只读取它，不修改。

**锚的强度不在 `v_t` 里**：`v_t` 恒定，强度由价值族的代理数/资本与偏离灵敏度决定
（spec Q-701、Q-703）。0.4.1 §14 的钉死形态对应强度无穷大，是扫描区间的一端。

**可见性**：`v_t` 不进 I0—I3 的累加层级，经正交字段 `value_reference` 下发；只有在
族声明里登记了该字段的族才能拿到，其他族的信息集携带它即在裁剪处拒绝（spec Q-702）。
Web 终端不显示。

## 3. 数据模型与 Migration

- 运行头新增 `value_process`：形态标识（本里程碑仅 `constant`）与冻结值。**向后兼容**：缺该块即表示
  未装配价值族，既有运行头逐字节不变。
- 质量报告新增对照轮引用字段（关闭价值族的同种子运行），缺省为 `null`。

## 4. 接口、Contract 与 Event

- **不新增事件类型**。价值族的决策写进既有 `AGENT_DECIDE` 的 `internal_state`，
  与 0.4.1 的四个族一致（TR-501）。
- `v_t` 的求值是纯函数 `(运行头参数, 逻辑时刻) -> int`，可重放。

## 5. Runtime、Workflow 与并发

装配与推进沿用 0.4.1 的 `LiveMarket.advance()` 结构，不改推进语义。对照运行是**同一
入口的第二次调用**（同装配、同种子、价值族数量置 0），不新建实验框架。

## 6. UI 与可观测性

本里程碑不改 Web 终端。`v_t` 与市价的偏离作为诊断字段随质量报告落盘。

## 7. 失败、恢复、安全与兼容

- **锚过强**（价格被钉死）：0.4.1 §14 实测过该形态——价格 1.6 小时只走 0.55%、波动
  聚集翻 FAIL、趋势族主动成交仅 4 笔。须有检出手段并如实记录，**不得以六项达标掩盖**。
- **强度参数名存实亡**：按 ADR-016 §4.1 的两种形态（不 binding / binding 但不单调）
  分别有断言，命中即 fail closed。

## 8. 测试策略与验收映射

| AC | 验证路径 |
|---|---|
| AC-701 | `v_t` 复现测试 + 对 `v_t` 自身的 stylized facts 检验（须不通过） |
| AC-702 | 价值族单调性单元测试 + binding/单调性实测断言 |
| AC-703 | 对照轮落盘的集成测试 |
| AC-704 | 达标与未达标两条路径的门禁测试 |
| AC-705 | 锚过强的检出测试（价格倍数过低 + 异质性塌陷） |

## 9. 已确认决策与残余风险

- 已确认：不使用实盘数据；不改 L1；判据一字不改地承接自 0.4.1。
- **残余风险 1**：`v_t` 参数落在「钉死」与「发散」之间的窗口可能很窄，需要多轮实测；
  实测时必须预注册判据，避免 0.4.1 记录过的「用代理量推断」与「单点满足判据」两种失误。
- **残余风险 2**（2026-10-04 更新）：强度挂载点已由 spec Q-703 定为价值族的响应函数，
  不挂任何容量约束。剩余风险是该响应函数在扫描中被证明不 binding 或不单调——按
  ADR-016 §4.1 fail closed，须换响应函数形式，不得保留名存实亡的参数。

## 10. 待确认设计问题

- [x] DQ-701: `v_t` 进哪个信息层？— **owner 裁决（2026-10-04）：正交字段 `value_reference`，不进 I0—I3**，理由见 spec Q-702。
- [x] DQ-702: 对照轮是否进 evidence index？— **owner 裁决（2026-10-04）：不进。** 本里程碑证据级别为 `engineering-demonstration`，与 0.4.1 NFR-503（产物不进任何 evidence index）一致；进 index 即需冻结与盖章，成本与证据价值不匹配。对照轮随质量报告落盘（FR-703）不受影响。
