## 1. 问题、目标与非目标

### 问题

当前 live 市场不是市场。2026-09-19 实测（口径见 [`ADR-011`](../../../decisions/011-market-engine-trader-layering.md) 背景表）：
H2 双代理配置 3.0 笔成交/分钟、52.3% 的秒没有双边盘口、中位盘口档位 (1, 1)；
换成 190 代理的群体配置后成交为 0，根因是**冷启动死锁**——代理目标仓位要等 EWMA
预热，预热样本取自公开成交流，没有代理下单就没有成交流，预热永不完成。关闭预热后
成交恢复到 22 笔/分钟，但价格波动仍为 `0.000%`：全部代理同属一个五因子模板，信号
买卖各半（同向率 50–54%），净订单流恒为零，只有流动性没有价格发现。

三个研究问题都建立在「AI 市场自己会交易、会形成价格」这个前提上，而这个前提目前不成立。

### 目标

1. 消除冷启动死锁：零成交市场中代理必须能产生首笔订单，且冷启动锚是显式的冻结决策，
   不是「把预热关掉」这种副作用式绕过。
2. 建立 L2 交易者策略层：`TraderStrategy` 协议 + 策略族注册表 + 分级信息集，
   新策略族不需要改内核。
3. 装配异质策略族市场（趋势跟随 / 均值回归 / 情绪噪声 / 改良做市商），使价格由策略
   互动内生形成。
4. 用市场质量与 stylized facts 两组可复现的数字判定「像个市场」，并把它做成可重复
   运行的门，不靠人眼看 K 线。
5. 接入量化交易者族（Alpha101 纯时序子集 + 不依赖 alphamill 的外部信号注入接口），
   作为异质信号源，且沙盘结果单向不回流；alphamill 适配器见 §3 范围外。

### 非目标

- 不引入外生基本面、价值过程、财报或市值数据（[`ADR-011`](../../../decisions/011-market-engine-trader-layering.md) §决策 2）；价值投资者族不做。
- 不做多标的/合约池；Alpha101 的横截面算子（`rank`）因此不在可用子集内。
- 不把沙盘内的盈亏、胜率、回撤写成任何策略的有效性证据，也不回流 alphamill 证据链。
- 不在本里程碑做人类扰动实验本身——本里程碑只交付它所需的对照基线与市场载体。
- 不修改 L1（撮合、账本、保证金、强平、事件 schema）的任何既有合同。
- 不建立研究声明：本里程碑 `evidence_class` 为 `engineering-demonstration`。

## 2. 用户场景

### US-501：看到一个会自己活动的市场（Priority: P1）

作为项目所有者，我希望在不做任何操作时市场自己就在成交、盘口在变化、价格在走，
以便我判断这个模拟市场值不值得我作为交易者进去。

**为什么是这个优先级**：这是 ADR-010 之后所有 owner-facing 交付的前提；市场不动，
终端做得再好也没有意义。

**独立测试**：新进程启动纯 AI 市场，连续运行 N 个逻辑分钟，不注入任何外部订单，
断言成交率、盘口可用性、档位数与价格波动达到冻结门限。

**验收场景**：

1. Given 纯 AI 市场从冷启动开始，when 运行到第一个逻辑分钟末，then 已产生成交且
   双边盘口可用，不需要任何人工或注入订单。
2. Given 市场持续运行，when 观察价格序列，then 价格发生内生变化，`price_range` 不为零。

### US-502：用异质策略族装配市场（Priority: P1）

作为项目维护者，我希望按策略族清单装配一个市场并运行，以便观察不同策略构成产生
什么价格行为，而不需要修改内核代码。

**为什么是这个优先级**：策略族异质是价格发现的机制来源；没有装配能力就只能反复
改写死的参数。

**独立测试**：用两份不同的策略族清单装配同一引擎，断言两次运行的装配记录、
市场质量报告可分别重建，且同清单同种子轨迹一致。

**验收场景**：

1. Given 一份策略族装配清单，when 启动市场，then 各策略族按声明的数量与参数进入
   市场，装配记录写入 artifact。
2. Given 同一清单与同一种子，when 重跑，then 价格序列逐点一致。

### US-503：把外部量化策略接进沙盘（Priority: P2）

作为项目所有者，我希望把 alphamill 挖出来的量化策略作为一类交易者放进沙盘，
以便在我作为上帝视角游玩时观察它们与其他策略族的互动。

**为什么是这个优先级**：这是分叉设计的价值所在，但依赖 US-501/US-502 先成立。

**独立测试**：用固定的外部信号序列驱动一个量化交易者族，断言其委托进入既有撮合
路径、因果链完整，且产出的 artifact 带有「不得用作策略有效性证据」的边界声明。

**验收场景**：

1. Given 一个外部策略信号源，when 市场运行，then 该策略的委托与其他策略族一样
   进入撮合、账本与风控路径，并可从事件链回溯到策略族标识。
2. Given 沙盘运行结束，when 导出结果，then artifact 明确标注单向边界，不含可被
   误用为 alphamill 证据的字段命名。

## 3. 范围与边界

### 范围内

- 冷启动锚机制与其冻结参数；`ewma_half_life_trades` 在 live 生态下的语义澄清。
- `TraderStrategy` 协议、策略族注册表、分级信息集定义，以及它们与既有
  `GoalModel`/`behavior_mapping`/`external_decision_sources` 接缝的接线。
- 原生策略族：趋势跟随（多时间尺度）、均值回归、情绪噪声、改良做市商（参数分散）。
- 量化交易者族：Alpha101 纯时序子集筛查结果 + 外部信号注入接口（用固定信号序列验收）。
- 市场质量度量（成交率、成交/委托比、盘口可用性、档位、价差、实时性能）与
  stylized facts 度量（厚尾、波动聚集、收益自相关、成交量—波动相关、订单流长记忆）。
- 策略族装配清单与市场质量报告两类 artifact，及其机器校验入口。
- live 市场的运行入口（模块 `__main__` 与 `RUN.md` 记录）。

### 范围外

- L1 任何既有合同的修改（撮合、账本、保证金、强平、事件 schema、确定性口径）。
- 外生基本面/价值过程、多标的合约池、行业与市值数据。
- 人类扰动实验的设计与执行、owner 场次安排、任何研究声明。
- Web 终端的界面改动（本里程碑只保证终端背后的市场是活的）。
- **alphamill 适配器本身**：其上游 M3「策略到 paper 闭环 + 版本化信号」尚未开工
  （2026-09-20 核实：alphamill 活跃 Feature 为 F003/F007/F008，均在 0.2 版本 M2 阶段），
  当前没有可消费的策略产出。本里程碑只交付**不依赖 alphamill 的**注入接口与筛查器；
  适配器移出为独立 Feature，触发条件是 alphamill M3 产出版本化信号。

### 边界场景

- 冷启动第一分钟没有任何历史成交：策略族必须有确定性的锚，不得靠随机数硬凑第一笔。
- 某策略族在某次装配中全员触发风控或强平退出：市场必须继续运行，并在质量报告里
  记录该族的退出，不得静默变成更少的族。
- 外部信号源中断或返回非法信号：该量化交易者族降级为不动作，不得阻塞内核推进，
  也不得伪造信号。
- stylized facts 未达门限：必须如实产出未通过报告，不得调门限就宣称通过；
  门限修改须留 git 痕迹与理由。

## 4. 需求

### 功能需求

### Requirement: 消除冷启动死锁（`FR-501`）

- **FR-501**：系统应使代理在零成交、零公开成交流的市场中仍能产生首笔委托；
  冷启动锚（预热期内的目标仓位口径、锚定价格来源、退出冷启动的判据）必须是显式的
  冻结参数并记入运行头，不得依赖关闭 EWMA 预热这类副作用；冷启动结束后的行为必须
  与既有 `GoalModel` 语义一致。锚的**来源**是可插拔接口（运行头记录来源标识）：本里程碑
  只实现 `synthetic`（确定性首笔意图，Q-501）；`historical_snapshot`（从实盘某一时点
  分叉）由 [`ADR-014`](../../../decisions/014-historical-snapshot-fork-anchor.md) 承接，
  不在本里程碑实现。

### Requirement: 提供可插拔的 L2 交易者策略层（`FR-502`）

- **FR-502**：系统应提供 `TraderStrategy` 协议与策略族注册表：输入为分级信息集，
  输出为目标仓位或委托意图；新增策略族只需注册，不得修改 L1 撮合、账本、保证金、
  强平与事件 schema；未注册的策略族标识必须 fail closed。

### Requirement: 按清单装配并运行异质策略族市场（`FR-503`）

- **FR-503**：系统应按策略族装配清单构建市场（族标识、数量、参数、时间尺度），
  运行纯 AI 生态并逐逻辑秒记录价格与盘口；同一清单与同一种子必须产生逐点一致的
  价格序列；装配清单必须随运行 artifact 一并落盘。

### Requirement: 量化交易者族与单向边界（`FR-504`）

- **FR-504**：系统应支持以外部信号驱动的量化交易者族（Alpha101 纯时序子集与
  alphamill 产出），其委托走与其他策略族完全相同的撮合、账本与风控路径；含横截面
  算子、行业或市值输入的公式必须在装配时被拒绝并给出稳定原因码；所有相关 artifact
  必须携带「不得用作策略有效性证据、不回流 alphamill 证据链」的边界声明。

### Requirement: 市场真实性判据与门（`FR-505`）

- **FR-505**：系统应对一次纯 AI 市场运行计算市场质量指标与 stylized facts 指标，
  并按冻结门限判定通过/未通过；未通过时必须输出未通过项与实测值，不得省略或
  只报告通过项；门限值与计算口径由本 spec §6 唯一拥有。

### 数据 / 实体需求

- **DR-501**：`StrategyRoster`（策略族装配清单）应记录 `roster_id`、种子、各族的
  族标识/数量/参数/时间尺度、冷启动锚参数与引擎配置指纹，并可由 `roster_id` 重建装配。
- **DR-502**：`MarketQualityReport` 应记录运行标识、逻辑时长、市场质量六项与
  stylized facts 五项的实测值、所用门限、逐项通过判定与内容哈希；未通过项必须在
  报告顶层可见。

### 事件 / Trace 需求

- **TR-501**：策略族产生的每笔委托应通过 `intent_id`、`decision_event_id` 连入既有
  因果链，并可从决策记录回溯到策略族标识与该族的信息集分级；外部信号驱动的决策
  必须额外记录信号来源标识与版本，不得与内生决策混淆。

### API / 接口需求

- **IR-501**：`TraderStrategy` 协议应声明稳定的输入（分级信息集）与输出（目标仓位
  或委托意图）契约，并提供注册/查询入口；协议变更必须升级版本号。
- **IR-502**：外部策略信号注入接口应支持限价与市价意图、非阻塞推进与信号版本号；
  信号缺失、超时或非法时返回稳定原因码并降级为不动作，不得阻塞内核。

### 非功能需求

- **NFR-501**：纯 AI 市场必须能以 1:1 实时运行——在目标环境下墙钟耗时不超过
  0.5 秒/逻辑秒（实测基线：当前 40 交易者装配为 4–5 秒/逻辑秒）。
- **NFR-502**：同装配清单、同种子、无外部介入时价格序列逐点可复现；策略族装配与
  冷启动锚参数必须进入运行头，使重放可判定。
- **NFR-503**：本里程碑产出一律为 `engineering-demonstration`，不进入任何 evidence
  index，不产生研究声明；沙盘结果不得出现在 alphamill 证据链中。

## 5. 生命周期与不变量

```text
DEADLOCKED      -> BOOTSTRAPPED   冷启动锚落地，零成交市场可产生首笔委托
BOOTSTRAPPED    -> LAYERED        TraderStrategy 协议与注册表可用，既有行为无回归
LAYERED         -> ASSEMBLED      异质策略族清单可装配并运行，同种子可复现
ASSEMBLED       -> QUALIFIED      市场质量六项达标且 stylized facts 达到冻结条数
QUALIFIED       -> QUANT_WIRED    量化交易者族接入，单向边界声明随 artifact 落盘
ASSEMBLED       -> UNQUALIFIED    质量门未通过：产出未通过报告，不得改门限充数
```

不变量：

- L1 合同不可变：本里程碑不得修改撮合、账本、保证金、强平与事件 schema 的既有语义；
  策略族只能通过 L2 接口影响市场。
- 冷启动锚是冻结参数，任何改动必须留 git 痕迹与理由；不得以关闭预热等副作用替代。
- 未注册的策略族标识、含横截面算子/行业/市值输入的公式，一律 fail closed。
- 同装配清单 + 同种子 + 无外部介入 ⇒ 价格序列逐点一致；外部信号源必须带版本号，
  否则该次运行不得声称可复现。
- 质量门未通过时只能产出未通过报告；门限值修改与「把未通过说成通过」在审计上是
  两件不同的事，前者必须显式、后者禁止。
- 沙盘结果永不进入 alphamill 证据链，也不构成任何策略有效性的证据（ADR-011 §决策 5）。

## 6. 成功与验收

### 成功标准

- **SC-501**：纯 AI 市场在冷启动后自发成交，市场质量六项全部达标——成交 ≥30 笔/分钟、
  双边盘口可用时间 ≥99%、中位盘口档位 ≥5 档/边、中位有效价差 ≤20 bp、
  成交/委托比 ≥0.001、墙钟 ≤0.5 秒/逻辑秒。
  **「全部达标」的判定点是成果门 `H2-E2` 及之后**：价格发现来自策略族异质而非代理数
  （[`ADR-011`](../../../decisions/011-market-engine-trader-layering.md) §决策 3），
  而异质策略族在 Phase 2 才实现，因此 Phase 1 的 `H2-E1` 只要求六项**逐项如实判定并
  输出未通过项**（见退出条件 E6、tasks `T967`），不得据此判 Phase 1 失败，也不得为让
  Phase 1「达标」而调低门限。
- **SC-502**：stylized facts 五项中至少 **3 项**达标。**判定口径不在本 spec 重新定义**：
  前三项直接引用已冻结的 [`0.1.2 基准市场验证协议`](../../../experiments/0.1.2-market-validation-protocol.md)
  与其实现 `src/market_game_sim/metrics/validation.py`（`build_market_validation_matrix`），
  连同该协议 §2 的采样口径（指标字典 §2，Δt = MD-001）、最低样本量 `n >= 2000`、
  前值填充比例 > 30% 判不适用、α = 0.05 与 Holm-Bonferroni 家族校正一并沿用；
  本里程碑只新增协议未覆盖的两项，并按同一检验规格书写：

  | # | 特征 | 判定口径拥有者 |
  |---|---|---|
  | 1 | 收益厚尾：**超额峰度** `k = m4/m2² − 3`，`z = k / sqrt(24/n)` 单侧检验，`p < 0.05` 且 `k > 0` 判通过 | 0.1.2 协议 §3.1（本 spec 不复制阈值） |
  | 2 | 收益 `r` 无显著线性自相关：lag 1–5 组 B 家族校正后均不显著 | 0.1.2 协议 §3.2 |
  | 3 | 波动聚集：`\|r\|` 的 ACF 在 lag 1 显著为正；本里程碑按同一标准误 `1/sqrt(n)` 与同一单侧检验**延伸到 lag 50**。组合判据（Q-505，owner 2026-09-21）：**lag 1 与 lag 50 都显著为正**才判通过，本项进入组 A 的 p 值取 `max(p_lag1, p_lag50)`（交并检验，家族成员数不变、无需额外校正） | 0.1.2 协议 §3.3；本 spec 只拥有「延伸滞后阶数 = 50」与上述组合规则 |
  | 4 | 成交量—波动正相关（协议未覆盖，新增）：滚动已实现波动率（MD-002，`W = 30`）与同时刻成交量的 Pearson `r`，`t = r·sqrt(n−2)/sqrt(1−r²)`，单侧 `H0: r <= 0` | 本 spec |
  | 5 | 订单流长记忆（协议未覆盖，新增）：委托方向序列（买 `+1` / 卖 `−1`）的 ACF 在 lag 1—100 全程为正，且 `ln(ACF)` 对 `ln(lag)` 的 OLS 斜率显著为负（幂律衰减） | 本 spec |

  新增两项与被引用的三项在**同一次运行**上按协议 §2 的分组规则处理：「拒绝 H0 即通过」
  的项（1、3、4、5）并入组 A 家族校正，第 2 项仍按组 B 在其 5 个滞后阶数内单独校正；
  复用 `experiment/stats.py::holm_bonferroni`，不新发明第二套校正算法。

  **本里程碑的组 A 与 KPI-005 的组 A 不是同一个集合，两处的校正后 p 值不可直接比较。**
  0.1.2 协议的组 A 是 {厚尾、波动聚集、价格冲击非线性、点差-波动率相关}
  （实现：`metrics/validation.py::_FAMILY_A`），本里程碑的组 A 是 {特征 1、3、4、5}——
  成员数相同但集合不同，而 Holm-Bonferroni 的校正强度取决于家族内全部成员的 p 值分布，
  因此**同一项特征在两处可能得到不同判定**；跨处引用对方的判定结果无效。
  实现约束：**不得把新增两项并入 `build_market_validation_matrix` 既有的家族实例**——
  那会静默改变已冻结协议对 KPI-005 的判定（协议 §4 明确禁止回头改判定）。本里程碑
  另建自己的家族实例，只复用 `holm_bonferroni` 原语。

  **「收益峰度 > 3」的旧写法已删除**：正态总体的样本峰度约有半数超过 3，不做显著性
  检验时 AC-505 要求的「独立正态序列判未通过」在数学上不可满足，等于开工即注定
  「为了让对照序列判失败而回头改判据」——这正是 SC-503 与 §5 不变量禁止的动作。
- **SC-503**：**内生不稳定事件的存在性判定**。无人类介入时跨种子运行，如实判定是否
  出现 ≥3% 的分钟级跳动或强平连锁（`chain_depth ≥ 1`）。**两个方向都算达标**：出现即
  记录其触发条件与频次；未出现则结论是「该市场结构在冻结参数下不产生离散崩盘事件」，
  这是一个如实的研究发现，不是工程失败。**禁止为制造「出现」而调低阈值或注入冲击**；
  阈值改动必须留 git 痕迹与理由。
  背景：v0.1 的 `0.1.5-evidence-index.json` 中两个目标模型 × 三个处理对比 × 两个结果
  家族的全部 `occurrence` 假设 `nonzero_block_counts` 均为 **0 / 128 blocks**——离散
  崩盘事件在现有代理构成下从未出现过，因此本条在开工时是开放问题。
- **SC-504**：量化交易者族可按清单装配并运行，其委托因果链可回溯到族标识与信号版本；
  被拒绝的公式（含 `rank`/`IndNeutralize`/`cap`）给出稳定原因码。

## 8. 待确认问题

- [x] Q-501: 冷启动锚的具体形态与冻结参数？— 决策（owner 2026-09-21）：本里程碑实现`synthetic` 锚——预热期内每个交易者持有 ±1 个最小数量单位的目标仓位，方向**不用随机数**，按装配清单中的顺序奇偶交替（偶数位买、奇数位卖，保证两侧都有首单），按对手方最优价下单以保证成交，对手方为空时以运行头中的初始价挂限价单（奇偶交替保证买卖两侧在同一价位相遇）；**退出判据复用既有预热条件**（样本数 ≥ `2 × 半衰期`），不新增退出参数；锚参数（量、定价规则、来源标识）进入运行头。市场质量与 stylized facts 的统计窗口从**最后一个代理退出冷启动**之后开始，预热期成交不进入指标；运行结束仍有代理未退出冷启动时，该运行的质量报告判「不适用」并在顶层可见，不得截断窗口或剔除该代理来凑出窗口。锚来源做成可插拔接口；owner 提出的「从实盘某一时点盘面分叉」方案（`historical_snapshot`）方向批准，但需要行情数据、越出本里程碑「不依赖外部行情源」的边界，且快照挂单在 L1b 中没有账户归属，故由[`ADR-014`](../../../decisions/014-historical-snapshot-fork-anchor.md) 与独立里程碑承接（tasks §5 明确后移）。
