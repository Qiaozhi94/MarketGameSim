## 1. 问题、目标与非目标

### 问题

北极星把「owner 亲身参与、看自己的操作会给市场带来什么」列为**第一**研究问题，
但它此前没有任何里程碑承接：PRD 只有一行「H2-F 待立项」，0.4.1 明确把人类扰动
实验排除在范围外。两个具体风险因此长期敞口：

1. **数据格式未冻结**：owner 一旦开始自由游玩，前若干场的会话记录如果没有冻结格式，
   事后无法与 AI 基线配对，等于白玩。归档的 N-of-1 轨已经付过一次这种代价。
2. **命题形态未定**：「人类能否造成崩盘」在允许高杠杆与大单量的市场里是**自我实现**
   的——只要资金够、杠杆够，答案必然是「能」，这不构成发现，也不可证伪
   （PRD §13.5）。北极星的「扰动即数据、不存在错误用法」是**设计判据**，不是研究命题；
   两者之间缺一条桥接条款。

### 目标

1. 在 owner 第一场自由会话之前**冻结**会话 artifact 格式，使每一场都可重放、可配对。
2. 提供同种子对照运行能力：无人类基线 vs 有人类 × N 次重复，共享装配清单与种子。
3. 把研究命题写成**效应量命题**：报告稳定性指标集合的分布移动、不确定性区间与
   失效边界，而不是「是否发生过一次崩盘」。
4. 保证「扰动即数据」：不判定操作对错、不产出 owner 个人画像。

### 非目标

- 不做 owner 个人画像、不产出「owner 是什么样的交易者」的结论（北极星 §4）。
- 不设固定场次、固定跨度或每窗一次动作的受控框架（北极星 §4；该框架已随 ADR-010 归档）。
- 不修改 L1 既有合同，也不修改 0.4.1 已冻结的市场质量与 stylized facts 口径。
- 不把 owner 会话数据并入 0.3.1 的 AI 研究声明或任何既有 evidence index。
- 不在本里程碑建立研究声明：证据级别为 `experiment-preview`，是否升级见 Q-601。

## 2. 用户场景

### US-601：自由进出市场并留下可分析的记录（Priority: P1）

作为项目所有者，我希望随时进出一个持续运行的 AI 市场并自由下单，同时我的每一步都被
完整记录下来，以便事后分析我的参与对市场做了什么。

**为什么是这个优先级**：这是 owner 亲身参与项目的核心动机；记录格式没冻结，参与本身
就产生不了数据。

**独立测试**：一场自由会话结束后，仅凭落盘的会话 artifact 即可重建 owner 的动作序列与
对应的市场时点，内容哈希稳定。

**验收场景**：

1. Given 一场自由会话，when 会话结束，then artifact 记录逐条动作、时间戳、市场标识、
   种子与观察快照指纹，且可重放。
2. Given 同一份 artifact，when 重新解析，then 内容哈希与动作序列逐条一致。

### US-602：比较有没有人类时的市场稳定性（Priority: P1）

作为项目所有者，我希望把「有我参与」的运行与「同种子、无人类」的基线运行放在一起比较，
以便看到我的介入把稳定性指标推动了多少，而不是只看一次运行的截图。

**为什么是这个优先级**：没有同种子对照，任何「人类让市场更不稳定」的说法都无法与
市场自身的随机波动区分。

**独立测试**：用固定的回放动作序列驱动「有人类」臂，与同种子的无人类基线配对，断言
报告输出三个稳定性指标的分布移动与区间，且基线臂逐点可复现。

**验收场景**：

1. Given 同一装配清单与同一种子，when 分别运行无人类基线与回放的有人类臂，then 两臂
   的指标可配对比较，基线臂逐点可复现。
2. Given 一组配对运行，when 生成报告，then 报告给出效应量、不确定性区间与失效边界，
   不给出「人类能否造成崩盘」的是非结论。

## 3. 范围与边界

### 范围内

- owner 自由会话 artifact 的**冻结格式**与其机器校验入口。
- 同种子对照运行：无人类基线臂与有人类臂共享 `StrategyRoster`、种子与引擎配置指纹。
- 会话动作序列的确定性回放（使有人类臂可在无人值守时重跑）。
- 稳定性指标集合与效应量报告：最大回撤、大波动频次、盘口可用率。
- owner 委托在事件因果链上的参与者类别标识（与 AI 委托同路径、可区分）。

### 范围外

- L1 既有合同的任何修改；0.4.1 的质量门限与 stylized facts 口径的任何修改。
- owner 个人画像、操作对错判定、固定场次/跨度/节奏的受控框架。
- Web 终端的界面重做（沿用 0.3.2 终端与 0.4.1 的 live 市场载体）。
- 把 owner 数据并入 AI 研究声明或任何既有 evidence index。
- 研究声明本身：本里程碑交付协议、载体与预览报告；升级为 `formal-research` 须先闭合 Q-601。

### 边界场景

- owner 中途离开或断线：会话 artifact 必须落盘为**完整的短会话**，不得丢失已发生的动作。
- owner 执行极端操作（满杠杆、单边扫单）：照常记录，不拦截、不判错——扰动即数据。
- 有人类臂回放时动作序列与基线时钟对不齐：判失败并给稳定原因码，不得静默丢弃动作。
- 指标在某臂上退化（如全程零成交）：如实报告退化，不得用退化臂算出效应量
  （`effect = 0.0 / CI = [0,0]` 全表出现属零功效，不是零结果）。

## 4. 需求

### 功能需求

### Requirement: 冻结 owner 自由会话 artifact 格式（`FR-601`）

- **FR-601**：系统应在 owner 第一场自由会话之前冻结会话 artifact 格式，记录会话标识、
  `roster_id`、种子、引擎配置指纹、逐条动作与逻辑/墙钟时间戳、观察快照指纹与内容哈希；
  格式变更必须升版本号并留 git 痕迹，不得就地改写已落盘会话的语义。

### Requirement: 同种子对照运行（`FR-602`）

- **FR-602**：系统应支持在同一装配清单与同一种子下运行「无人类基线」与「有人类」两臂，
  并按配对关系组织结果；基线臂在无人类介入时必须逐点可复现。

### Requirement: 稳定性效应量报告（`FR-603`）

- **FR-603**：系统应对一组配对运行输出稳定性指标（最大回撤、大波动频次、盘口可用率）
  的分布移动、不确定性区间与失效边界；报告不得以「是否出现过崩盘」作为结论形态，
  也不得在任一臂退化时输出效应量。

### Requirement: 扰动即数据（`FR-604`）

- **FR-604**：系统不得对 owner 的操作做对错判定或行为画像；会话 artifact 与报告中
  不得出现「错误用法」「违规操作」一类判定字段，也不得包含直接身份信息。

### 数据 / 实体需求

- **DR-601**：`PerturbationSession` 应记录会话标识、臂标识（`baseline` / `human`）、
  `roster_id`、种子、动作序列、观察快照指纹与内容哈希，并可由会话标识重放。
- **DR-602**：`PerturbationEffectReport` 应记录配对集合、每个指标的两臂分布、效应量、
  不确定性区间、失效边界与退化判定；退化时效应量字段必须缺省而不是填 0。

### 事件 / Trace 需求

- **TR-601**：owner 委托应走与 AI 委托完全相同的撮合、账本与风控路径，并在既有决策
  记录中携带参与者类别标识，使事件链可区分人类与 AI 来源，而不新增事件类型。

### API / 接口需求

- **IR-601**：人类参与入口应沿用 0.3.2 终端与 0.4.1 的非阻塞注入路径，不新增内核接口；
  会话回放入口接受冻结格式的动作序列并按逻辑时点重放。

### 非功能需求

- **NFR-601**：人类在场不得改变 L1 语义与 AI 侧确定性；无人类基线运行在同种子下逐点可复现。
- **NFR-602**：会话 artifact 与报告不含直接身份信息，不进入任何既有 evidence index，
  也不与 0.3.1 的 AI 研究声明合并统计。

## 5. 生命周期与不变量

```text
UNSCHEDULED   -> FORMAT_FROZEN   会话 artifact 格式冻结并有机器校验入口
FORMAT_FROZEN -> BASELINE_READY  无人类基线臂可在同种子下逐点复现
BASELINE_READY-> PAIRED          有人类臂可回放并与基线配对
PAIRED        -> REPORTED        效应量报告产出（含区间与失效边界）
PAIRED        -> DEGENERATE      任一臂退化：如实报告退化，不输出效应量
```

不变量：

- 会话 artifact 格式一经冻结，变更须升版本号并留 git 痕迹；已落盘会话不被改写。
- 「扰动即数据」：不判定 owner 操作对错，不产出个人画像。
- 研究命题是效应量命题，不是存在性问题；「人类能否造成崩盘」不作为结论形态。
- 退化臂不得产出效应量：`effect = 0.0 / CI = [0,0] / p = 1.0` 全表出现是零功效证据。
- owner 数据永不并入 AI 研究声明与既有 evidence index。

## 6. 成功与验收

### 成功标准

- **SC-601**：会话 artifact 格式在第一场自由会话之前冻结，任一场会话仅凭 artifact 即可
  重放动作序列，内容哈希稳定。
- **SC-602**：同装配清单、同种子下，无人类基线臂逐点可复现；有人类臂可由冻结的动作
  序列重放并与基线配对。
- **SC-603**：报告以效应量形态给出结论——三个稳定性指标（最大回撤、大波动频次、
  盘口可用率）的分布移动 + 不确定性区间 + 失效边界；任一臂退化时输出退化判定而非效应量。
- **SC-604**：artifact 与报告不含对错判定、行为画像字段与直接身份信息。

### 退出条件

| 退出 | 条件 | 证据 |
|---|---|---|
| E1 | 会话 artifact 格式与机器校验入口冻结，格式版本号与内容哈希就位 | 冻结格式文档 + validator 通过记录 |
| E2 | 无人类基线臂在同种子下逐点可复现，owner 委托的参与者类别标识进入事件链 | 基线复现测试 + 因果链测试 |
| E3 | 有人类臂可回放并与基线配对，配对集合可重建 | 配对运行 artifact |
| E4 | 效应量报告产出（分布移动 + 区间 + 失效边界），退化路径如实输出退化判定 | 效应量报告 + 退化用例 |

### 验收清单

- [ ] **AC-601** (`FR-601`, `DR-601`, `SC-601`, `E1`): 会话 artifact 按冻结格式落盘并可重放；
      缺字段/错版本号的 artifact 被校验入口拒绝（正反两侧都有断言）。
- [ ] **AC-602** (`FR-601`, `US-601`): 短会话（owner 中途离开/断线）仍产出完整 artifact，
      已发生的动作一条不丢；空会话与多动作会话两种场景都有用例。
- [ ] **AC-603** (`FR-602`, `NFR-601`, `SC-602`, `E2`): 同装配同种子的无人类基线逐点可复现；
      有人类臂的动作回放与基线时钟对齐，不对齐时给稳定原因码而不是静默丢弃。
- [ ] **AC-604** (`TR-601`, `IR-601`, `US-602`, `E3`): owner 委托走既有撮合/账本/风控路径并
      带参与者类别标识；人类与 AI 委托并存的批量场景有专门用例。
- [ ] **AC-605** (`FR-603`, `DR-602`, `SC-603`, `E4`): 效应量报告输出三指标的分布移动、区间与
      失效边界；有效对照与退化对照两种输入都有断言，退化时效应量字段缺省。
- [ ] **AC-606** (`FR-604`, `SC-604`, `NFR-602`): artifact 与报告不含对错判定/画像字段与直接
      身份信息；含此类字段的产物被校验入口拒绝。
- [ ] **AC-607** (`NFR-602`): owner 会话产物不进入任何既有 evidence index，也不与 0.3.1 的 AI
      研究声明合并；尝试并入时门禁拒绝。

## 7. 测试、依赖与决策

### 测试策略

- 单元测试：artifact 格式校验（字段缺失、版本号不匹配、含画像字段）的正反用例；
  效应量估计在构造输入上的数值口径；退化输入的判定。
- 集成测试：同种子基线复现、动作序列回放与配对、人类与 AI 委托并存的批量因果链、
  产物不进入 evidence index 的守卫。
- 真实环境 / 手动验证：owner 在 loopback 终端上完成一场自由会话，导出 artifact 并重放。
- 既有回归：0.4.1 的市场质量门、0.3.1 配对轨与 0.3.2 终端测试必须全绿。

### 依赖

- 上游 Feature / Contract：`0.4.1`（live 市场载体、`StrategyRoster`、质量指标）、
  `0.3.2` Web 终端与 owner 会话审计链、v0.1 事件 schema 与确定性口径。
- 下游消费者：北极星研究问题 #3（人机流动相互作用）复用同一套会话数据。
- 外部 / 环境依赖：无外部网络、行情源或第三方服务。

### 决策与风险

| 决策 / 风险 | 结论或缓解 | 理由 | 后续 |
|---|---|---|---|
| 研究命题形态 | 效应量命题（分布移动 + 区间 + 失效边界），不是「人类能否造成崩盘」 | 后者在允许高杠杆大单量时自我实现，不可证伪（PRD §13.5、§15 桥接条款） | 不变量已锁 |
| artifact 格式冻结时点 | **第一场自由会话之前**，不允许「先玩起来再补格式」 | 归档的 N-of-1 轨已经付过一次「前若干场数据不可用」的代价 | E1 / Phase 1 |
| 证据级别 | 本里程碑为 `experiment-preview`，不建立研究声明 | owner 会话是样本量 1、有学习效应的运行，SOP §2 禁止其进入统计 | Q-601 |
| 「扰动即数据」与可证伪的关系 | 前者是设计判据（不拦截、不判错），后者是结论纪律（命题必须可被数据否定），两者不冲突 | 北极星 §3 只规定 owner 侧体验，不规定结论形态 | PRD §15 桥接条款唯一拥有 |
| 与 0.3.1 配对协议的关系 | 不复活固定场次/跨度框架；只复用其配对**统计**口径 | owner 2026-09-19 裁决固定节奏与连续市场假设冲突 | 归档轨保持归档 |

## 8. 待确认问题

- [ ] Q-601: 本里程碑最终证据级别——同种子对照 + 动作回放成立后，`experiment-preview` 是否可升级为 `formal-research`？须先回答 SOP §2「交互运行不进统计」的适用边界：分析单元是市场运行（seed）还是人？升级前不得声明任何研究结论。
- [ ] Q-602: 三个稳定性指标（最大回撤、大波动频次、盘口可用率）各取 0.4.1 已冻结的哪一版计算口径，窗口与分位数如何定？
- [ ] Q-603: 每个配对需要多少次重复（N）才有可接受的功效，功效分析在哪一步做？
- [ ] Q-604: owner 单场会话不可重复，重放臂与原场若有差异如何处置——只报原场，还是报重放臂并声明差异？
