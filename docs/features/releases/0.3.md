# v0.3：AI Mechanism Baseline & Web Trading Terminal 签收记录

v0.3 于 2026-09-20 签收。版本根、`0.3.1`（AI 正式机制基线）与 `0.3.2`（Web 交易终端）
均为 `done`。研究声明**只挂在 AI 轨**：`0.3.1` 的 `research_claim_status` 为
`established`，证据级别 `formal-research`。

## 签收范围

- **0.3.1 AI 正式机制基线**：168 个 paired-seed block 的冻结协议、三个独立结果家族、
  预注册机制指标与可重建的 AI evidence index。
- **0.3.2 Web 交易终端**：loopback 真实终端形态页面（报价、盘口、最近成交、多周期
  K 线、本人账户）、市价/限价委托与撤单、preview fail-closed 门控、逻辑时点采样与
  owner 主动/技术中止的审计链。

## 不在签收范围（范围裁决，非未达标）

`0.3.2` 的 **N-of-1 采集轨**——6 个训练场景、24 个正式场景、owner evidence index、
个人描述性报告——随 [`ADR-010`](../../decisions/010-market-ecology-research-pivot.md)
整体归档。owner 2026-09-19 裁决：固定场次、固定跨度、每窗一次动作的受控框架与
「模拟一个正常市场」的研究意图冲突，该轨不再执行。

后果与处置：

- `SC-403`、`SC-404` 在 [`traceability.json`](../0.3/traceability.json) 中状态为 `removed`；
- 退出条件 `E3`、`E4` 与验收项 `AC-407`、`AC-408` 一并移除；`AC-407` 中仍然有效的
  「artifact 不含直接身份信息」并入 `AC-404`；
- 原 Phase 2 的 `T937`、`T939`—`T944`、`T946` 从任务清单移除，**不伪造勾选**；
- 协议、assignment、session guard 机械与其测试**保留在仓库**，受控对照类研究问题
  出现时可复活，届时须先修订研究北极星与配对协议。

## 研究边界

`0.3.1` 的结论限定为冻结 AI 策略在 paired-seed 分布上的差异，不外推到真实市场，
不构成交易信号。`0.3.2` 的自由模拟会话**永不进入任何实验证据索引**，owner session
不进入 AI 研究声明。本版本不连接交易所、券商、钱包、真实账户或资金。
