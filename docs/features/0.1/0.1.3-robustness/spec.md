**父规格**：[`../spec.md`](../spec.md)　**架构**：[`../design.md`](../design.md)  
**前置**：0.1.2 全部退出条件达成

## 1. 目标

证明旗舰结论**不是实现的性质，而是市场的性质**——它不依赖单一行为映射、单一参数
点或单一模型族。

方法论 §10.5 与检视报告反复强调的同一件事：只在一种设定下成立的结论，说明的是设定
本身。

## 2. 范围

| 项 | 内容 |
|---|---|
| **替代行为映射** | 至少替换代理策略 §12 已知局限中的一项（如阈值型仓位映射替代线性映射、自适应标准化替代固定尺度） |
| **模型族扫描** | 至少两个预注册模型族（差异边界定义见任务 T006），验证旗舰结论不依赖单一模型族 |
| **参数空间扫描** | 杠杆上限分布、`maint_bp`、做市商厚度作为扫描维度（A-005） |
| **因子消融** | 逐个移除因子，观察哪些是崩盘的必要成分 |
| **共同随机输入** | 配对对照使用相同随机冲击路径，区分「相同种子」与「相同路径」 |
| **留出验证区** | 在校准时未使用的参数区域复核结论 |

## 3. 退出条件

| # | 条件 |
|---|---|
| E1 | 旗舰结论在**至少两种行为映射 × 至少两个预注册模型族**的交叉对照下同向成立，或明确报告映射/模型族主效应、交互或依赖边界 |
| E2 | 效应量随参数变化的趋势可报告，失效边界已定位 |
| E3 | 因子消融结果表明崩盘机制的必要成分 |
| E4 | 冻结留出区已按预注册计划一次性执行；复核结果（通过、方向反转或证据不足）已如实报告，且无数据污染或未披露重跑 |
| E5 | KPI-009 达标；0.1.3 不研究资金/信息/速度/执行四个能力维度的归因（该范围移至后续里程碑单独排期），报告中出现的任何能力归因必须为空集，或由既有、明确版本的单维度配对证据支持——不得空集真值默认通过 |

E4 的措辞刻意不要求"通过"：§4 明确"留出区不复现"本身是有效的负结果，若 E4
字面要求复核通过，会与该原则自相矛盾，并反向激励选择性报告。E4 验收的是**过程
可信**（预注册、一次性执行、如实报告、无污染），不是**结果符合预期**。

## 4. 可能的负面结论及其价值

以下结果都是**有效产出**，不是失败：

- 崩盘只在极窄参数区间出现 → 说明该机制脆弱，需要很强的前提；
- 替代行为映射下效应消失 → 说明结论依赖于特定行为假设，这本身是重要发现；
- 无杠杆对照组同样崩盘 → **否定旗舰假设**，杠杆不是必要条件。

第三种情形直接否定了项目的初始预期，但它正是预注册要保护的东西——PRD §13.1 的
「不预设庄家」与此同理。
