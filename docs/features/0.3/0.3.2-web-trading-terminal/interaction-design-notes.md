# 0.3.2 Web 交易终端 · 交互设计说明（开发向）

> 本文档承载 [`interaction-design.html`](interaction-design.html)（最终交付版设计稿）中的
> 全部开发向解释内容。设计稿本身只保留用户面必要解释；本文件与其余开发说明按
> [`design.md`](design.md) §6 归档。状态：Accepted（2026-09-13/14 owner 评审）。

## 1. 定位与决策依据

- 终端形态裁决：**ADR-006 / Q-403**——真实世界时间 + 自由连续交易，实验约束收敛到
  采集模式；AI 正式轨（0.3.1）不受影响。
- 布局基准：**币安现货交易页**（owner 2026-09-14 指定）：买入/卖出为页签 + 单一
  下单按钮，盘口与最近成交左栏堆叠，委托/回报为图表下方全宽面板。
- 产品定位：确定性合成模拟市场（`SIM` 环境角标），对手方为可复现 AI 代理（做市商、
  因子策略、噪声/情绪交易者）；自由模拟为 `engineering-demonstration`，采集模式为
  `experiment-preview`（个人描述性，不进研究统计）。

## 2. 真实终端对齐审查（逐项处置，已完成）

| 元素（v2 及以前） | 为什么曾存在 | 处置 |
|---|---|---|
| 8 秒提交倒计时 / 决策窗口 | 采集协议"决策机会匹配"合同（Q-303） | **彻底删除（含采集模式）**：自由连续交易 + 服务端逻辑时点静默采样，采样不约束用户节奏 |
| "本时点不操作"按钮 | 协议显式 NO_ACTION | **删除**：不操作就是不点按钮；采样在服务端完成 |
| 每时点一次的锁定态 / 迟到 / 重复错误 | 一次性动作槽 | **删除**；委托幂等由服务端 `client_request_id` 保证 |
| 阶段徽标 preview/training/formal | UX-403 | 改为 **SIM 环境角标**（对齐交易所测试网标记习惯）；阶段信息只在采集模式出现 |
| 信息边界 / 解盲清单卡片 | FR-403 | 移入采集模式；自由模式只有「ⓘ 市场说明」 |
| 门禁阻断 / 每日强制休息 / 结果盲完成页 | E2 gate、Q-303、SC-404 | 全部归入采集模式（评审模式状态组保留检视） |
| 中止会话 + OWNER_ABORT 原因枚举 | 实验中止审计 | 自由模式弱化为普通「退出」；带原因的中止只在采集模式 |
| 单笔上限 1.000 / 挂单上限 8 | 合同限额 | **保留**：真实交易所也有下单量与频率限制 |
| 杠杆选择缺失（v4.0 遗漏） | 内核 0.1.2 起就有全仓杠杆/强平路径；H1 合同把演示参数冻结为 1×/100% 保证金率，设计稿漏了入口 | **已补**：资产页与下单面板均可调杠杆 1–10×（全仓）；采集模式由协议冻结 |
| 初始资金固定 10,000 | H1 合同演示参数 | **已补**：资产页可设初始资金、模拟入金、一键重置；采集模式由协议冻结 |
| 下单只有 PERP 数量 | v3 起数量输入默认币本位 | **已补**：下单面板支持 PERP 数量 / USDT 金额两种单位，自动换算并显示市值与占用保证金 |

## 3. 布局（币安现货版式）与标注对照

三段式：顶部导航 + 行情 ticker；左栏盘口（上）与最近成交（下）堆叠；中栏图表 +
底部全宽「当前委托 / 操作回报」；右栏现货式下单面板（买入/卖出页签 → 限价/市价 →
价格/数量 → 百分比滑杆 → 成交额与占用保证金 → 单一下单按钮）。

**合约页（2026-09-14 补全）**：与交易页共用同一交易终端（图表/盘口/下单），并在下方
注入实况「资产与仓位」卡与「杠杆 1–10×」卡，其后为合约规格与市场机制说明卡——
对齐币安合约页"交易 + 账户 + 合约信息"的信息结构；交易页则是同一市场的现货式简易入口。
导航含 交易/行情/合约/资产 五个用户入口（研究页已移除）。

| # | 区域 | 关键交互 |
|---|---|---|
| 1 | 盘口 | 累计深度 + 买卖比条；观察集 k≤10 档（渲染 8 档）；点档位填入限价；无报价空态不造假（FR-401） |
| 2 | 图表 | 多周期（1m—1D）、MA(7/25/99)、十字光标（价格/时间轴标签）、最新价标签、成交量、水印；最新 K 线实时更新（收口后才入 artifact） |
| 3 | 下单面板 | 买入/卖出页签、限价/市价页签、价格快捷（最后价/卖一/买一）、数量 PERP/USDT 双单位换算、百分比滑杆、成交额与预估占用保证金、单一下单按钮 |
| 4 | 底部面板 | 当前委托（逐笔撤单）与操作回报页签；回报流转 委托中→已成交/已撤单/已拒绝；点行展开服务端回执 |
| 5 | 资产页 | 初始资金设置、模拟入金、杠杆 1–10×、总览（权益/可用/未实现/仓位/保证金比率/预估强平价） |
| 6 | 合约页 | 合约规格与市场机制（内核映射：撮合/账本/保证金/强平/时间模型/K 线派生） |

## 4. 两种形态

| | 自由模拟终端（默认） | 采集模式（正式 N-of-1） |
|---|---|---|
| 交易节奏 | 自由连续交易，限价可挂 | 同样自由交易；服务端按冻结粒度做时点采样（ADR-006） |
| 可见性 | 全部自己的账户与市场信息 | 参照策略/种子/未来事件/未解盲结果隐藏（FR-403） |
| 流程约束 | 无 | 阶段门控、每日 6 场节奏（每场为冻结的市场时间跨度）、强制休息、中止裁决 |
| 证据级别 | engineering-demonstration | experiment-preview（个人描述性） |

## 5. 关键交互流

- **市价单**：数量（或 USDT 金额/% 滑杆）→ 下单按钮（印参考价）→ 即时成交 → 回报"已成交"。
- **限价单**：点盘口档位/最后价快捷填价 → 下单 → 穿越盘口即时成交，否则进入「当前委托」；
  价格触及自动成交；或手动撤单 → "已撤单"。
- **拒单**：服务端风控拒绝（如保证金不足）→ 回报红色行 + 可读原因 + 零副作用；
  数量/价格错误在本地预检拦截，不发请求。
- **断线/刷新**：断线遮罩说明"行情不暂停、挂单仍生效"；恢复后从服务端快照重建，
  幂等键保证不重复委托（NFR-402）。
- **退出**：确认后挂单自动撤销并入回报、仓位权益入会话存档；采集模式的退出语义由
  实验协议约束。

## 6. 需求映射（保留项）

| 需求 | 落点 |
|---|---|
| FR-401 / AC-401 | 报价/盘口/K 线/成交来自同一冻结 tape；无报价空态不造假 |
| FR-402 / IR-402 / AC-402 | 市价/限价委托进入既有撮合/账本/风控路径；稳定错误码；回报流转 |
| US-403 / FR-403 / AC-403 | 采集模式门控与结果盲；自由模式 SIM 角标 |
| FR-302 / TR-302 / NFR-402 / AC-405 | 时点采样 + 幂等；刷新/断线不重复委托 |
| UX-401 / UX-402 / UX-404 | 一屏信息、按钮与空态/错误态可读 |
| DR-401 / DR-402 / AC-404 | 回报详情即回执字段；K 线绑定 tape 哈希/周期/压缩比 |
| NFR-401 / NFR-403 | 零依赖单文件原型，原生 loopback、无外部行情/凭据 |

## 7. 待裁决 / 后续项

- **DQ-C**：盘口渲染档位数（观察集 k≤10，现渲染 8 档）——E1 冻结；若深度/K 线被认定为
  新增观察信息，须升级 owner observation/协议版本并让参照策略获得同一信息集。
- **DQ-I 残余**：限价单部分成交语义（原型未演示）留待 T932 定义并补测试。
- **DQ-J**：AI 对手方家族（alphamill `FactorDef` 导入 + 噪声/情绪交易者）——另立 feature
  冻结参与者家族、RNG 语义键与证据隔离；导入时过滤模拟市场不具备的数据列
  （funding/OI/basis 等通道不存在）。
- 资金费率/标记价格当前为演示数值；E1 冻结其口径（内核暂无 funding 结算路径）。
