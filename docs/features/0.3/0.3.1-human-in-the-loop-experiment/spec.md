## 1. 问题、目标与非目标

### 问题

在无外生基本面冲击的合成永续市场中，冻结 AI 决策策略是否会在配对随机路径上改变价格
崩盘、流动性枯竭与强平连锁？当前里程碑只回答 AI 机制问题；所有者个人行为问题留给后续
Web 终端与采集里程碑，不与本里程碑合并或互相阻塞。

Q-308 已裁决：**估计对象是匹配可观测接口与决策窗口后的决策来源差异**，不是“接管 + 换目标
+ 换节奏”的联合处理。当前只冻结可供 0.3.2 复用的接口合同：

- `AI_FORMAL` 轨比较两个冻结策略 `risk_budget_linear_v1` 与 `risk_budget_threshold_v1`。
  它们共享账户、初始状态、信息集、动作空间与窗口调度合同，唯一预定差异是决策策略本身。
  这条轨道是研究声明的**唯一**载体。
- `OWNER_N_OF_1` 的窗口匹配、输入链和隐私边界只作为下游合同记录，本里程碑不执行所有者
  会话，也不生成个人描述性结果。

这种匹配**不声称目标函数对齐**：策略目标函数可精确写出；所有者任务由 0.3.2 另行实现。
因此当前只冻结账户/风险边界、信息集、动作空间与决策机会的可审计比较矩阵。

结论语法：本里程碑只允许表述“在冻结市场模型、参数范围与 seed 分布下，两个指定策略之间的
差异”。所有者个人结论由 0.3.2 单独限定任务、模型族与场景分布，禁止跨里程碑合并样本量或
不确定性。

### 目标

1. 预先冻结 AI 正式轨的假设、估计量、SESOI 与 block 数、排除规则和分析计划，并保留 owner
   接口所需的不可变窗口合同。
2. 在 168 个配对 seed block 上估计两个冻结策略在三个结果家族上的严重程度配对差，
   这是 v0.3 研究声明的唯一来源。
3. 预注册激进订单、流动性撤回和风险减仓指标，解释 AI 观察到的方向与时序。
4. 交付一份可复建、可审计且明确限制的 AI `formal-research` 证据包。

### 非目标

- 不招募、筛选或支付任何外部真人，不使用招募平台。
- 不把项目所有者的一人结果外推为普通交易者、人类总体或真实市场规律。
- 不把同一 AI 模型的多次调用称为多个独立参与者；AI 正式推断单位是配对 seed block。
- 不让所有者轨承担研究声明，不跨轨合并样本量、p 值或置信区间。
- 不施加外生价格、基本面、新闻或订单流冲击。
- 不把三类主要结果压缩成综合崩盘得分，不因显著性选择性报告结果。
- 不把相关的机制指标称作已识别的因果中介；因果中介需要独立操纵或额外假设。
- 不比较人类与代理的裸反应速度，不允许正式运行通过暂停获得无限思考时间。
- 不使用 H1 自由交互、培训、理解检查、pilot 或失败调试运行建立正式结论。
- 不在本里程碑实现或启动所有者 Web 终端、K 线展示、交互按钮、训练或 N-of-1 正式采集。
- 不外推到真实市场，不提供投资建议，不接触真实资金或账户。

## 2. 用户场景

### US-301：执行配对的 AI 正式实验（Priority: P1）

作为研究者，我希望在 168 个配对 seed block 上成对执行两个冻结策略，以便在比较矩阵中标为
“相同”的字段逐项一致、策略 ID/参数与决策输出按预注册差异披露，而不是比较不可比的市场路径。

**为什么是这个优先级**：没有配对反事实和可审计比较矩阵，AI 正式轨的严重程度估计量就没有识别基础。

**独立测试**：对固定协议与种子生成同一 paired block 的两份 AI arm manifest，机器验证比较矩阵中标为“相同”的字段逐
字段一致、标为“不同”的字段完整披露，并拒绝未注册漂移。

**验收场景**：

1. Given 已冻结协议，when 启动正式 block，then 同一 block 内各运行共享配置、种子、初态、
   背景代理、窗口调度与逻辑时长。
2. Given 正式运行请求修改信息权限、窗口或制度参数，when 校验协议，then 会话在写入样本
   前 fail closed。

### US-302：审计 AI 决策来源的行为机制（Priority: P1）

作为研究者，我希望把每次策略决策与盘口、成交、账户和强平因果链连接，以便判断结果差异
是否与预注册行为机制一致。

**为什么是这个优先级**：项目要识别决策来源带来的反馈通道，而不只是报告两组终点均值。

**独立测试**：从决定事件回溯激进成交、撤单/改挂、深度变化、风险减仓和首次强平，并验证
指标只使用决定当时可见及随后发生的数据。

**验收场景**：

1. Given 一次 AI 正式运行，when 生成机制表，then 每个指标能追溯到规范输入和事件 ID。
2. Given 因果链缺失或指标定义未冻结，when 构建正式分析，then 样本被拒绝而非补猜。

### US-303：生成边界清晰的 AI 结论（Priority: P1）

作为审阅者，我希望查看 AI 正式轨的效应量、不确定性、排除项和限制，以便判断数据支持放大、
稳定还是未检出差异。

**为什么是这个优先级**：双侧假设允许任一方向或未检出；报告不能把“没有显著差异”包装成
等效，不能用综合指标隐藏相反方向，也不能让 n=1 的个人结果冒充研究声明。

**独立测试**：从冻结 AI evidence index 重建分析，核对样本流图、配对完整性、三类结果、
机制分析和结论措辞。

**验收场景**：

1. Given 合格 AI 正式样本，when 生成报告，then 三类结果分别呈现配对效应和不确定性。
2. Given 数据不足或区间跨越预注册 SESOI，when 生成结论，then 报告“未建立方向性差异”
   而非声称无效应。

## 3. 范围与边界

### 范围内

- 单品种、合成加密式永续市场；无外生基本面信息或价格冲击。
- `AI_FORMAL` 轨：168 个配对 seed block，每个 block 含同 seed 的 `risk_budget_linear_v1` 与
  `risk_budget_threshold_v1` 两次纯代理运行；正式场景分布必须包含高杠杆 + `maint_bp=1200`
  制度格，否则强平连锁家族没有数据。
- `OWNER_N_OF_1` 轨的窗口、输入和配对字段只保留为 0.3.2 的接口合同；本里程碑不运行所有者
  训练或正式场景。
- 两条策略参照运行必须使用与所有者相同的有限窗口调度器（同窗口长度、每窗至多一个动作、
  超时同样写 `NO_ACTION`），取自 v0.1 已验证的代理家族并随协议预注册，不得为 H2 重新调参，
  也不得在场景间交换身份；其余代理、制度和初始状态冻结。
- 固定 AI 任务说明、信息权限、操作窗口与场景分配；所有者任务与顺序由 0.3.2 单独冻结。
- 价格崩盘、流动性枯竭、强平连锁三个结果家族及预注册机制指标。
- 所有者研究假名、技术故障状态与预注册排除状态。
- `AI_FORMAL` 与 `OWNER_N_OF_1` evidence index 严格隔离，preview 与正式运行隔离，正式分析、报告、代表性回放。

### 范围外

- H1 `interactive` 自由操作数据和事后挑选的演示路径。
- 招募、筛选或支付任何外部真人；招募平台、报酬预算与外部伦理审查材料。
- 多人同时交易、参与者互相通信、排行榜和真钱激励系统。
- 外生新闻、基本面、价格注入或专门构造的压力冲击。
- 股票式制度、多品种、订单流预知、大资金执行算法和策略在线学习。
- 任何人群层面的推断：所有者轨不外推到普通交易者、人类总体或真实市场。

### 边界场景

- 所有者断线、客户端崩溃或运行完整性失败时，按冻结规则标记技术无效；不得根据结果决定
  是否排除，也不得事后补跑同一场景而不留记录。
- 所有者中止参与时，已完成的正式场景按冻结规则保留或排除，决定不得读取结果字段。
- 所有者超时按协议定义的 `NO_ACTION` 处理，不暂停市场，也不由任何人代为决策。
- 配对任一成员缺失时，该 block 不进入对应轨道的配对分析；缺失数量与原因完整报告。
- 若分析发现方向变化，机制指标只能支持“与某行为通道一致”的解释，不能单独证明中介因果。
- 若三个家族方向不一致，逐项报告，不选择最符合故事的一项作为总体结论。
- 若正式场景分布不含高杠杆 + `maint_bp=1200` 制度格，强平连锁家族按“无数据”报告，
  不得用另两个家族的结论替代。

## 4. 需求

> **方向重置已完成**：本节及以下正文已按 `H2-dual-track-contract-v1` 逐项重基线，不再包含
> 旧的多人招募、报酬、平台或人群推断需求。旧合同只保留在 `docs/experiments/` 下标记
> `SUPERSEDED_*` 的证据文件中，供变更审计使用。

### 功能需求

### Requirement: 冻结 H2 协议与配对反事实（`FR-301`）

系统应在首个正式样本前冻结并内容寻址：研究问题、双侧假设、AI_FORMAL 的估计量、三个
结果家族、机制指标、每个家族的 SESOI 与 block 数、两个策略实例、场景与顺序分配、排除/
缺失规则、分析方法和结论语法，并记录供 OWNER_N_OF_1 复用的窗口与输入合同。协议还必须
冻结 AI_FORMAL 两个策略的比较矩阵：逐项声明账户/风险边界、信息集、动作空间和决策机会是否
相同，并明确目标函数不声称对齐。

- `AI_FORMAL` 轨：每个 paired seed block 恰含同 seed、同配置的两次纯代理运行——
  `risk_budget_linear_v1` 与 `risk_budget_threshold_v1`；两者沿用 v0.1 已冻结的风险偏好抽样、
  订单参数与同一非做市目标插槽，策略 ID 或参数组合必须不同，不得为 H2 调参或在场景间交换
  身份。协议须记录主对照选择依据（两条策略各自为何入选），而不是按结果择优。
- `OWNER_N_OF_1` 轨：只冻结供 0.3.2 复用的同 seed 参照、目标插槽、账户、信息集、动作空间
  与窗口调度合同；本里程碑不生成所有者运行。

#### Scenario: 拒绝不完整或漂移协议

- GIVEN 协议缺失任一冻结项、比较矩阵中标为“相同”的字段发生漂移，或标为“不同”的字段未完整披露
- WHEN 请求进入正式样本
- THEN 系统以稳定原因拒绝且不写 evidence index

### Requirement: 隔离阶段与 AI/owner 证据（`FR-303`）

系统应区分 `training`、`preview`、`formal` 样本阶段，并维护 AI formal evidence index。
只有绑定冻结协议、满足完整性规则且未命中预注册排除条件的 AI `formal` 运行可进入分析；
H1 `interactive`、训练、preview、调试、中止以及未来 owner 轨运行必须 fail closed。禁止跨
里程碑或跨轨合并样本量、p 值或置信区间。

#### Scenario: 跨轨或非正式数据伪装成正式样本

- GIVEN header 或 manifest 表明运行源自 `interactive`、非正式阶段或另一条轨道
- WHEN 正式证据入口消费该运行
- THEN 原子拒绝且不生成部分统计、报告或索引

### Requirement: 分别计算三个结果家族（`FR-304`）

分析应按冻结指标口径，分别计算 AI 正式轨的价格崩盘、流动性枯竭和强平连锁的发生与严重程度。
**唯一的主要估计量**是 `AI_FORMAL` 轨在 168 个配对 seed block 上的
`risk_budget_threshold_v1 - risk_budget_linear_v1` 严重程度配对差，按三个家族分别估计双侧
效应量与不确定性；Holm 校正只作用于这三个主要终点。所有者轨不在本里程碑计算，缺失与
SESOI 判定按冻结计划处理。

三个家族各以**严重程度的配对差**为主要 estimand；**发生指标降为描述性次要**。这一改动由
[`H2-endpoint-calibration`](../../../experiments/H2-endpoint-calibration.md) 的实测结果强制：
v0.1.5 用同样两个冻结策略跑的 128 个配对 block 里，全部 12 个发生指标假设的非零配对块数
都是 **0**——配对差恒等于零、方差为零，任何 block 数下功效都是 0。旧的发生率 SESOI
`0.125` 与配套的 `q=0.25` 一并作废（两者都是真人口径）。严重程度 SESOI 已按实测中位配对
SD 的 **0.25 倍**冻结：`price_crash` 与 `liquidity_dry_up` 均为 `4.5969e-3`，对应 block 下限
**168**。`liquidation_cascade` 由 [`H2-cascade-calibration`](../../../experiments/H2-cascade-calibration.md)
实跑 256 个配对 block 单独校准，SESOI 为 `0.25049`，同样需要 168 个 block；三个家族一致，
最终 block 数冻结为 **168**。发生指标的零方差事实必须在报告中如实呈现，不得写成“未发现
差异”。价格崩盘和流动性枯竭沿用 v0.1 的 EV-1—EV-4 归属、`ln(10)` 与 `5%*run_total_ns` 阈值。

强平连锁家族有三条实测约束必须随结论一起声明：(a) 只有高杠杆 + `maint_bp=1200` 的制度格会
发生强平，正式场景分布必须包含该格；(b) 原定发生条件「同一 `chain_id` 至少两个不同账户且
`max(chain_depth)>=1`」在本模型族恒为假——实测所有 `chain_depth` 均为 `0`，而 event-schema
定义 `0` 即「非连锁触发」，故该发生指标同样退化、不得作主要 estimand；(c) 严重程度指标读作
「一次强平判定牵连的账户数」，不得表述为连锁深度或传导强度，结论中使用“强平连锁”一词时必须
同时声明未观察到任何深度 ≥1 的传导。精确公式和零值/缺失语义见 design §9，并须在正式协议
冻结前写入指标字典。

#### Scenario: 结果方向不一致

- GIVEN 三个结果家族产生不同方向或不确定性
- WHEN 生成正式报告
- THEN 逐家族原样呈现，不生成未预注册的综合分数

### Requirement: 记录并分析预注册机制指标（`FR-305`）

系统应从可审计事件链计算至少三类 AI 决策行为：激进订单、流动性撤回、风险减仓；可附加
撤单/改挂、首次强平触发和终局权益。机制分析应预先声明时序与统计口径，默认解释为关联
和时序一致性，不声明因果中介。指标 ID、公式、单位、窗口、缺失语义和适用事件版本必须
写入 [`metrics-dictionary.md`](../../../research/metrics-dictionary.md)；冻结协议只引用其版本
与指标 ID，不得在实现、分析脚本或报告中另行定义同名口径。

#### Scenario: 指标无法追溯

- GIVEN 某机制值缺少规范输入、决定事件或后续市场事件引用
- WHEN 构建机制数据集
- THEN 将其标记为缺失并按冻结规则处理，不推断或手工补值

### Requirement: 生成 H2 正式证据包（`FR-306`）

系统应从冻结协议和 evidence index 单命令生成样本流图、配对检查、三类主要结果、机制
分析、敏感性分析、限制说明、代表性回放、机器可读结果和 manifest。报告结论必须区分
放大、稳定、未建立方向性差异，不把未拒绝零假设表述为等效。

#### Scenario: 重建正式结果

- GIVEN 发布的协议、evidence index 与代码版本
- WHEN 在新进程运行重建入口
- THEN 得到内容哈希一致的机器结果和语义等价的报告

### 数据 / 实体需求

- **DR-301**：`Protocol` 应保存协议 ID、内容哈希、冻结时间与所有预注册字段（含 AI_FORMAL 的
  SESOI、block 数、策略实例与比较矩阵，以及供 OWNER_N_OF_1 复用的接口合同）；`Assignment` 保存 AI seed block、条件和备用 seed
  池；`ExperimentSession` 保存协议、分配、运行、轨道、阶段、完整性和排除状态。所有者字段
  只保留为 0.3.2 可复用的合同边界，不在本里程碑生成个人会话数据。

### 事件 / Trace 需求

- **TR-301**：正式 `RUN_HEADER` 和 manifest 必须交叉绑定 `run_mode`、`sample_stage`、
  `protocol_id/hash`、匿名 `participant_id`、`assignment_id`、`pair_id`、条件、session order、
  目标代理和冻结窗口版本；H2 事件 schema 使用 v5，v4 只读回放且不得升级为正式证据，未知、
  缺失或不一致均 fail closed。
### API / 接口需求

- **IR-302**：正式 evidence guard 应验证运行模式、样本阶段、协议哈希、pair 完整性、排除
  状态和 artifact 哈希；验证完成前不得写部分聚合或 evidence index。

### UX 需求

- **UX-301**：固定假参与者 preview 必须显示合成市场、逻辑进度、冻结可见信息和输入回执；
  不显示未来事件或正式结果。
- **UX-302**：preview 会话应覆盖 waiting、active-window、submitted、no-action、completed、
  technical-abort 和 aborted 状态，用于验证下游 Web 终端的状态合同。
- **UX-303**：preview 必须持续显示阶段标识，并明确 `experiment-preview` 不得升级为正式证据。

### 非功能需求

- **NFR-301**：纯代理控制应在冻结代码/配置/种子下逐事件可复现；配对字段比较和 artifact
  哈希必须机器验证。
- **NFR-303**：停止、排除、补跑和缺失处理只能依据冻结规则；系统故障必须留下审计记录，
  不得根据已观察的市场结果改变样本纳入决定。

## 5. 生命周期与不变量

```text
DRAFT_PROTOCOL -> FROZEN_PROTOCOL  开放问题关闭 / 校准、preview 与重基线条件通过
FROZEN_PROTOCOL -> ASSIGNED        分配表签发 seed blocks、条件与场景顺序
ASSIGNED -> RUNNING                运行入口校验协议、轨道与 assignment
RUNNING -> COMPLETED               全部窗口与 trailer 完整
RUNNING -> TECHNICAL_ABORT         冻结技术无效条件命中
COMPLETED -> INCLUDED/EXCLUDED     仅按预注册规则裁决并留审计证据
INCLUDED blocks -> ANALYZED        block 数满足且对应轨道的 evidence index 冻结
```

不变量：

- 首个正式样本后协议不可原地修改；任何修订必须新建协议版本并按冻结规则决定是否重启研究。
- `AI_FORMAL` 轨的每个分析 block 恰含同 seed 的 `risk_budget_linear_v1` 与
  `risk_budget_threshold_v1` 两次运行；账户、初始资金、风险边界、信息集、动作空间与窗口
  调度必须逐字段相同，允许差异仅为决策策略本身，并须在比较矩阵中显式列出。
- `OWNER_N_OF_1` 轨的窗口、输入链和隐私字段由 0.3.2 继续实现；本里程碑不生成 owner
  分析场景或个人 evidence index。
- AI evidence index 与未来 owner evidence index、样本量和不确定性永不合并；研究声明只由
  AI 轨承担。
- 正式市场中不存在外生基本面或价格冲击；owner 输入在 0.3.2 中作为显式条件而非隐藏冲击变量。
- 样本阶段、运行模式和协议完整性缺一不可；`interactive` 永不升级为 `formal`。
- 三类主要结果保持独立；所有预注册结果均报告，发生指标的零方差事实如实呈现。
- 纳入、排除、停止和补跑决定不读取结果字段；owner 解盲规则由 0.3.2 单独执行。
- 本里程碑不采集个人身份数据；owner 假名与数据最小化由 0.3.2 承担。

## 6. 成功与验收

### 成功标准

- **SC-301**：首个正式样本前存在内容寻址、机器可验证且覆盖 FR-301 全部字段的冻结协议。
- **SC-302**：达到 AI 轨预注册样本量/停止条件，所有纳入运行均有完整 pair、因果链和哈希校验。
- **SC-303**：价格崩盘、流动性枯竭、强平连锁及三类机制指标按冻结计划分别输出效应量、
  不确定性、缺失与敏感性结果。
- **SC-304**：独立新进程可从 evidence index 重建正式结果；报告明确条件性结论、隐私边界、
  排除项和不可外推范围。

### 退出条件

| 退出 | 条件 | 证据 |
|---|---|---|
| E1 | 协议、功效/停止规则、同意/隐私、排除与分析计划冻结并通过机器校验 | frozen protocol + review record |
| E2 | 固定 preview harness 完成协议、窗口和阶段边界验证；正式证据门拒绝 H1、非正式阶段和协议漂移 | experiment-preview bundle + guard matrix |
| E3 | 按停止规则取得完整 AI formal pair；重放、配对与纳入裁决通过 | AI formal evidence index + sample flow |
| E4 | AI 三个结果家族与机制分析按预注册方法重建，未产生综合分数或因果中介越界 | machine results + analysis checks |
| E5 | AI 正式报告、代表性回放、限制与 manifest 可复建；外部审阅通过 | AI H2 delivery bundle + review record |

### 验收清单

- [ ] **AC-301** (`FR-301`, `DR-301`, `NFR-303`, `SC-301`): 不完整协议不能冻结；
      冻结后内容变化产生新哈希且旧 assignment 不可复用。
- [ ] **AC-302** (`UX-301`, `UX-302`, `UX-303`): preview harness 在有限窗口内完成合法决策和
      `NO_ACTION`，并明确不产生正式证据。
- [ ] **AC-303** (`FR-303`, `IR-302`, `TR-301`): evidence guard 原子拒绝 interactive、
      training、preview、未知模式、协议漂移和不完整 pair。
- [ ] **AC-304** (`FR-301`, `TR-301`, `NFR-301`, `SC-302`): 每个纳入 AI pair 的
      比较矩阵中标为“相同”的字段逐字段一致（含账户、初始资金、信息集、动作空间与窗口
      调度参数）；决策生产者、策略目标与参数按矩阵分别披露。主对照可复现、
      处理可重放，次要对照缺失不使主要 pair 失效。
- [ ] **AC-305** (`FR-304`, `SC-303`): 三类结果分别输出发生率、严重程度、双侧配对效应、
      不确定性、多重性和缺失处理，不生成综合分数。
- [ ] **AC-306** (`FR-305`, `TR-301`, `SC-303`): 激进订单、流动性撤回和风险减仓指标均可
      追溯到事件链，并只作预注册的关联/时序解释。
- [ ] **AC-307** (`FR-306`, `IR-302`, `NFR-301`, `SC-304`): 新进程从 evidence index 重建
      机器结果和报告，且 artifact 哈希、样本流与结论语法通过校验。
- [ ] **AC-308** (`DR-301`, `NFR-303`, `UX-303`): AI 成果包不含个人身份信息，preview 阶段
      可辨识且不进入正式 evidence index。

## 7. 测试、依赖与决策

### 测试策略

- 单元测试：协议冻结、assignment、窗口调度、配对比较、排除裁决、指标和结论语法。
- 集成测试：AI/preview 会话、`NO_ACTION`、中止、重放、evidence guard 与原子输出。
- UI / E2E：preview 的有限窗口、阶段提示、信息闭集和无特权控制；生产 Web 终端由 0.3.2 验收。
- 研究验证：冻结模拟数据恢复已知效应；preview 验证流程但永不进入正式证据；正式运行前
  完成分析代码盲测/锁定。
- 真实环境 / 手动验证：目标 Windows 环境运行 AI/preview 演练；所有者 Web 终端、K 线和正式
  场景在 0.3.2 完成后验证。

### 依赖

- 上游 Feature / Contract：已签收 v0.2.1；事件、代理、撮合、账户、指标与退化状态合同。
- 下游消费者：H2 分析、报告、回放、evidence index 和未来人类行为扩展研究。
- 外部 / 环境依赖：无外部真人招募；不依赖项目所有者四天训练时间，避免阻塞当前研究交付。

### 决策与风险

| 决策 / 风险 | 结论或缓解 | 理由 | 后续 |
|---|---|---|---|
| 因果对象（Q-308 已裁决） | 主要估计量为两个冻结 AI 参照策略在 168 个 paired-seed block 上的严重程度配对差 | 需要预先指定、可复现且机会集一致的策略实例 | 主对照策略预注册且取自 v0.1 已验证家族，不为 H2 调参 |
| 匹配边界 | 匹配账户/风险边界、信息集、动作空间与决策机会；不声称策略目标函数对齐 | 策略实例的目标与参数可精确记录 | 协议冻结比较矩阵并分别披露策略差异 |
| 主要假设 | 双侧，允许放大、稳定或未建立方向差异 | 不预设 threshold 或 linear 的方向 | 冻结严重程度 SESOI 与区间解释 |
| 反事实 | 同 seed/config 配对运行两条纯代理策略 | 降低市场路径噪声并锁定矩阵声明的相同项与差异项 | 机器比较冻结字段并输出差异矩阵 |
| 机制声明 | 关联与时序一致性，不默认称因果中介 | 处理后的行为变量存在混杂 | 若需因果中介另立操纵实验 |
| 学习/疲劳 | AI 批处理无参与者内学习/疲劳；所有者训练和正式场景由 0.3.2 单独处理 | 当前估计量不使用真人重复测量 | owner 窗口与顺序仅作为 0.3.2 下游合同 |
| 选择与排除 | 预注册、结果盲的 AI 纳入和补跑规则 | 防止事后选择有故事的运行 | evidence index 保留样本流 |

## 8. 待确认问题

- [x] Q-301: 已关闭 — 决策：两条参照策略为冻结参数的 `risk_budget_threshold_v1` 与 `risk_budget_linear_v1`，在 AI 轨地位平等；全部场景固定同一非做市目标插槽与策略身份，不得为 H2 调参。
- [x] Q-302: 已关闭 — 决策：所有者执行平均终局权益任务；外部招募、报酬和平台均为零，旧预算证据保留但不再生效。
- [x] Q-303: 已关闭 — 决策：逻辑窗 1 秒、每场景 60 窗；所有者会话墙钟窗 8 秒，24 个正式场景分 4 天、每天 6 个、第 3 个后强制休息；AI 轨批处理执行，无墙钟与休息约束。
- [x] Q-304: 已关闭 — 决策：AI 正式轨固定 168 个 paired-seed blocks（三家族 0.25 SD SESOI 各需 168）；所有者轨固定 6 个训练和 24 个正式场景；旧真人功效证据已废止。
- [x] Q-305: 已关闭 — 决策：不设外部资格筛选或身份映射；所有者可停止，只有技术故障可按预签发备用 seed 整局补跑。
- [x] Q-306: 已关闭 — 决策：外部真人为零、唯一真人为项目所有者；不运行外部招募、报酬或人群研究流程，不声称人群效应。
- [x] Q-307: 已关闭 — 决策：三家族主要 estimand 一律是严重程度，发生指标只作描述性（实测零方差）；强平连锁的主要严重度是单个 chain_id 下的最大账户数，不得改用 chain_depth；三家族不合成。
- [x] Q-308: 已裁决——估计对象是账户/风险边界/信息集/动作空间/决策机会匹配后的决策来源差异。AI 轨比较两条冻结策略并独占研究声明；所有者轨的两条参照运行同为 `WINDOW_MATCHED_POLICY_CONTROL` 形态，结果只作描述性。不声称目标函数对齐；结论语法、匹配矩阵与禁用简称见 §1、FR-301 与 §7。
