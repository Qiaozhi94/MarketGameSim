## 回写规则

- 每完成一个检视循环（`stop_condition_met` 全部满足），把完整 issue 表与模式教训
  追加到**当前版本**的文件，例如 v0.4 期的循环写入新建的 `0.4.md`，并在上表加一行。
  **不再追加到本文件**，本文件只维护索引。
- 新开一个版本时由检视人创建 `<version>.md`，沿用各版本文件开头的引言块。
- 循环进行中的过程稿（`CURRENT-doc.md` / `CURRENT-code.md` / `FIX-log.md`）永不进 git
  （`.gitignore` 已覆盖），闭环后由检视人删除；真正落进 git 的是本目录的版本复盘文件。
- 跨版本引用写成「v0.1 循环 8」这类带版本前缀的形式，不要只写「循环 8」——
  循环编号在切分后仍然全局连续，但读者需要知道去哪个文件找。
