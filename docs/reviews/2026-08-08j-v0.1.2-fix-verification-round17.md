## 2. 实现

### 2.1 T002：`docs/experiments/0.1.2-market-validation-protocol.md`（新增）

冻结 PRD §12 六项特征各自的：

1. **收益分布厚尾**——超额峰度 `k`，`z = k/sqrt(24/n)` 渐近检验；
2. **收益序列无显著线性自相关**——lag 1–5 的 `ACF`，Bartlett 白噪声界
   `1/sqrt(n)`，5 个 lag 内部做 Holm-Bonferroni 校正；
3. **绝对收益自相关为正（波动聚集）**——`|r_t|` lag-1 `ACF` 单侧检验；
4. **价格冲击非线性**——`ln(impact_bp) ~ ln(Q)` OLS 回归，`H0: γ=1`；
5. **点差/深度合理且随波动变化**——固定阈值范围检查 + 与滚动波动率
   （`W=30`）的 Pearson 相关显著性检验；
6. **强平连锁规模分布**——纯描述性报告 + 内部一致性检查（非阈值检验）。

统一前提：`n >= 2000` 采样点、前值填充比例 `> 30%` 时收益类检验整体判
不适用、`α = 0.05`、全部用 `statistics.NormalDist` 做渐近正态近似（项目不引入
scipy）。**多重比较**：拒绝 H0 即通过的四项（厚尾/波动聚集/冲击非线性/
点差-波动率相关）合并做一次 Holm-Bonferroni 家族校正；收益自相关一项的判定
方向相反（不拒绝才是通过），单独在其内部 5 个 lag 上做校正，不能与前四项
混进同一个家族（方向语义冲突）。

### 2.2 T606：`src/market_game_sim/metrics/validation.py`（新增）

按上述协议实现 `build_market_validation_matrix`，复用已有的

## 3. 故障注入验证

- `metrics/sampling.py` 成交量累计逻辑注释掉一行 → `test_sampling.py` 2 个新
  测试失败（符合预期），已恢复；
- `metrics/validation.py` 价格冲击回归的退化判据 `sxx < 1e-12` 还原为精确
  `sxx == 0` → 暴露一个真实 bug：`quantity_units` 完全相同的订单集合，
  `log(Q)` 理论上应完全相同，但 `sum/n` 引入的浮点舍入误差使 `sxx` 落在
  `~3.5e-29` 而非精确 0，导致退化判据失效、误判为可回归（结果 `FAIL` 而非
  `NOT_APPLICABLE`）。已改用 `1e-12` 阈值判断，`_pearson` 中同类判据一并加固。
  故障注入 + 复原后确认修复生效；
- `experiment/runner.py::build_market_validation_report` 的技术无效运行跳过
  逻辑替换为直通 → `test_build_market_validation_report_skips_technical_
  invalid_runs` 按预期失败，已恢复。
