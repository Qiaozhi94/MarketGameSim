## 2. T602：配对组 parity 校验（方法论 §10.5）

新增 `experiment/runner.py::check_paired_parity`（静态检查）：对照
`ExperimentConfig` 除 `seed`/`group_label`/`agent_specs` 外全部字段、以及每个共同
`agent_id` 的 `AgentSpec` 除声明的 `treatment_field`（默认 `leverage_tier`）外全部
字段，逐项比对，第一个不一致的字段即返回描述性错误。

新增 `check_shared_randomness_parity`（动态检查）：真实跑完两组后，比对
`AGENT_DECIDE.internal_state.signal_bp`（第13轮 §2.13 新增的字段）在相同
`(agent_id, decision_index)` 下 control/treatment 是否逐位相同——这是"共同语义键
随机冲击逐位相同"要求的实证验证，而不只是"结构上应该相同"的口头保证。能够直接
复用 §2.13 的成果是本轮意外的收获。

`run_paired` 现在**先做静态检查（跑之前）**，通过后才真正运行两组，**再做动态
检查（跑之后）**；任一失败都 `raise ValueError`，不允许静默产出对比报告——对应
方法论 §10.5"未经单维度对照的归因不得写入结论"。

## 3. T604：效应量 + 置信区间 + bootstrap + 多重比较校正

新增 `experiment/stats.py::bootstrap_proportion_diff`：对经济终点率的差值
（treatment−control）做 bootstrap 置信区间，用**局部实例化的 `random.Random(seed)`**
（不是全局 `random` 模块状态）保证给定输入/种子时结果确定可复现。

新增 `holm_bonferroni`：Holm 逐步法多重比较校正，阶梯式——一旦某个假设按其排名
对应的门槛未过，其后所有假设（即使自身 p 值满足更宽松的门槛）也一并判定不显著，
不是逐个独立比较。本轮 `run_paired` 只对比单一主指标，未触发这个函数的实际调用
路径，但函数本身已实现测试并可供未来加入次要指标时复用。

这两个函数都不受 ADR-001"核心领域层禁浮点/只用哈希随机数"约束——它们属于报告/
统计层，`metrics/report.py` 已有先例（`mean_margin_ratio_bp: float`），不是
`kernel`/`ledger` 那样的确定性核心域。

## 4. T605：条件性结论文本生成

新增 `build_conditional_conclusion`：把 T604 的 bootstrap 结果格式化成方法论 §10.2
要求的"在参与者结构 S、参数区间 R 与 N 个随机种子下，信念 B 的效应量为 X
（含置信区间），在条件 C 之外失效"形式，显式拒绝"有效/无效"这种二元表述——
`failure_condition_desc` 未提供时会显式声明"失效条件未声明，不得外推"，而不是
留空当作"总是有效"处理。

`run_paired` 的返回字典新增 `endpoint_rate_effect`（`ProportionDiffResult`）与
`conditional_conclusion`（格式化文本）两个字段。
