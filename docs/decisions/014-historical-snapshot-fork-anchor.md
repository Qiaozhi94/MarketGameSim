# ADR-014：以实盘历史时点作为冷启动锚——市场从该时点分叉为模拟盘

日期：2026-09-21  
状态：Proposed（owner 2026-09-21 批准方向；数据来源与设计细节待裁决）  
关联规格：[`../features/0.4/0.4.1-ai-market-ecology/spec.md`](../features/0.4/0.4.1-ai-market-ecology/spec.md)
（Q-501：本里程碑只实现 `synthetic` 锚，并预留可插拔的锚来源接口）  
关联决策：[`ADR-011`](011-market-engine-trader-layering.md)（§决策 2 不引入外生基本面）、
[`ADR-013`](013-l1-matching-core-clearing-split.md)（L1a/L1b 分层）  
关联文档：[`../SOP.md`](../SOP.md) §4（实施禁止项）

## 背景

0.4.1 Q-501 讨论冷启动锚时，owner 提出第二种来源：取实盘某一时点的盘面作为起点，
「前面是实盘，后面是模拟盘」。它的吸引力有两点：

1. **能自然解决冷启动死锁**：分叉点之前的真实成交可以直接预填代理的 EWMA 样本，
   代理一开局就已经完成预热，不需要 `synthetic` 锚那种人为规定方向的预热成交；
2. **初始条件有真实来源**：价格水平、波动状态和成交节奏都来自真实市场，而不是一个
   人为选定的初始价。

但它不能放进 0.4.1：该里程碑 §7 声明「不依赖外部网络、交易所或行情源」；快照里的
挂单属于真实参与者，在 L1b 中没有账户和保证金归属；分叉后的走势天然会被读成对真实
价格的预测，与 SOP §4 冲突。这些都需要单独决策，因此立本 ADR。

## 决策（草案，待 owner 裁决）

1. **只继承价格与成交带，不继承挂单**：分叉价作为初始价；分叉点之前的成交带用于预填
   EWMA 与因子窗口；盘口由装配清单中的做市商重建。这样每一笔撮合的双方仍然来自
   `agent_specs` 或人类参与者，ADR-011 方案 D 的测试锁定不受影响。
2. **快照是冻结的离线输入**：以文件形式进入仓库之外的数据目录，内容哈希、来源、
   时点与许可写进运行头；相同快照 + 配置 + 种子 ⇒ 逐位可复现。运行时不联网。
3. **与 ADR-011 §决策 2 的关系**：快照只提供**初始条件**，分叉之后不再有任何外生输入，
   价格只由订单流与策略互动决定。因此它不是「外生基本面过程」，不需要修订 ADR-011。
4. **产物声明**：每份使用 `historical_snapshot` 锚的产物都必须携带「分叉后走势是该合成
   市场在这些假设下的演化，不是对真实价格的预测」的声明（SOP §4）。
5. **接口**：作为锚来源 `historical_snapshot` 注册进 0.4.1 交付的可插拔锚来源接口，
   不修改 L2 与 L1。

## 待裁决问题

- 数据来源、标的与许可（本项目的制度钩子是 `crypto_perp`，候选是加密永续合约的公开
  历史成交与盘口数据）。
- 快照格式：需要的最小字段集（分叉时点、分叉前 N 笔成交、可选的盘口形状用于标定
  做市商参数）。
- 「分叉前 N 笔」的 N 如何与代理的半衰期对齐，保证全部代理在分叉点已经完成预热。
- 分叉后的市场质量与 stylized facts 是否与 `synthetic` 锚的运行做同口径对照。
- 承接的里程碑编号与版本位置。

## 备选方案

- **方案 A：连同挂单一起继承**。盘口更真实，但挂单需要一个不在装配清单里的伪账户
  承接保证金与成交，重新引入 ADR-011 方案 D 已经否决的伪参与者。倾向不采纳。
- **方案 B：在线接入实时行情分叉**。违反 SOP §4「不连接交易所」，且无法复现。不采纳。
- **方案 C：只用 `synthetic` 锚**。最简单，但放弃了真实初始条件的价值。作为默认值保留。

## 后果

- 正面：冷启动不再依赖人为规定方向的预热成交；owner 可以从真实市场的具体时刻出发做扰动实验。
- 负面：引入外部数据的获取、许可与存储负担；产物需要额外的合规声明。
- 后续行动：
  - owner 裁决上面的待裁决问题后，本 ADR 转为 Accepted，并立承接里程碑；
  - 0.4.1 T963 交付的锚来源接口必须保证 `historical_snapshot` 接入时不改 L2。
