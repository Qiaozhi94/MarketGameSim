# ADR-006：Owner 交易终端采用真实世界时间与自由连续交易，实验约束收敛到采集模式

## 背景

0.3.2 的 owner Web 终端最初沿用 0.3.1 Q-303 冻结的 owner 墙钟窗合同：每场 60 个逻辑窗
（逻辑窗 1 秒）、所有者会话每窗 8 秒墙钟、每窗至多一次规范动作、到点写 `NO_ACTION`，
目的是与两条参照策略（`WINDOW_MATCHED_POLICY_CONTROL`）做逐窗的"决策机会匹配"。

交互设计原型经两轮所有者评审（2026-09-12/13）确认该合同与真实交易终端的心智模型根本
冲突：真实交易系统没有决策窗口、没有提交倒计时、没有"不操作"按钮；窗口语义还派生出
"拒绝是否消耗动作槽"（原 DQ-A）等纠缠不清的子合同。同时项目方向扩展为"AI 因子策略与
噪声/情绪交易者陪玩的模拟市场"，所有者以真实交易者身份持续使用该终端。

关键边界事实：

- H2 的**研究声明只由 AI_FORMAL 轨承担**（168 个配对 block，0.3.1），其窗口调度为
  批处理执行，不经过 owner 终端，本决策不影响 0.3.1 已冻结文本。
- owner 轨（OWNER_N_OF_1）由 Q-308 裁决为**描述性结论**，不承载研究声明、不外推人群；
  机会匹配放宽的科学代价是场景级描述性对比中声明"机会集不同"。
- 0.3.2 里程碑 `status: draft`，E1（owner observation/K 线语义/动作空间/隐私边界冻结）
  尚未发生——现在是修订的合法窗口。

## 决策

1. **两形态架构**：owner 终端分为**自由模拟终端**（默认形态）与**采集模式**。同一市场
   内核、撮合、账本、保证金与强平路径；阶段门控、解盲清单、每日节奏、结果盲页等实验
   约束只存在于采集模式，自由模拟永不进入任何实验证据索引。
2. **时间双层分离**：内核保留离散步进与逻辑时间作为确定性机制（实现细节，不对用户
   可见）；市场层对外呈现**合成交易所墙钟**（真实格式时间戳、真实分钟边界收 K 线），
   两者由冻结的**时间压缩比**连接。采集模式 1:1 实时；自由模拟可选加速并展示角标。
   owner 场景定义为**冻结的市场时间跨度**（真实时间），取代"60 个窗口"计数。
3. **自由连续交易**：所有者随时提交市价/限价委托并随时撤单（限价单进入 MVP 动作空间，
   内核与 H1 合同已支持 `order_type`/`price_ticks`）；用户侧无窗口、无倒计时、无显式
   "不操作"。服务端按冻结粒度对逻辑时点**静默采样**（仓位/权益/净成交/动作数），维持
   TR-302 因果链与描述性对比，采样不约束用户操作节奏。
4. **呈现决策**：自由模式以 `SIM` 环境角标替代阶段徽标；解盲说明收进「ⓘ 市场说明」
   弹层（采集模式下显示隐藏清单）；K 线提供 1m/5m/15m/1h/4h 派生视图（同一冻结
   public tape，不新增信息源）；最新一根 K 线按普通蜡烛实时更新，"未收口不进入
   artifact"仅为内部语义。

## 备选方案

- **方案 A（放弃）：全局保留 8s 窗口合同**。优点：与参照策略保持逐窗机会匹配；
  缺点：与真实终端心智模型根本冲突，派生子合同（拒绝是否消耗动作槽等）难以收敛，
  所有者四天时间被流程摩擦消耗，而收益仅作用于描述性轨道。
- **方案 B（放弃）：保留窗口合同、仅隐藏倒计时**。优点：规格改动最小；缺点：概念
  仍然存在，歧义与实现复杂度不减，用户明确否决。

## 后果

- **正面**：终端体验与主流交易软件一致；限价/撤单/挂单管理等真实能力成为可能；
  删除 DQ-A/DQ-B/DQ-G 等窗口派生语义，T932/T933 实现与测试范围明显缩小；
  owner 时间消耗在交易本身而非流程。
- **负面**：owner 与参照策略的对比失去逐窗机会匹配，只能做场景级描述性对比并声明
  机会集差异；采样方案需要新增冻结参数并在 E1 前定义。
- **后续行动**：
  1. 0.3.2 spec/design/tasks/版本根/PRD 按本决策修订；新增裁决记录 Q-403。
  2. E1 冻结清单新增：时间压缩比（采集 1:1）、可选 K 线周期集合、时点采样粒度、
     场景市场时间跨度。
  3. Q-303 中 owner 墙钟窗部分由本决策取代；0.3.1 正文不回改，仅追加修订记录。
  4. alphamill 因子策略与噪声/情绪交易者作为自由模拟的 AI 对手方家族，另立 feature
     冻结（`engineering-demonstration`，不进 H2 正式样本）。
