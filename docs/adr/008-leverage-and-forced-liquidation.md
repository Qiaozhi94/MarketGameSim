# ADR-008：杠杆、保证金与强制平仓进入第一版

日期：2026-07-31  
状态：Accepted  
关联规格：[`../../specs/002-belief-testing-laboratory/spec.md`](../../specs/002-belief-testing-laboratory/spec.md)  
解决问题：PRD Q-003  
关联决策：[ADR-007](007-pluggable-market-regimes.md)（制度可插拔）、
[ADR-005](005-numeric-and-serialization-contract.md)（数值口径）

## 背景

v0.3.0 的 MVP 不允许卖空、无融资、无保证金，账户模型只有现金与持仓。这使模型无法
表达一整类现象：**下跌触发平仓、平仓加剧下跌**。

这类现象是产品首要用户的核心关切，也是 PRD §13.1 那条纪律能否落地的关键——如果
模型能证明「无需任何人有意为之，杠杆与拥挤仓位即可自发产生暴跌」，那么「暴跌只能
解释为操控」这个论断中的**「只能」就被去掉了**。这是仿真能提供的最有价值的一类
结论：不是证明真实市场发生了什么，而是证明某个机制**足以**产生该现象。

关键在于强平订单的性质：**它是不计价格的市价单，且其规模由价格本身决定。** 它对
订单簿的冲击与普通卖单完全不同，且构成正反馈回路。省略它，模型里的下跌永远是线性、
温和、可控的。

## 决策

### 1. 第一版即包含杠杆，不推迟

代价是账户模型复杂度上升，但推迟的代价更大：无杠杆基准跑通后再加杠杆，等于把整套
账户、准入、守恒断言与退化状态重做一遍。保证金逻辑渗透进订单准入的每一处，不是
可以后期叠加的模块。

### 2. 单一保证金模型，不做组合保证金

账户维护：

```text
权益     = 现金 + 持仓 × mark
保证金占用 = f(持仓, mark, 制度参数)
担保比例  = 权益 / 保证金占用
```

- 第一版只支持**单一标的、全仓保证金**；
- **不做组合保证金、风险度分层、跨品种对冲减免**——它们会引入与研究问题无关的
  复杂度；
- 所有金额沿用 ADR-005 的最小单位整数，担保比例以整数比值（万分数）表达，避免浮点
  比较决定强平与否。

### 3. 强平触发与执行

| 阶段 | 规则 |
|---|---|
| 判定 | 担保比例 < `maintenance_ratio` 时标记为**待强平** |
| 判定时点 | 每次该账户涉及的账户变动后；股票式制度另在收盘时点判定一次（ADR-007 §3） |
| 宽限 | `grace_ns` 可配置，为 0 时立即强平；> 0 时给予补充保证金的时间窗（第一版无代理会补，等价于延迟） |
| 执行 | 以**市价单**平仓，数量为使担保比例恢复到 `target_ratio` 所需的最小整数量 |
| 部分成交 | 允许；剩余部分在下一事件继续尝试，不放弃 |
| 对手方不足 | 触发**穿仓**：权益为负，记录 `negative_equity_units`，账户转入 `LIQUIDATED` |

**强平不设速率限制，也不打断连锁。** 一次强平推动价格，可能使下一个账户跌破维持
线，从而触发下一轮——PR-007 明确要求该连锁必须允许发生。人为限速会消除本模型最想
观察的现象。

### 4. 穿仓损失有明确归属

权益为负意味着有人的钱没了。第一版把穿仓损失记入**交易所风险账户**（有符号累计量，
与 ADR-005 §3 的费用账户同类），使守恒等式仍然精确成立：

```text
Σ 代理权益 + 交易所费用 + 交易所风险账户 = Σ 初始权益
```

不采用「社会化分摊」（把损失摊给盈利账户）——那是加密交易所的真实做法，但会在代理
之间引入一条与交易行为无关的财富转移通道，污染 PR-016 的收益来源分解。若将来要研究
分摊机制的影响，应作为独立配置项引入。

### 5. 强平事件完整记录

强平在事件日志中不是普通订单：`ORDER_ARRIVAL` 增加 `origin` 字段区分
`AGENT` / `LIQUIDATION`，并携带触发时的担保比例与判定依据。这使「哪些成交由强平
造成」可以被机器识别，是分析连锁规模的前提。

## 备选方案

- **方案 A：不做杠杆（v0.3.0 现状）**  
  优点：账户模型最简。  
  缺点：无法回答产品的核心问题；下跌永远温和。

- **方案 B：做杠杆但强平限速/分批**  
  优点：数值更稳定，不易出现极端连锁。  
  缺点：**限速本身就是研究者注入的一个隐藏变量**，且恰好抑制了要观察的现象。排除。

- **方案 C：完整保证金体系（组合保证金、分层风险度）**  
  优点：贴近真实券商。  
  缺点：复杂度与研究价值不成比例；引入大量需要标定的参数。

- **方案 D：单一全仓保证金 + 不限速强平（已采纳）**

## 后果

- **正面**：模型能表达自我强化的下跌；「杠杆连锁足以造成暴跌」成为可证伪命题；强平
  订单可被机器识别，连锁规模可测量。
- **负面**：
  - 账户模型、订单准入、守恒断言、退化状态全部变复杂；
  - 极端配置下可能出现全市场连环强平至流动性枯竭——这是**有效结果**而非缺陷，但需
    要退化状态定义明确其判定与处置；
  - 穿仓使守恒等式多一项，KPI-001 的断言相应扩展。
- **风险**：强平连锁的规模对 `maintenance_ratio`、`target_ratio`、初始杠杆分布极度
  敏感。这些参数必须作为**扫描维度**而非固定值，否则结论只反映一次任意的参数选择。
