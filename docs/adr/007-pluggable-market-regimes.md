# ADR-007：市场制度可插拔，同一内核承载股票式与加密式

日期：2026-07-31  
状态：Accepted  
关联规格：[`../../specs/002-belief-testing-laboratory/spec.md`](../../specs/002-belief-testing-laboratory/spec.md)  
解决问题：PRD Q-002  
取代：ADR-003（加密现货单一制度，随 v0.3.0 研究层移除）

## 背景

v0.3.0 把标的固定为加密现货：24/7、无涨跌停、无 T+1、即时结算。这在当时是为了
排除制度摩擦对价格形成的干扰。

方向重置后有两个新约束使单一制度不再够用：

1. **研究动机来自股票市场**。要理解融资盘的连锁平仓，需要维持担保比例、强平线与
   收盘机制——加密永续的爆仓逻辑与之形似而神不同（资金费率、24/7 无隔夜跳空）。
2. **制度本身就是一个值得研究的变量**。同一群参与者、同一套信念配置，在两种制度下
   跑对照，能回答「多少结果来自参与者行为、多少来自市场规则」。这是单一制度下问不出
   的问题。

`plan.md` 早已预留 `ConstraintHooks` 插槽（v0.3.0 时为空实现），本 ADR 把它实化。

## 决策

### 1. 制度是配置，不是分支代码

撮合核心不含任何制度判断。制度通过一组**约束钩子**注入，钩子在固定的时点被调用：

| 钩子 | 调用时点 | 典型职责 |
|---|---|---|
| `validate_order` | 订单准入 | 价格笼子、单笔上限、可交易数量、卖空许可 |
| `session_state` | 每个事件 | 判定当前处于连续交易 / 收盘 / 熔断 |
| `settlement_rule` | 成交结算 | T+N 可用性、可卖数量计算 |
| `margin_rule` | 账户变动后 | 保证金计算、强平触发判定（ADR-008） |
| `price_bound` | 撮合前 | 涨跌停、熔断阈值；无限制时为空实现 |

**钩子只能拒绝或延迟，不能改写订单。** 静默修正会使代理的实际行为偏离其声明策略，
让行为归因失效——与退化状态定义 §5「不静默取整」同一理由。

### 2. 第一版提供两套制度配置

| 项 | 股票式（`equity_margin`） | 加密式（`crypto_perp_free`） |
|---|---|---|
| 交易时段 | 连续交易 + 收盘（隔夜） | 24/7 连续 |
| 涨跌停 | 无 | 无 |
| 熔断 | 有，阈值可配置 | 无 |
| 卖空 | 需融券，第一版禁止 | 允许（保证金内） |
| 融资 | 融资买入 + 维持担保比例 | 全仓杠杆 + 强平线 |
| 结算 | T+2 可用 | 即时 |
| 最小报价单位 | tick | tick（更细） |

两套配置共享同一撮合核心、同一账本、同一事件 Schema。

### 3. 收盘与隔夜是股票式的一等公民

收盘不是「暂停」，而是一个**状态**：

- 收盘期间订单簿冻结，不接受新订单，不撮合；
- 隔夜后以**集合竞价或直接连续竞价**开盘（第一版取后者，简化）；
- **隔夜跳空由开盘后的订单流自然产生**，不人为注入价格缺口；
- 强平判定在收盘时点执行一次，触发的强平单在下一交易时段开盘后执行——这正是
  真实市场中「隔夜爆仓」的形态，也是加密式制度下不存在的现象。

## 备选方案

- **方案 A：只做加密式（v0.3.0 原方案）**  
  优点：制度最简，涌现最纯粹。  
  缺点：无法承载研究动机中的融资盘连锁；无法把制度作为变量。

- **方案 B：只做股票式**  
  优点：贴近首要用户的真实经历。  
  缺点：放弃了 24/7 这个干净的对照条件——加密式没有收盘，能把「隔夜」这个混淆因素
  完全消除，是研究连续时间下价格形成的更好基准。

- **方案 C：钩子可插拔（已采纳）**  
  优点：两者兼得；制度成为可研究变量；未来接入 A 股、期货只是新增配置。  
  缺点：MVP 变大；钩子接口一旦定错，改动成本高于分支代码。

## 后果

- **正面**：制度对照成为一类研究问题；撮合核心保持纯粹；新增制度不需重写核心。
- **负面**：
  - 第一版工作量显著上升（收盘、T+2、熔断都要实现）；
  - 钩子调用点必须在实现前定死——遗漏一个时点（例如「收盘时强平判定」）会导致整类
    制度无法表达；
  - 两套制度都要有各自的基准验证，M2 的验证工作量翻倍。
- **风险**：制度差异可能掩盖参与者差异。任何跨制度比较必须固定参与者配置与种子，
  且在报告中显式声明制度差异清单。
