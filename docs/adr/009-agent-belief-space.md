# ADR-009：以连续信念空间取代离散代理类型

日期：2026-07-31  
状态：Accepted  
关联规格：[`../../specs/002-belief-testing-laboratory/spec.md`](../../specs/002-belief-testing-laboratory/spec.md)  
解决问题：PRD Q-004、Q-005  
取代：ADR-003 §2—§3（内生锚与代理分类部分，随 v0.3.0 研究层移除）

## 背景

v0.3.0 把散户划分为四个硬类别：噪声、趋势、均值回复、羊群。参数扫描的自变量是
「趋势代理占比」。

这个设计有两个问题：

1. **类别是研究者钦定的。** 真实市场里没有人是纯粹的技术派或纯粹的价值派；四个
   工种式的类别把连续的认知光谱切成了四块，边界的位置直接影响结论。
2. **它容易滑向循环论证。** 若趋势代理的规则写着「上涨则买入」，再观察到「价格走势
   影响了交易者」，那只是规则的重述（PRD §13.5）。

同时必须避免一个反向的陷阱：让代理**在线优化**（以利润最大化为目标搜索策略）看似
消除了钦定，实则把自由度从「看得见的交易规则」转移到了「看不见的学习机制」——探索
率、记忆长度、适应频率、策略表示空间同样由研究者选定，同样能决定结论，而且**更难
被审查**。文献中这类模型对学习速率与规则表示的敏感性是众所周知的。

## 决策

### 1. 共同动机 + 异质信念，而非共同目标 + 在线搜索

真实市场的结构是：几乎所有参与者都想赚钱（**动机相同**），但对「什么会让价格上涨」
的理解各不相同（**信念相异**）。价值投资者、K 线交易者、情绪交易者的差别不在目标
函数，而在这个信念上。

「想赚钱」本身不产生任何行为——它无法告诉代理此刻该买还是该卖。从动机到订单，中间
必须有一个**对价格如何变动的信念**。因此本模型给代理的是信念，不是优化能力。

一个支持该选择的经验事实：真实市场中持续亏损的群体长期存在，且亏损者通常不切换到
正确策略，只是换参数继续。若代理能有效优化，这个群体不该存在。**「人人追求利润
最大化」在动机层为真，在行为层为假。**

### 2. 不引入外生基本价值（继承并强化）

模型中不存在基本面信息通道，价格完全由订单流互动内生产生。

这一条继承自 ADR-003 并在新方向下获得了更强的理由：它在形式上正是**技术分析第一
公理**（价格包含一切有用信息）的实现——市场中没有外部「真值」，价格就是全部。

由此，「技术因子是否有效」从一个前提变成了**可以在模型内被证伪的问题**：

> 在一个纯粹由订单流互动形成价格的市场里，技术因子能否获得超额收益？在什么参与者
> 结构下能？

若能，说明其有效性可能来自订单流的自相关结构本身；若不能，说明它必须来自模型之外的
东西。两个答案都有价值。

### 3. 信念以因子权重向量表达

每个代理持有一个权重向量，一次运行内**固定不变**：

```text
w = (w₁, …, w_k)             从可配置分布中抽取，Σ|wᵢ| 归一
signal_t = Σ wᵢ · factorᵢ(该代理的信息集)
```

- `signal_t` 经代理各自的阈值与规模参数转为订单意图；
- 「纯趋势交易者」只是 `w` 的一个角点，绝大多数代理落在内部；
- 研究者定义的是**信念空间的形状**（因子库与权重分布），不是每个代理的规则。

### 4. 因子库须覆盖不同信息源

第一版因子库至少包含五类，且**必须来自不同信息源**：

| 因子 | 信息源 | 说明 |
|---|---|---|
| 动量 | 价格历史 | 近期收益的加权和 |
| 回归 | 价格历史 | 相对内生 EWMA 锚的偏离；锚的半衰期逐代理异质抽取 |
| 从众 | 成交流 | 近期主动买卖不平衡 |
| 盘口 | 订单簿状态 | 买卖档位深度失衡 |
| 随机 | 无 | 纯噪声，代表不理解市场的参与者 |

**MACD、均线交叉、各类摆动指标与「动量」本质同族**——都是价格历史的线性滤波，只是
窗口与差分方式不同。把它们全部塞进因子库会制造**表面的多样性**：因子高度共线，同涨
同跌，反而更易共振。因此扩充因子库时，判据是「是否引入新的信息源」，而不是「是否是
一个新指标」。

**因子相关矩阵必须随每次研究运行报告**，用于验证多样性是真实的。

### 5. 内生锚的自指风险仍然存在

回归因子锚定内生 EWMA，构成自指结构（价格锚定于自身历史），其稳定性不能假定。
三种失效形态——**锁定**（锚跟随过快，回复力名存实亡）、**发散**（制动失效）、
**周期振荡**（锚过于僵化，产生由半衰期决定的人造周期）——继承自原 ADR-003 的分析，
仍然有效。

周期振荡尤须警惕：它外观酷似真实市场周期，极易被误读为发现。判据是收益自相关函数
在锚半衰期对应的 lag 附近出现显著峰。异质半衰期（逐代理抽取而非共用）是打散共振的
设计手段，其有效性须由实验检验，不得假定。

### 6. 单次运行内不适应

代理的信念权重、因子参数、能力配置在一次运行内固定。理由见 PRD §13.3：若代理自我
优化，改变某个能力维度时策略会同时改变，测到的效应是「该维度 + 策略适应」的混合，
单维度归因失效。

策略适应作为独立研究方向留待后续阶段，且应采用**群体层面**（跨运行按绩效复制变异）
而非个体层面（运行内在线学习）的机制——前者保住了运行内的对照有效性。

## 备选方案

| 方案 | 评估 |
|---|---|
| 四类离散代理（v0.3.0） | 类别边界由研究者钦定，影响结论；容易滑向循环论证 |
| 连续信念权重（**已采纳**） | 先验强度显著降低，且可对因子库构成做敏感性检验 |
| 运行内在线优化（RL / GA） | 自由度从交易规则转移到学习机制，更难审查；破坏单维度对照。排除 |
| 零智能代理（仅受预算约束随机下单） | 有价值，作为**对照基准**保留（对应「随机」因子权重为 1 的角点），但不作为主体设计 |

## 后果

- **正面**：参与者结构成为连续可扫描的变量；「技术因子的条件有效性」成为可证伪问题；
  单维度对照与收益来源分解的有效性得以保持。
- **负面**：
  - 因子库的构成仍是研究者的先验，**只能减弱不能消除**——必须显式声明并做敏感性
    检验，写入结论限制；
  - 权重分布的形状（均匀？狄利克雷？稀疏？）是新增的一组参数，需要预注册；
  - 「趋势代理占比」这类直观概念不再存在，参数扫描的自变量变成分布参数，解释成本
    上升。
- **风险**：若因子库全部来自价格历史，多样性是假的。§4 的信息源判据与相关矩阵报告
  是针对该风险的缓解，须在实现中强制执行。
