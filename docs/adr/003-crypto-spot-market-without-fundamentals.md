# ADR-003：市场标的设为加密现货，并以内生锚替代外生基本价值

日期：2026-07-29  
状态：Accepted（§4 的 NaN 表述已由
[ADR-005](005-numeric-and-serialization-contract.md) §6 细化：领域层不产生未定义
状态，未定义的量在日志中写 `null`，NaN 仅是分析层的统计表示）  
关联规格：[`../../specs/001-market-simulation-foundation/spec.md`](../../specs/001-market-simulation-foundation/spec.md)  
解决问题：PRD Q-001、Q-003、Q-007  
关联方法论：[`../product/methodology.md`](../product/methodology.md)

## 背景

研究目标是观察**市场行为本身**——订单流互动、价格路径以及价格走势如何反过来影响
交易者决策——而不希望结论被基本面信息的到达过程所主导。

原设计（PRD v0.2.0）以通用连续竞价为标的，并使用**合成基本价值**驱动价值代理与
知情交易者。若直接删除基本价值，会连带影响：

- **PR-005 / FR-005** 的价值代理失去交易依据；
- **PR-006 / FR-006** 的知情交易者失去"更准确的价值信号"这一优势来源；
- **A-001**（外生基本价值只影响代理决策）失效；
- **A-003** 的能力四维分解（资金 / 信息 / 速度 / 执行）中"信息"一维塌陷。

同时存在动力学风险：在基于代理的市场模型中，价值型代理提供的均值回复力通常是
价格不发散的主要约束，也是厚尾与波动聚集的重要成分（回复力与趋势正反馈的对抗）。
纯噪声加趋势的市场易退化为爆炸性漂移或无结构随机游走，两者都无法满足 PRD §12 的
市场验证框架。叠加"允许极端情况"（Q-003）后，该风险进一步上升。

## 决策

### 1. 市场制度设为加密现货

- 24/7 连续交易，无休市、无集合竞价；
- 无涨跌停、无 T+1、无整手限制；
- tick size 可配置且支持极细粒度；
- **手续费按 maker / taker 分离计费**（替代原 PR-003 的单一费率）。

maker/taker 费率不对称直接塑造做市商的报价与库存行为，是加密市场区别于股票市场的
关键机制，必须作为一等配置项。

### 2. 以内生锚替代外生基本价值

**价值代理改为均值回复代理**：锚定**内生**的价格统计量，而非外生价值信号。系统中
不再存在外生基本价值过程。

这与"把基本面放回来"有本质区别：外生价值是系统外注入的信息，内生锚是价格自身的
历史。后者不引入任何基本面信息，同时保留了防止价格发散的稳定力。

#### 2.1 自指结构与三种失效形态

外生锚是单向的：价格追随 V，V 不受价格影响。内生锚是循环的：价格追随均价，而均价
由价格计算得出。该自指结构的稳定性不能假定，其失效有三种形态：

**锁定**——锚的记忆过短时，价格变动后锚立即跟随，偏离恒接近零，均值回复代理几乎
不下单。回复力名存实亡，系统退化为无锚状态。

**发散**——锚记忆过短叠加趋势代理推动时，价格上行而锚同步上行，均值回复代理因
"未观察到偏离"而不反向操作。本应制动的力量失效，价格单边跑飞。

**周期振荡**——锚的记忆过长时，锚近乎静止，价格累积大幅偏离后触发均值回复代理集体
反向操作，随后反向越过锚，形成往复摆动。**该振荡的周期由记忆长度决定，是参数的
人造产物而非涌现现象**，且外观酷似真实市场周期，极易被误读为研究发现——正落在
PRD §13 首行的循环论证风险上。

因此关键参数是**锚的记忆长度**：过短导致锁定或发散，过长导致振荡，中间存在可用
区间。该区间的宽度取决于趋势代理占比，故锚的取值与 M3 的技术交易者占比研究相互
耦合，不是两个独立问题。

#### 2.2 锚的具体形式

**采用指数加权移动均价（EWMA），且各代理的半衰期从一个分布中抽取，而非共用同一
值。** 参数为两个：半衰期分布的中心 **τ** 与离散度 **σ**。

**明确排除成交量加权均价（VWAP）。**

采用 EWMA 的理由：

1. 无窗口掉出效应。简单移动均价 SMA(N) 在第 N 笔之前的价格离开窗口时锚会跳变，
   制造周期为 N 的伪信号——该伪信号与上述"周期振荡"外观一致，将使真实动力学与
   计算伪影无法区分；
2. O(1) 增量更新、无需保存价格历史，对 NFR-003 的性能门槛与确定性回放均有利；
3. 单参数（半衰期）语义清晰。

采用异质半衰期的理由：若所有均值回复代理共用同一记忆长度，它们将同时触发反向
操作，**周期振荡几乎必然出现**。半衰期散开后，短记忆代理先反应、长记忆代理后
反应，集体行为被摊平，共振被打散。该设计同时更贴近真实市场——不同参与者本就参考
不同周期。

排除 VWAP 的理由：VWAP 使锚同时依赖价格与成交量，而成交量由代理行为内生决定。
M3 的大资金执行者拆单会产生大量成交，**这些成交将直接推动锚本身**。届时研究
"执行策略对成交质量的影响"时，执行行为已经改变了整个市场的回复中心，构成混淆
变量，归因链断裂。自指结构也会从一维升为二维，稳定性分析难度显著上升。

#### 2.3 稳定性的验证方法

三种失效形态分别对应 PRD §12 已有的检查项，**无需新增诊断指标**：

| 失效形态 | 诊断指标 | 判据 |
|---|---|---|
| 锁定 | 均值回复代理的成交量占比 | 占比接近 0 表明锚失效 |
| 发散 | 价格对数偏离的终值分布、触界样本比例 | 与发散样本排除率同源统计 |
| 周期振荡 | 收益序列自相关函数 | 在 lag ≈ τ 附近出现显著峰，即为人造周期的指纹 |

第三项尤其重要：「收益序列是否缺乏显著线性自相关」本就是 §12 的必检项，若该检验
在半衰期位置出现峰值，应判定为参数产物而非市场特征。

**M2 参数扫描的坐标为 τ × 趋势代理占比**，输出一张标注可用区与三类失效区的图。
该图既确定锚参数的有效取值范围，也为 M3 的占比研究划定边界，是 M2 的核心交付物
之一。

需要强调：上述三种失效形态的描述是基于该反馈结构的**定性预期**，实际动力学必须由
M2 参数扫描实证确认，不得作为已验证结论引用。

### 3. 知情交易者重定义为订单流预知

信息优势不再表现为"更准确的价值信号"，而是**提前 N 个事件获知某笔大单将到达**。
N 与可见订单流范围为显式配置参数。

该定义在加密市场有现实对应（mempool 可见性、MEV），且可测量、可配置，使 A-003 的
"信息"维度得以保留而不塌陷。

### 4. 允许极端情况，但必须定义退化状态行为

不引入价格限制或熔断，允许崩盘、暴涨与流动性枯竭。但以下退化状态的行为必须在 M1
之前明确定义，否则仿真将产出 NaN 或崩溃而非有研究价值的极端样本：

- 价格下界（0 或 1 tick）以及是否允许无上界发散；
- 代理破产后的行为（退出，或保留但禁止新开仓）；
- 订单簿单边清空时市价单的处理；
- 长时间无成交的判定与处理。

此外须**预先声明"发散样本"的判定标准与排除规则，并在报告中给出排除率**。统计验证
在发散样本上不具意义，但排除过程必须透明——排除率本身即是一项结果。该要求是
methodology §9.2"记录失败、破产、无成交和异常终止样本"的操作化。

### 5. 校准与范围边界

- **MVP 只做现货**；永续合约与资金费率明确不进入 MVP。
- **不锁定具体币种**。MVP 使用合成订单流（PRD §10.4 已定），将参数校准到某一具体
  标的推迟至 M4 立项，避免过早引入真实数据依赖。

## 备选方案

- **方案 A：保留外生合成基本价值（原设计）**  
  优点：价值代理与知情交易者定义清晰；均值回复力明确；文献可比性强。  
  缺点：与"屏蔽基本面影响、单纯研究市场行为"的研究目标直接冲突。

- **方案 B：彻底删除任何锚定机制**  
  优点：最彻底地排除基本面。  
  缺点：价格缺乏回复力，易发散或退化，难以满足 §12 验证框架；且"信息"能力维度
  塌陷，A-003 无法成立。

- **方案 C：内生锚 + 订单流信息优势（已采纳）**  
  优点：不引入任何外生基本面信息，符合研究目标；保留稳定力与"信息"维度；信息
  优势的新定义更贴合加密市场语境。  
  缺点：内生锚引入自指结构（价格锚定于自身历史），其稳定性需在 M2 通过参数扫描
  确认；与使用外生价值的经典 ABM 文献的可比性下降。

### 锚的形式（对应决策 §2.2）

| 形式 | 说明 | 评估 |
|---|---|---|
| 简单移动均价 SMA(N) | 过去 N 笔成交的算术平均 | 存在窗口掉出效应，制造周期为 N 的伪信号，与"周期振荡"失效难以区分 |
| 指数加权 EWMA | 权重按指数衰减 | **采纳**。无窗口掉出效应，O(1) 增量更新，单参数语义清晰 |
| 成交量加权 VWAP(N) | 按成交量加权 | **排除**。引入价格与成交量的二维耦合，并使 M3 执行研究产生混淆变量 |
| 多尺度混合 | 各代理使用不同记忆长度 | **与 EWMA 组合采纳**。打散共振，代价是参数增加一维 |

## 后果

- **正面**：实验环境中不存在基本面信息通道，价格路径完全由订单流互动产生，直接
  服务于"市场行为与价格走势对交易者的影响"这一研究目标；无制度约束使极端状态可
  自由涌现，便于研究崩盘与流动性枯竭。
- **负面**：
  - 内生锚的自指结构可能在某些参数区间产生非预期动力学（锁定、发散或周期振荡），
    M2 必须以 τ × 趋势代理占比的参数扫描确认稳定区间，并将不稳定区间作为结果报告；
  - 锚参数空间为二维（τ × σ），M2 参数扫描成本上升；
  - "半衰期"概念比"过去 N 笔"略抽象，需在指标字典中定义其与事件时间的换算关系；
  - 与使用外生基本价值的经典模型对比时需额外说明差异；
  - 允许发散意味着部分实验样本不可用于统计验证，有效样本量下降。
- **后续行动**：见下节文档同步清单；σ 的初始取值范围为遗留项（PRD Q-010），
  在 M2 扫描后回写。

## 研究纪律提醒

"K 线走势对交易者的影响"这一课题本身落在 PRD §13 风险表首行（代理规则预先决定
结论）：若代理规则写明"上涨则买入"，再观察到"价格走势影响了交易者"，属于循环
论证而非发现。

该课题必须改写为可证伪的形式，例如：

> 当技术交易者占比从 10% 升至 50% 时，波动聚集强度、价格冲击非线性与崩盘频率
> 如何变化？在何种参数区间内，趋势跟随群体的净收益为负？

后者可被实验数据否定，前者不能。相关正反例已补入 methodology §11。
