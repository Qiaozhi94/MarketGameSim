## 1. 文档目的

本文说明 MarketGameSim 为什么采用基于代理的计算经济学、博弈分析和市场微观结构
仿真，以及这些方法在产品中如何落地和验证。

本文不是投资理论、真实市场预测方法或市场操纵指南。它约束模型设计、实验方法和结论
表达，防止使用者将仿真结果过度外推。

## 2. 基于代理的计算经济学

基于代理的计算经济学（Agent-Based Computational Economics，ACE）通过计算机中的
自主代理表示经济参与者，并观察它们反复互动后形成的系统级结果。

这里的“代理”不是中介机构，而是具有以下组成部分的决策实体：

- **状态**：钱包余额、合约仓位、保证金占用、风险预算和历史记忆；
- **信息集**：可见价格、订单簿、成交、以及（在引入外生价值的模型中）基本价值信号
  及其噪声——**本项目 MVP 不启用基本价值通道**（001 / D-4）；
- **决策规则**：何时下单或撤单、选择什么价格和数量；
- **目标**：利润、成交质量、库存控制、风险控制或其他实验目标；
- **约束**：资金、持仓、订单类型、延迟、手续费和市场制度。

每个代理只能使用其信息集中的内容。仿真引擎掌握的真实状态不得自动暴露给代理。

## 3. 代理决策循环

MarketGameSim 中的代理遵循统一循环：

```text
观察市场和私有信号
  → 更新内部状态
  → 根据策略生成意图
  → 提交订单或撤单
  → 交易所校验和撮合
  → 更新钱包、仓位和绩效
  → 进入下一次决策
```

决策时间、观察频率和通信延迟可以因代理而异，但事件顺序必须确定、可记录并可回放。

## 4. 价格如何形成

MVP 中的市场价格必须完全由订单簿交互内生形成：

1. 代理基于各自信息和规则产生订单；
2. 交易所按照价格时间优先原则维护订单簿；
3. 可成交订单按照撮合规则形成交易；
4. 成交价格、盘口深度和后续代理反应共同构成价格路径。

任何过程都不得绕过订单簿直接指定成交价格，否则系统模拟的是外生价格回放，而不是
参与者之间的市场博弈。

### 4.1 无外生基本价值

按 [001 规格 D-3/D-4](../../specs/v0.1-belief-testing-laboratory/spec.md)，模型中**不存在
外生基本价值过程**，也不存在新闻等基本面信息通道。研究目标是市场行为本身，以及
价格走势如何反过来影响交易者决策。

价格不发散所需的均值回复力，由锚定**内生**长周期价格统计量的代理提供。这与外生
基本价值有本质区别：外生价值是系统外注入的信息，内生锚是价格自身的历史，不引入
任何基本面信息。

该机制含**自指结构**（价格锚定于自身历史），其稳定性不能假定，可能出现三种失效：
**锁定**（锚跟随过快，回复力名存实亡）、**发散**（制动失效，价格单边跑飞）与
**周期振荡**（锚过于僵化，产生由参数决定的人造周期）。

第三种尤须警惕：人造周期外观酷似真实市场周期，极易被误读为研究发现。判据是收益
自相关函数在锚半衰期附近出现显著峰——该检验本就是 §9.3 的必检项。

基准验证必须通过参数扫描识别可用区间与三类失效区间，并将失效区间作为结果报告而非
隐藏（见 §9.3）。锚的具体形式与验证判据见
[001 规格 D-3/D-4](../../specs/v0.1-belief-testing-laboratory/spec.md) §2。

## 5. 博弈分析与代理仿真的关系

| 方法 | 在 MarketGameSim 中回答的问题 |
|---|---|
| 博弈分析 | 参与者的目标、策略选择、信息优势和相互依赖是什么？ |
| 代理仿真 | 大量异质、有限理性的参与者持续互动后会发生什么？ |
| 市场微观结构 | 订单、撮合、流动性和价格冲击如何连接？ |
| 统计分析 | 观察到的差异是否稳定，还是随机路径造成的？ |
| 历史数据校准 | 模型的参数和统计特征与目标市场有多大差距？ |

MarketGameSim 不预设所有代理都能求解最优策略或市场最终必然达到均衡。规则代理可以
采用启发式策略，后续学习代理也必须遵守相同的信息、账户和市场约束。

## 6. 产品中的代理分类

### 6.1 散户：连续信念空间

散户**不划分为固定类别**。每个代理持有一个因子权重向量，一次运行内固定
（[001 规格 D-3/D-4](../../specs/v0.1-belief-testing-laboratory/spec.md)）：

```text
signal = w_动量·动量 + w_回归·回归 + w_从众·从众 + w_盘口·盘口 + w_噪声·噪声
```

「纯趋势交易者」只是该空间的一个角点，绝大多数代理落在内部——真实市场里很少有人是
纯粹的技术派或纯粹的价值派。研究者定义的是信念空间的形状，不是每个代理的规则。

动量与回归分量的对抗（正反馈 vs 回复力）是厚尾与波动聚集的必要成分。回归因子锚定
内生 EWMA，各代理半衰期从分布中抽取而非共用同一值，以打散集体反向操作造成的共振。

**因子库须覆盖不同信息源。** MACD、均线交叉与「动量」本质同族（都是价格历史的线性
滤波），堆砌它们只会制造表面的多样性——因子高度共线，反而更易共振。因子相关矩阵须
随每次研究运行报告。

### 6.2 大资金代理

- **库存型做市商**：持续提供双边流动性并控制库存风险；
- **大资金执行者**：在限定时间内完成目标仓位并管理市场冲击；
- **订单流预知者**：提前 N 个事件获知大单到达。由于模型无外生基本价值，信息优势
  不表现为更准确的价值信号，而表现为对**未来订单流**的提前可见性——该定义在加密
  市场有现实对应（mempool 可见性、MEV），且可配置、可测量。

### 6.3 非 MVP 代理

操纵型代理、强化学习代理和 LLM 代理必须通过独立规格引入。操纵型代理只能服务于
异常行为检测和监管压力测试，不得连接真实市场。

## 7. 角色、能力和行为必须分离

“庄家”不是可直接实现的单一代理类型。模型必须分别描述：

- **角色**：代理在实验中的经济目标；
- **能力**：资金、信息、速度、订单权限和风险预算；
- **行为**：具体观察、决策、下单和撤单规则。

例如，大资金执行者不一定拥有信息优势，做市商也不等同于操纵者。只有将这些维度
分开，实验才能判断收益究竟来自资金规模、信息质量、速度还是策略本身。

## 8. 涌现及其限制

当代理之间的局部互动产生未被直接写入程序的系统现象时，称为涌现。例如：

```text
初始买盘增加
  → 价格上升
  → 趋势代理跟随
  → 卖方深度下降
  → 点差和波动扩大
  → 库存及风险约束触发
  → 价格反转或流动性恢复
```

涌现只说明现象由模型内部互动产生，不说明它必然存在于真实市场。如果代理规则、
数量或参数预先偏向某个结果，仿真仍可能只是把假设重新表现为价格曲线。

因此，任何涌现现象都必须经过反事实对照、消融实验、参数敏感性和多随机种子检验。

## 9. 模型验证层级

### 9.1 机制正确性

首先验证软件是否按照声明规则运行：

- 价格时间优先；
- 部分成交和撤单；
- 钱包、仓位、保证金占用和费用守恒；
- 订单拒绝和边界约束；
- 相同配置和种子的确定性回放。

机制正确性未通过时，不得解释策略或市场结果。

### 9.2 内部有效性

检查实验差异是否确实由目标变量造成：

- 对照组只改变一个能力或策略因素；
- 使用相同外生路径和配对随机种子；
- 排除实现缺陷、初始化差异和指标泄漏；
- 记录失败、破产、无成交和异常终止样本。

### 9.3 统计与微观结构特征

基准市场至少报告：

- 收益分布及厚尾；
- 收益和绝对收益的自相关；
- 波动聚集；
- 点差、深度、成交量和撤单率；
- 订单规模与价格冲击；
- 各代理类型的库存、交易成本和 PnL；
- **内生锚的稳定参数区间**——由参数扫描确定的可用区，及三类失效区（锁定、发散、
  周期振荡）的边界；
- **杠杆连锁的规模分布**——强平触发次数、连锁深度、强平成交量占比
  （[001 规格 D-2](../../specs/v0.1-belief-testing-laboratory/spec.md)）。

MVP 不要求所有特征都与真实市场一致，但必须明确标记通过、失败或不适用。

**发散样本的处理**：由于模型允许极端行情自由涌现且无外生价值锚，部分样本会出现
价格发散。统计验证在这些样本上不具意义，因此必须：

1. **预先声明**发散样本的判定标准（在实验开始前，不得事后调整）；
2. 报告**排除率**——排除率本身即是一项结果，反映该参数配置的稳定性；
3. 根据有效样本量调整统计功效，必要时提高种子数量。

事后调整判定标准以获得更好的统计结果，等同于选择性报告。

### 9.4 稳健性

每项重要结论至少应检查：

- 多个随机种子；
- 合理范围内的参数扫描；
- 代理构成变化；
- 极端和边界场景；
- 替代策略规则或指标定义。

结论若只在狭窄参数区间成立，应将该条件作为结果的一部分，而不是隐藏。

### 9.5 外部校准

引入真实数据后，还需要记录：

- 数据来源、许可和时间范围；
- 清洗、聚合和缺失值处理；
- 目标市场的交易制度；
- 用于校准与用于验证的数据隔离；
- 模型无法复现的真实市场特征。

## 10. 实验设计原则

每次正式实验必须预先声明：

- 研究问题和可证伪假设；
- 对照组、实验组和唯一主要变量；
- 固定条件及代理构成；
- 随机种子和样本量；
- 主要与次要指标；
- 排除标准和停止规则；
- 配置哈希、代码版本及运行环境。

实验记录使用 [`../experiments/experiment-template.md`](../experiments/experiment-template.md)。

### 10.1 三层验证顺序与「够用即止」

本产品分三层：市场微观结构地基 → 信念检验 → 可玩模拟器（PRD §1）。验证顺序不可
颠倒：**在一个不像市场的市场里检验出来的规律，是模型的人造产物。**

但第一层要设**「够用即止」**的门槛：达到 §9.3 与 PRD §12 声明的统计特征即进入第二
层，不追求所有特征完美吻合。理由是两者的目标不同——纯微观结构研究会为了拟合优度
无限调参，而信念检验只需要市场「足够像」。门槛以预先声明的形式固定，**不得在看过
第二层结果后回头放宽**。

### 10.2 信念检验的结论形式

每条信念结论必须写成条件性命题，而非二元判断：

> 在参与者结构 S、参数区间 R 与 N 个随机种子下，信念 B 的效应量为 X（含置信区间），
> 在条件 C 之外失效。

「有效 / 无效」这种形式**不予接受**——它隐藏了适用边界，而边界恰恰是最有实用价值的
部分。报告须同时给出失效区间。

### 10.3 参数空间三区分离

同一片参数区域既用来把市场调成「像市场」，又用来检验信念，结论会被校准目标诱导——
这与用同一份数据既训练又测试是同一种错误。参数空间须预先划分：

| 区域 | 用途 | 纪律 |
|---|---|---|
| 校准区 | 挑选模型可用区域 | 允许反复试，结果不进结论 |
| 冻结验证区 | 检验市场充分性（第一层门槛） | 划定后不得再调参数 |
| 信念实验区 | 检验目标命题 | 预注册，与校准区不重叠 |

划分方案须随实验协议一并预注册。最终结论应跨替代代理规则或模型族复核——只在单一
行为映射下成立的结论，是实现的性质而非市场的性质。

### 10.4 零和恒等式不是发现

在无外部资金流入的封闭市场中，扣除手续费后所有代理的 PnL 之和恒为负，恰等于交易所
收取的总费用（含风险账户）。因此「某类参与者整体亏钱」是**会计恒等式**，不是研究
结果。

有内容的问题只能是**分布与机制**：谁亏、亏多少、通过哪个渠道转移。每份涉及财富转移
的报告必须显式声明该恒等式，避免把它误读为结论。

### 10.5 能力维度的单维度对照

资金、信息、速度、执行能力四个维度的影响，**各自必须由只改变该一个维度的配对对照
实验支撑**（相同种子集合，其余配置逐字节相同）。同时改动两个维度再解释其中一个的
效果，属于 §9.2 意义上的内部有效性缺陷——效应无法归因到具体维度。

未经单维度对照的归因不得写入结论，只能作为探索性观察报告，并显式标注。这是第二层
的退出验收（PRD §11.3 KPI-008）；第一层的对应验收是 KPI-005 的市场验证报告。

## 11. 允许和不允许的结论

推荐表达：

> 在配置 C、参数范围 R 和 N 个随机种子下，订单流提前可见量增加与该类代理平均执行
> 收益提高相关；当市场深度下降到 D 以下时，该效果不再稳定。

不允许表达：

> 仿真证明真实市场中的庄家一定会这样操作，因此可以据此获利。

所有结论必须说明模型假设、样本量、不确定性、失败区域和外推限制。

### 11.1 循环论证：研究问题的提法

最常见的失效模式不是结论错误，而是**问题本身不可证伪**。当研究问题的答案已经被写进
代理规则时，实验无法否定它，观察到的"现象"只是规则的重述。

以"价格走势对交易者的影响"这一课题为例：

**不可证伪的提法**：

> K 线走势会影响交易者的决策吗？

趋势代理的规则中已写明"上涨则倾向买入"，因此答案必然为"会"。这不是发现，是把
输入当成了输出。

**可证伪的提法**：

> 当技术交易者占比从 10% 升至 50% 时，波动聚集强度、价格冲击非线性与崩盘频率
> 如何变化？在何种参数区间内，趋势跟随群体的净收益为负？

后者询问的是**行为规则的市场后果**，而非行为规则是否存在。它可以被实验数据否定：
占比上升可能不改变波动聚集，趋势群体也可能在所有测试区间内都盈利。

**通用判据**：写下研究问题后，先问"什么样的实验结果会否定它？"如果答不出来，说明
问题的答案已经藏在代理规则里，必须重新提法。

## 12. 方法论治理

- PRD 负责说明为什么采用该方法及产品级边界；
- 本文负责定义跨规格通用的方法和验证纪律；
- 功能规格负责声明具体代理、市场机制和验收标准；
- 实验文档负责记录单次研究问题、配置和结果；
- 重大方法变更必须记录 ADR，并检查对既有实验可比性的影响。

如果实现、规格或实验结论与本文冲突，应先修订并评审方法论，而不是静默偏离。
