## 1. 产品摘要

MarketGameSim 是一个本地运行、订单簿驱动、可复现的市场仿真实验环境。它的用途不是
预测价格，而是**把交易信念变成可以被实验否定的命题**。

产品分三层，逐层依赖：

```text
第三层  可玩的市场模拟器      人可作为交易者亲身参与，建立直觉      （远期）
第二层  交易信念检验实验室    条件性命题的可证伪检验                （核心产出）
第一层  市场微观结构地基      证明这个市场像个市场                  （前提）
```

第一层不产生交易洞察，但没有它，第二层的所有结论都不可信——在一个不像市场的市场里
检验出来的规律，是模型的人造产物。这个顺序由宪章第 5 条「先验证市场，再解释策略」
决定，不可颠倒。

## 2. 背景与问题

真实市场里，交易者持有大量信念：趋势会延续、放量突破更可靠、下跌中的反弹应当减仓、
大资金会在关键位置制造假突破。这些信念指导着真金白银的决策。

**但它们在真实市场里永远无法被干净地检验**，原因是结构性的：

- 只有**一条**历史路径，没有对照组；
- 无法控制变量——你不能让同一段行情在「散户杠杆率更低」的条件下重演一次；
- 每次结果都掺杂运气，单次盈亏不构成证据；
- 归因极易滑向自我确认：赚钱归因于信念正确，亏钱归因于「有人操纵」。

最后一条尤其危险。当一个人只想到一种解释（例如「基本面没变，暴跌只能是操控」），
通常不是因为其他解释不成立，而是因为没有系统地列出其他解释——杠杆连锁平仓、拥挤
仓位的出口拥堵、预期而非现状的重新定价，每一条都能在基本面不变时造成暴跌，且都
不需要任何人有意为之。

仿真环境能提供真实市场给不了的三样东西：**可重复的路径、可控的变量、可分解的收益
来源**。这就是本产品存在的理由。

## 3. 产品愿景

让每一条交易信念都能被改写成如下形式并接受检验：

> 在参与者结构 S、参数区间 R 与 N 个随机种子下，信念 B 成立 / 不成立，
> 其效应量为 X（含置信区间），在条件 C 之外失效。

答案是**条件性**的，而不是「有效」或「无效」。条件性答案同时告诉使用者信念何时失效，
这比一个绝对结论更有用，也更诚实。

## 4. 目标用户

### 4.1 首要用户：有实盘经验的交易者（研究自己的信念）

- 持有明确的交易信念，希望知道它们在什么条件下成立；
- 有过重大盈亏经历，希望理解背后的机制而非仅复盘价格；
- 能读懂统计结论，接受「条件性成立」这种答案形式。

### 4.2 次要用户：市场微观结构学习者

- 希望理解冲击成本、逆向选择、流动性枯竭、强制平仓连锁等机制的实际形态；
- 用仿真建立直觉，而非从教科书定义出发。

### 4.3 潜在用户：风控与监管研究者

- 在隔离环境中研究杠杆连锁、拥挤交易与异常行为的检测指标；
- 非 MVP 首要对象，但设计需保留扩展能力。

## 5. 产品目标

- **G-001**：建立正确、确定性、可复现的订单簿与账户系统，含杠杆与强制平仓。
- **G-002**：以**连续信念空间**表达参与者异质性，而非少数几类预设代理。
- **G-003**：使任一成交可追溯至代理的观察、信念、决策与账户变化。
- **G-004**：支持固定种子的批量对照实验、参数扫描与配对比较。
- **G-005**：先以预先声明的统计特征验证市场本身，再在其上检验交易信念。
- **G-006**：把代理收益分解到可归因的渠道（价差、冲击、择时、对手方转移）。
- **G-007**：支持市场制度可插拔，同一内核可运行股票式与加密式两种制度。
- **G-008**：形成从 PRD、规格、代码、测试到实验结论的完整追溯链。

## 6. 非目标

以下几条是**硬边界**，不随阶段放宽：

- **不预测任何真实证券、指数或加密资产的未来价格。**
- **不生成交易信号，不提供投资建议。** 本产品的输出是条件性命题与机制理解，任何
  「照此操作」的解读都超出其能力范围。
- **不把仿真结论外推至真实市场。** 合成订单流、规则代理、单品种、无外生基本面——
  与真实市场的差距是结构性的，不是参数校准可以弥补的（见 §13.2）。
- 不连接券商、交易所、钱包或真实资金。
- 不假设存在能够无条件控制价格的单一「庄家」角色（见 §13.1）。
- MVP 不实现多品种、期权、跨市场套利、强化学习或 LLM 代理。
- 不提供生产级高频撮合性能与真实交易所协议兼容。

## 7. 核心概念

### 7.1 信念空间取代代理类型

参与者不再划分为「趋势代理 / 均值回复代理」等少数硬类别，而是每个代理持有一个
**信念权重向量**，从因子库中抽取（002 / D-3）：

```text
w = (w_动量, w_回归, w_从众, w_盘口, w_噪声, …)   一次运行内固定
下单信号 = Σ wᵢ · factorᵢ(信息集)
```

「纯趋势交易者」只是这个空间的一个角点，绝大多数代理落在内部——如同真实市场里
很少有人是纯粹的技术派或纯粹的价值派。研究者定义的是**信念空间的形状**，而不是
每个代理的具体规则。

**因子是被检验的对象，不是内置的真理。** 因子库中包含哪些因子本身是一项先验，须在
报告中显式声明并做敏感性检验。

### 7.2 能力维度

任何参与者优势必须由可测参数表达，且可单独改变（用于单维度对照）：

- 初始现金、持仓与**可用杠杆**；
- 信息质量与信息到达时间（订单流提前可见范围）；
- 观察频率与通信延迟；
- 可用订单类型、单笔数量限制、执行工具（拆单调度）；
- 风险预算、库存限制与维持担保比例。

### 7.3 市场制度可插拔

同一内核通过约束钩子承载不同制度（002 / D-1）：

| 制度 | 交易时间 | 价格限制 | 融资 | 结算 |
|---|---|---|---|---|
| 股票式 | 连续交易 + 收盘 | 无涨跌停、有熔断 | 融资买入、维持担保比例 | T+2 |
| 加密式 | 24/7 连续 | 无 | 全仓杠杆、强平线 | 即时 |

制度是**配置项而非分支代码**——同一份代理与信念配置能在两种制度下跑对照，这本身
就是一类研究问题（制度如何改变同一群参与者的结果）。

### 7.4 杠杆与强制平仓

第一版即包含（002 / D-2）。理由：
强平订单是**不计价格的市价单**，它对订单簿的冲击与普通卖单完全不同，是理解暴跌
机制不可省略的部件。没有它，模型无法回答「下跌是否会自我强化」。

## 8. MVP 用户旅程

1. **配置实验**：选择市场制度、参与者规模、信念空间形状、杠杆上限与随机种子。
2. **验证市场**：运行基准配置，确认统计特征达标（§12），否则不进入下一步。
3. **提出信念**：把一条交易信念写成可证伪命题与对应的对照设计。
4. **批量运行**：多种子、配对对照、参数扫描。
5. **读取结论**：条件性结论 + 效应量 + 置信区间 + 失效边界 + 收益来源分解。
6. **回放审查**：对任一成交回放其完整因果链，确认结论不是实现缺陷造成的。

## 9. MVP 功能范围

### 9.1 市场与撮合

- **PR-001**：价格时间优先的单品种限价订单簿，支持限价单、市价单、撤单、部分成交。
- **PR-002**：市场制度以约束钩子表达，至少支持股票式与加密式两套配置。
- **PR-003**：maker / taker 分离计费，支持负 maker 费率（返佣）。
- **PR-004**：账户维护现金、持仓、冻结、保证金、费用与已实现/未实现 PnL，守恒等式
  在每个事件后精确成立。

### 9.2 杠杆与风险

- **PR-005**：支持融资买入与保证金账户，维持担保比例可配置。
- **PR-006**：担保比例低于阈值时触发强制平仓，强平以市价单执行并完整记录。
- **PR-007**：强平引发的价格变动可能触发下一轮强平——**该连锁必须允许发生**，不得
  以人为限制打断，其规模作为结果报告。

### 9.3 参与者

- **PR-008**：代理信念以因子权重向量表达，权重从可配置分布中抽取。
- **PR-009**：因子库至少包含动量、回归、从众、盘口失衡、随机五类，可扩展。
- **PR-010**：提供做市商、大资金执行者与订单流预知者，其优势由 §7.2 的能力维度
  显式表达。
- **PR-011**：代理能力与信念在单次运行内**不适应、不学习**——策略适应留待后续阶段，
  因为它会破坏单维度对照的内部有效性（§13.3）。

### 9.4 实验与记录

- **PR-012**：配置可序列化、含随机种子，支持多种子批量运行与配对对照。
- **PR-013**：事件日志记录订单、成交、账户分录、强平、代理观察与决策，含因果外键。
- **PR-014**：市场层指标——收益、波动、点差、深度、成交量、撤单率、价格冲击。
- **PR-015**：代理层指标——按时间序列输出的权益、库存、杠杆率、交易成本、PnL。
- **PR-016**：**收益来源分解**——把每个代理的 PnL 拆分为价差收入、冲击成本、择时
  损益与对手方转移四个渠道。
- **PR-017**：退化状态有确定行为：破产、强平失败、单边簿、长时间无成交、价格触界。

### 9.5 呈现

- **PR-018**：单文件 HTML 回放器，以事件日志为唯一输入逐帧呈现。
- **PR-019**：总结报告与回放同源，含条件性结论、效应量与置信区间。
- **PR-020**：K 线视图（周期定义见指标字典），供人工审阅与远期交互模式复用。

## 10. 关键产品决策

| 决策 | 内容 | 记录 |
|---|---|---|
| 数值口径 | 最小单位整数，手续费为唯一舍入点 | **ADR-005** |
| 事件调度 | 全序键严格递增，因果外键与账户分录 | **ADR-006** |
| 市场制度 | 约束钩子可插拔，支持股票式与加密式 | 002 / D-1 |
| 杠杆 | 融资、维持担保比例、强制平仓进第一版 | 002 / D-2 |
| 参与者 | 连续信念空间取代离散代理类型 | 002 / D-3 |
| 基本面 | **不引入外生基本价值**，价格完全由订单流内生形成 | 002 / D-4 |
| 时间内核 | 离散事件、整数逻辑时间、分流 RNG | 002 / D-5 |
| 实现路线 | 自建最小内核，外部框架仅作参考 | 002 / D-6 |
| 可视化 | 事件日志回放，回放与报告同源 | 002 / D-7 |

「不引入外生基本价值」一条继承自方向重置前的设计并保留：它在形式上正是技术分析第一公理（价格包含一切
有用信息）的实现——市场中没有外部「真值」，价格就是全部。这使「技术因子是否有效」
成为一个可以在模型内被证伪的问题，而不是一个前提。

## 11. 产品成功指标

### 11.1 工程可信度

- **KPI-001**：撮合、优先级、撤单、部分成交、保证金与守恒等式验收测试 100% 通过。
- **KPI-002**：固定配置与种子的重复运行产生相同事件摘要哈希。
- **KPI-003**：订单簿、账本与强平逻辑分支覆盖率不低于 90%。
- **KPI-004**：基准配置在参考硬件上的单核运行时间满足性能门槛。

### 11.2 第一层：市场可信度

- **KPI-005**：基准市场验证报告逐项声明 §12 的统计特征为通过 / 失败 / 不适用，并
  报告发散样本判定标准与排除率。
- **KPI-006**：任一成交可追溯至观察、信念、决策与账户变化，且由日志因果外键**机器
  验证**，不依赖重放。

### 11.3 第二层：信念检验质量

- **KPI-007**：每条信念结论以条件性命题表达，含效应量、置信区间与失效边界。
- **KPI-008**：每条能力维度的归因由**只改变该维度**的配对对照实验支撑。
- **KPI-009**：每个代理的 PnL 可完整分解到 PR-016 的四个渠道，残差可解释。
- **KPI-010**：不存在仅凭单次价格路径或单次运行得出的结论。
- **KPI-011**：报告显式声明零和恒等式（§13.4），不把恒等式结果当作发现。

### 11.4 第三层：呈现

- **KPI-012**：回放器仅以事件日志为输入还原整段仿真，与原运行逐帧一致。

## 12. 市场验证框架（第一层门槛）

基准市场至少检查以下特征，MVP 不要求全部通过，但必须透明报告：

- 收益分布厚尾；
- 收益序列无显著线性自相关；
- 绝对收益自相关为正（波动聚集）；
- 价格冲击随订单规模非线性增长；
- 点差与深度在合理范围且随波动变化；
- **杠杆情形下的强平连锁规模分布**（新增）。

**「够用即止」原则**：第一层达标即进入第二层，不追求所有特征完美吻合。追求完美会
把项目锁死在无止境的调参上，而信念检验只需要市场「足够像」。达标门槛以 KPI-005 的
声明形式固定，不得在看过第二层结果后回头放宽。

## 13. 结论纪律

本章是本产品的核心约束，违反它会使全部实验失去意义。

### 13.1 不得预设「庄家」

若把大资金代理的规则写成「先拉高诱多、再派发」，然后观察到散户亏损，这不是发现，
而是把自己写的规则用价格曲线重述一遍。**不对称收益必须作为结果涌现，不得作为规则
写入。** 大资金的优势只能通过 §7.2 的能力维度表达。

### 13.2 不得外推至真实市场

模型可以证明某机制**足以**产生某种现象（例如「无需操纵，杠杆连锁即可造成暴跌」），
但**不能**证明真实市场中的某次暴跌就是这么发生的。统计特征等价不等于机制等价：
两个模型可能在 §12 全部指标上都通过，产生机制却完全不同。

结论中必须写明这一限制。任何把仿真结论用于真实交易决策的做法都超出产品能力范围。

### 13.3 单次运行内不允许策略适应

若代理在实验过程中自我优化，那么改变某个能力维度时，代理策略会同时改变，测到的
效应是「该维度 + 策略适应」的混合，KPI-008 的单维度归因随即失效。策略适应作为独立
研究方向留待后续阶段，且须使用群体层面（跨运行）而非个体层面（运行内）的适应机制。

### 13.4 零和恒等式不是发现

在无外部资金流入的封闭市场中，扣除手续费后所有代理的 PnL 之和**恒为负**，恰等于
交易所收取的总费用。因此「散户整体亏钱」是会计恒等式，不是研究结果。

有内容的问题只能是**分布与机制**：谁亏、亏多少、通过 PR-016 的哪个渠道转移。报告
必须显式声明该恒等式，避免把它误读为结论。

### 13.5 问题的提法必须可证伪

写下研究问题后先问：**什么样的结果会否定它？** 答不出来，说明答案已藏在代理规则里，
必须重新提法。正反例见 [`methodology.md`](methodology.md) §11.1。

## 14. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 循环论证：结论已写进代理规则 | §13.1、§13.5；信念作为变量而非前提（§7.1） |
| 把仿真结论当交易信号 | §6 硬边界、§13.2；报告模板强制声明限制 |
| 因子库的选择偏差 | 因子构成作为先验显式声明并做敏感性检验 |
| 因子高度共线（MACD 与动量本质同族） | 因子库须覆盖不同**信息源**，并报告因子相关矩阵 |
| 第一层无止境调参 | §12「够用即止」，门槛预先固定 |
| 杠杆使账户模型复杂度失控 | 002 / D-2 限定为单一保证金模型，不做组合保证金 |
| 强平连锁被误当作「操控证据」 | §13.1、§13.4；报告须同时给出无杠杆对照组 |
| 人在环数据污染研究结论 | 交互运行与研究运行分离，日志头部标记，前者不进统计 |

群体层面策略适应、多品种、期权、真实数据校准。
