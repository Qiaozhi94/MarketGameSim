## 1. 产品摘要

MarketGameSim 是一个本地运行、订单簿驱动、可复现的**合成市场反事实与压力测试环境**。
它的用途不是预测价格，而是**把交易信念变成可以在明确声明的模型族内被实验否定的
命题**。

必须准确表述它能否定什么：系统能否定的是「信念在该模型族中无条件成立」，**不是**
「信念在真实市场中成立」。合成订单流、人工代理、人工制度参数、无真实数据校准——
这些边界决定了结论的适用范围只到模型族边缘为止（§13.2）。

产品分三层，逐层依赖：

```text
第三层  可玩的市场模拟器      人可作为交易者亲身参与，建立直觉      （远期）
第二层  交易信念检验实验室    条件性命题的可证伪检验                （核心产出）
第一层  市场微观结构地基      证明这个市场像个市场                  （前提）
```

第一层不产生交易洞察，但没有它，第二层的所有结论都不可信——在一个不像市场的市场里
检验出来的规律，是模型的人造产物。这个顺序由宪章第 5 条「先验证市场，再解释策略」
决定，不可颠倒。

## 2. 背景与问题

真实市场里，交易者持有大量信念：趋势会延续、放量突破更可靠、下跌中的反弹应当减仓、
大资金会在关键位置制造假突破。这些信念指导着真金白银的决策。

**但它们在真实市场里永远无法被干净地检验**，原因是结构性的：

- 只有**一条**历史路径，没有对照组；
- 无法控制变量——你不能让同一段行情在「散户杠杆率更低」的条件下重演一次；
- 每次结果都掺杂运气，单次盈亏不构成证据；
- 归因极易滑向自我确认：赚钱归因于信念正确，亏钱归因于「有人操纵」。

最后一条尤其危险。当一个人只想到一种解释（例如「基本面没变，暴跌只能是操控」），
通常不是因为其他解释不成立，而是因为没有系统地列出其他解释——杠杆连锁平仓、拥挤
仓位的出口拥堵、预期而非现状的重新定价，每一条都能在基本面不变时造成暴跌，且都
不需要任何人有意为之。

仿真环境能提供真实市场给不了的三样东西：**可重复的路径、可控的变量、可分解的收益
来源**。这就是本产品存在的理由。

## 3. 产品愿景

让每一条交易信念都能被改写成如下形式并接受检验：

> 在**模型族 M**、参与者结构 S、参数区间 R 与 N 个随机种子下，信念 B 的目标效应为
> X（含置信区间），在条件 C 之外失效。该结论仅说明这些机制**足以或不足以**产生目标
> 结果，不说明真实市场中的对应现象由同一机制造成。

答案是**条件性**的，而不是「有效」或「无效」。条件性答案同时告诉使用者信念何时失效，
这比一个绝对结论更有用，也更诚实。

### 3.1 第一版的旗舰问题

第一版不建设通用平台，而是围绕**一个**可证伪问题形成端到端闭环：

> 在无外生价值冲击的加密式**永续**市场中，**杠杆上限分布**与维持保证金率是否足以
> 产生**自我强化的价格崩盘**？该效应在什么参数区间出现、在什么区间消失？

选它的理由：它是首要用户的直接关切；它只需要单一制度即可回答；它的答案可以是否定的
（可能必须有人主动砸盘才会崩），因而可证伪；它同时检验了杠杆、强平、连锁与账户模型
这条最难的实现路径。

**第一版的全部范围由该问题决定。** 与它无关的能力一律后移（§15）。

## 4. 目标用户

当前工作流要求使用者自行完成可证伪提问、对照设计、参数扫描、排除规则与统计解释——
这更接近研究者而非一般交易者。用户排序据此设定：

### 4.1 首要用户：市场机制研究者 / 能编辑配置的开发者

- 能把一个模糊直觉改写成可证伪命题与对照设计；
- 能读懂效应量、置信区间与失效边界。

### 4.2 协作用户：有实盘经验的资深交易者

- **提供信念**并审阅机制解释，但不必自己搭实验；
- 第一版的检验清单应来自这类用户的真实信念，而非凭空设计。

### 4.3 远期用户：通过实验模板使用的普通交易者

- 需要预制模板与向导，属第三层（可玩模拟器）范围，非 MVP 对象。

**开发实验向导前的前置动作**：收集 10—20 条真实交易信念，逐条判断能否被当前信息集、
制度与指标表达。表达不了的比例过高，说明该做的是扩展模型而不是做界面。

## 5. 产品目标

- **G-001**：建立正确、确定性、可复现的订单簿与账户系统，含杠杆与强制平仓。
- **G-002**：以**连续信念空间**表达参与者异质性，而非少数几类预设代理。
- **G-003**：使任一成交可追溯至代理的观察、信念、决策与账户变化。
- **G-004**：支持固定种子的批量对照实验、参数扫描与配对比较。
- **G-005**：先以预先声明的统计特征验证市场本身，再在其上检验交易信念。
- **G-006**：把代理权益变动完整分解为可精确加总的会计项（指标字典 §5.2）。
- **G-007**：市场制度以约束钩子表达，使新增制度不需重写撮合核心；第一版只实现
  加密式一套。
- **G-008**：形成从 PRD、规格、代码、测试到实验结论的完整追溯链。

## 6. 非目标

以下几条是**硬边界**，不随阶段放宽：

- **不预测任何真实证券、指数或加密资产的未来价格。**
- **不生成交易信号，不提供投资建议。** 本产品的输出是条件性命题与机制理解，任何
  「照此操作」的解读都超出其能力范围。
- **不把仿真结论外推至真实市场。** 合成订单流、规则代理、单品种、无外生基本面——
  与真实市场的差距是结构性的，不是参数校准可以弥补的（见 §13.2）。
- 不连接券商、交易所、钱包或真实资金。
- 不假设存在能够无条件控制价格的单一「庄家」角色（见 §13.1）。
- MVP 不实现多品种、期权、跨市场套利、强化学习或 LLM 代理。
- 不提供生产级高频撮合性能与真实交易所协议兼容。

## 7. 核心概念

### 7.1 信念空间取代代理类型

参与者不再划分为「趋势代理 / 均值回复代理」等少数硬类别，而是每个代理持有一个
**信念权重向量**，从因子库中抽取（002 / D-3）：

```text
w = (w_动量, w_回归, w_从众, w_盘口, w_噪声, …)   一次运行内固定
下单信号 = Σ wᵢ · factorᵢ(信息集)
```

「纯趋势交易者」只是这个空间的一个角点，绝大多数代理落在内部——如同真实市场里
很少有人是纯粹的技术派或纯粹的价值派。研究者定义的是**信念空间的形状**，而不是
每个代理的具体规则。

**因子是被检验的对象，不是内置的真理。** 因子库中包含哪些因子本身是一项先验，须在
报告中显式声明并做敏感性检验。

### 7.2 能力维度

任何参与者优势必须由可测参数表达，且可单独改变（用于单维度对照）：

- 初始现金、持仓与**可用杠杆**；
- 信息质量与信息到达时间（订单流提前可见范围）；
- 观察频率与通信延迟；
- 可用订单类型、单笔数量限制、执行工具（拆单调度）；
- 风险预算、仓位限制与维持保证金率。

### 7.3 市场制度可插拔

**第一版只实现加密式一套制度**：24/7 连续、即时结算、全仓杠杆与强平线、无涨跌停、
无熔断、无收盘。

撮合核心仍不含制度判断，制度经约束钩子注入（002 / D-1）——**接口一次设计对，实现
只做一套**。股票式（收盘、隔夜、T+2、熔断、融券）后移，届时新增配置而非重写核心。

后移的理由不是它不重要，而是它引入的事件生命周期（开盘、收盘、熔断、到期结算）会
使第一版的事件体系复杂度翻倍，而旗舰问题用加密式即可回答。「制度如何改变同一群
参与者的结果」是一个**独立的研究问题**，属于后续阶段。

### 7.4 杠杆与强制平仓（线性永续）

账户模型为**线性永续合约**而非杠杆现货：每笔成交产生一多一空，**净持仓恒为 0**，
由此全局权益守恒精确成立，且做空与做多天然对称、无需债务与借贷分录
（002 / D-2、[账户合同](../contracts/margin-and-account.md)）。

第一版即包含杠杆。理由：
强平订单是**不计价格的市价单**，它对订单簿的冲击与普通卖单完全不同，是理解暴跌
机制不可省略的部件。没有它，模型无法回答「下跌是否会自我强化」。

## 8. MVP 用户旅程

1. **配置实验**：选择市场制度、参与者规模、信念空间形状、杠杆上限与随机种子。
2. **验证市场**：运行基准配置，确认统计特征达标（§12），否则不进入下一步。
3. **提出信念**：把一条交易信念写成可证伪命题与对应的对照设计。
4. **批量运行**：多种子、配对对照、参数扫描。
5. **读取结论**：条件性结论 + 效应量 + 置信区间 + 失效边界 + 收益来源分解。
6. **回放审查**：对任一成交回放其完整因果链，确认结论不是实现缺陷造成的。

## 9. MVP 功能范围

### 9.1 市场与撮合

- **PR-001**：价格时间优先的单品种限价订单簿，支持限价单、市价单、撤单、部分成交；
  撮合规则见 `docs/contracts/matching.md`。
- **PR-002**：市场制度以约束钩子表达；**第一版只提供加密式配置**，接口须能在不改
  撮合核心的前提下接入其他制度。
- **PR-003**：maker / taker 分离计费，支持负 maker 费率（返佣）。
- **PR-004**：账户模型为线性永续合约——钱包余额、合约仓位、开仓成本、保证金、费用与
  已实现/未实现 PnL；守恒等式（指标字典 §5）在每个事件后整数精确成立。

### 9.2 杠杆与风险

- **PR-005**：支持全仓保证金与双向持仓，维持保证金率可配置；初始仓位恒为 0。
- **PR-006**：保证金率低于维持线时触发强制平仓，强平以市价单执行并完整记录。
- **PR-007**：强平引发的价格变动可能触发下一轮强平——**该连锁必须允许发生**，不得
  以人为限制打断，其规模作为结果报告。

### 9.3 参与者

- **PR-008**：代理信念以因子权重向量表达，权重从可配置分布中抽取。
- **PR-009**：因子库至少包含动量、回归、从众、盘口失衡、随机五类，可扩展。
- **PR-010**：提供库存型做市商。大资金执行者与订单流预知者**后移**——它们服务的是
  能力归因问题，不是旗舰问题。
- **PR-011**：代理能力与信念在单次运行内**不适应、不学习**——策略适应留待后续阶段，
  因为它会破坏单维度对照的内部有效性（§13.3）。

### 9.4 实验与记录

- **PR-012**：配置可序列化、含随机种子，支持多种子批量运行与配对对照。
- **PR-013**：事件日志记录订单、成交、账户分录、强平、代理观察与决策，含因果外键。
- **PR-014**：市场层指标——收益、波动、点差、深度、成交量、撤单率、价格冲击。
- **PR-015**：代理层指标——按时间序列输出的权益、库存、杠杆率、交易成本、PnL。
- **PR-016**：**会计桥接**——把每个代理的权益变动拆分为**价差、即时冲击、仓位重估、
  资金费与违约、手续费**五项（指标字典 §5.2），互斥且精确加总，残差为 0。

  这是对原「价差 / 冲击 / 择时 / 对手方转移」四渠道归因的**降级**：那四项在经济含义
  上天然重叠（价差与冲击共享同一基准价，「对手方转移」很可能只是零和对账的另一种
  表达），无法在不引入任意约定的前提下做到互斥。会计桥接的每一项都有唯一定义、可
  手工验算，先把账算对；经济归因待第一个实验闭环后再评估是否可行。
- **PR-017**：退化状态有确定行为：破产、强平失败、单边簿、长时间无成交、价格触界。

### 9.5 呈现

- **PR-018**：单文件 HTML 回放器，以事件日志为唯一输入逐帧呈现。
- **PR-019**：总结报告与回放同源，含条件性结论、效应量与置信区间。
- **PR-020**：K 线视图（周期定义见指标字典），供人工审阅与远期交互模式复用。
- **PR-021**：验证报告须**分两部分**给出结果——经济终点的发生率与严重度，以及条件于
  未发生终点的连续市场指标（§12、退化状态 §4.0）。

## 10. 关键产品决策

| 决策 | 内容 | 记录 |
|---|---|---|
| 数值口径 | 最小单位整数，手续费为唯一舍入点 | **ADR-005** |
| 事件调度 | 全序键严格递增，因果外键与账户分录 | **ADR-006** |
| 市场制度 | 约束钩子可插拔；第一版只实现加密式 | 002 / D-1 |
| 杠杆 | 线性永续、维持保证金率、强制平仓进第一版 | 002 / D-2 |
| 参与者 | 连续信念空间取代离散代理类型 | 002 / D-3 |
| 基本面 | **不引入外生基本价值**，价格完全由订单流内生形成 | 002 / D-4 |
| 时间内核 | 离散事件、整数逻辑时间、分流 RNG | 002 / D-5 |
| 实现路线 | 自建最小内核，外部框架仅作参考 | 002 / D-6 |
| 可视化 | 事件日志回放，回放与报告同源 | 002 / D-7 |

「不引入外生基本价值」是一项**实验隔离选择**（002 / D-4）：用于研究订单流与价格
反馈是否足以产生目标现象，**不是**对真实市场信息效率或技术分析公理的认可。它使
「技术因子是否有效」成为该模型族内可证伪的问题，而不是一个前提。

## 11. 产品成功指标

### 11.1 工程可信度

- **KPI-001**：撮合、优先级、撤单、部分成交、保证金与守恒等式验收测试 100% 通过。
- **KPI-002**：固定配置与种子的重复运行产生相同事件摘要哈希。
- **KPI-003**：订单簿、账本与强平逻辑分支覆盖率不低于 90%。
- **KPI-004**：基准配置在参考硬件上的单核运行时间满足性能门槛。

### 11.2 第一层：市场可信度

- **KPI-005**：基准市场验证报告逐项声明 §12 的统计特征为通过 / 失败 / 不适用，并
  分别报告**经济终点发生率**与**技术无效率**（退化状态 §4.0）。
- **KPI-006**：任一成交可追溯至观察、信念、决策与账户变化，且由日志因果外键**机器
  验证**，不依赖重放。

### 11.3 第二层：信念检验质量

- **KPI-007**：每条信念结论以条件性命题表达，含效应量、置信区间与失效边界。
- **KPI-008**：每条能力维度的归因由**只改变该维度**的配对对照实验支撑。
- **KPI-009**：每个代理的权益变动可完整分解到 PR-016 的五项会计桥接，**残差恒为 0**。
- **KPI-010**：不存在仅凭单次价格路径或单次运行得出的结论。
- **KPI-011**：报告显式声明零和恒等式（§13.4），不把恒等式结果当作发现。

### 11.4 第三层：呈现

- **KPI-012**：回放器仅以事件日志为输入还原整段仿真，与原运行逐帧一致。

## 12. 市场验证框架（第一层门槛）

基准市场至少检查以下特征，MVP 不要求全部通过，但必须透明报告：

- 收益分布厚尾；
- 收益序列无显著线性自相关；
- 绝对收益自相关为正（波动聚集）；
- 价格冲击随订单规模非线性增长；
- 点差与深度在合理范围且随波动变化；
- **杠杆情形下的强平连锁规模分布**——强平触发率、连锁深度分布、强平成交量占比。

**报告分两部分**（退化状态 §4.0）：经济终点（崩盘、穿仓、连锁清空）的发生概率与
严重度，以及条件于未发生终点的连续指标。只报后者等于只统计幸存者，会系统性低估
尾部风险。

**数值门槛与统计判定规则尚未冻结**，须在 M2 的预注册协议中确定（§17.2）——包括每项
特征的检验统计量、通过区间、置信水平、多重比较处理、最低有效样本量与功效依据。
在协议冻结前，本节只是特征清单，不构成可执行的验收。

**「够用即止」原则**：第一层达标即进入第二层，不追求所有特征完美吻合。追求完美会
把项目锁死在无止境的调参上，而信念检验只需要市场「足够像」。达标门槛以 KPI-005 的
声明形式固定，不得在看过第二层结果后回头放宽。

## 13. 结论纪律

本章是本产品的核心约束，违反它会使全部实验失去意义。

### 13.1 不得预设「庄家」

若把大资金代理的规则写成「先拉高诱多、再派发」，然后观察到散户亏损，这不是发现，
而是把自己写的规则用价格曲线重述一遍。**不对称收益必须作为结果涌现，不得作为规则
写入。** 大资金的优势只能通过 §7.2 的能力维度表达。

### 13.2 不得外推至真实市场

模型可以证明某机制**足以**产生某种现象（例如「无需操纵，杠杆连锁即可造成暴跌」），
但**不能**证明真实市场中的某次暴跌就是这么发生的。统计特征等价不等于机制等价：
两个模型可能在 §12 全部指标上都通过，产生机制却完全不同。

结论中必须写明这一限制。任何把仿真结论用于真实交易决策的做法都超出产品能力范围。

### 13.3 单次运行内不允许策略适应

若代理在实验过程中自我优化，那么改变某个能力维度时，代理策略会同时改变，测到的
效应是「该维度 + 策略适应」的混合，KPI-008 的单维度归因随即失效。策略适应作为独立
研究方向留待后续阶段，且须使用群体层面（跨运行）而非个体层面（运行内）的适应机制。

### 13.4 零和恒等式不是发现

在无外部资金流入的封闭市场中，扣除手续费后所有代理的 PnL 之和**恒为负**，恰等于
交易所收取的总费用。因此「散户整体亏钱」是会计恒等式，不是研究结果。

有内容的问题只能是**分布与机制**：谁亏、亏多少、通过 PR-016 的哪个渠道转移。报告
必须显式声明该恒等式，避免把它误读为结论。

### 13.5 问题的提法必须可证伪

写下研究问题后先问：**什么样的结果会否定它？** 答不出来，说明答案已藏在代理规则里，
必须重新提法。正反例见 [`methodology.md`](methodology.md) §11.1。

## 14. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 循环论证：结论已写进代理规则 | §13.1、§13.5；信念作为变量而非前提（§7.1） |
| 把仿真结论当交易信号 | §6 硬边界、§13.2；报告模板强制声明限制 |
| 因子库的选择偏差 | 因子构成作为先验显式声明并做敏感性检验 |
| 因子高度共线（MACD 与动量本质同族） | 因子库须覆盖不同**信息源**，并报告因子相关矩阵 |
| 第一层无止境调参 | §12「够用即止」，门槛预先固定 |
| 杠杆使账户模型复杂度失控 | 002 / D-2 限定为单一全仓保证金，不做组合保证金；永续模型免除了债务与借贷分录 |
| 强平连锁被误当作「操控证据」 | §13.1、§13.4；报告须同时给出无杠杆对照组 |
| 人在环数据污染研究结论 | 交互运行与研究运行分离，日志头部标记，前者不进统计 |

## 15. 交付路线图

路线由**旗舰问题**（§3.1）驱动，而非由能力清单驱动。每个阶段都要求端到端可验收，
不允许「先把功能做全再说」。

### M1：最小确定性内核（**无杠杆**）
→ [`specs/002-.../milestones/M1-minimal-kernel.md`](../../specs/002-belief-testing-laboratory/milestones/M1-minimal-kernel.md)

订单簿、账户、事件调度与日志、确定性哈希、因果链。**账户结构须一次留好保证金字段**，
但本阶段不开启杠杆。

**退出条件**：仓位恒等式 C1 与价值守恒 C2（指标字典 §5）逐事件整数精确成立；
[验收向量](../contracts/acceptance-vectors.md)的十个案例全部通过——**含三代理跨价
换手**，只用一对多空会误证已推翻的旧等式；KPI-001—KPI-004、KPI-006 达标。

先做无杠杆不等于「后期叠加」——接口一次设计对，实现分两步，能在最简状态下先把守恒
和确定性钉死。带着杠杆调试账本会让两类缺陷混在一起。

### M2：杠杆与第一个实验闭环
→ [`M2-leverage-and-first-experiment.md`](../../specs/002-belief-testing-laboratory/milestones/M2-leverage-and-first-experiment.md)

杠杆、保证金、强平、穿仓、连锁；最小代理策略合同；**无杠杆 vs 有杠杆的配对对照**。

**退出条件**：一项**预注册**实验能从配置、运行、原始证据一路追溯到条件性结论；
经济终点与连续指标两部分报告齐备；KPI-005、KPI-007、KPI-010、KPI-011 达标。

### M3：模型稳健性
→ [`M3-robustness.md`](../../specs/002-belief-testing-laboratory/milestones/M3-robustness.md)

替代代理规则、参数空间与模型族扫描、因子消融、共同随机输入、留出验证区。

**退出条件**：旗舰结论不依赖单一行为映射或单一狭窄参数点。

### M4：平台扩展（按证据决定）

股票式制度与 T+2 / 熔断 / 收盘、订单流预知者、大资金执行者、能力维度归因、
经济含义的 PnL 归因、多品种。**每项都须先说明它服务于哪个新的可证伪问题。**

### M5：交互产品

回放增强、人在环、教学模板。交互运行始终与研究样本隔离（002 / D-7）。
