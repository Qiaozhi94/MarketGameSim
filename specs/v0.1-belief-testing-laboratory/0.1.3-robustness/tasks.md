# 0.1.3：模型稳健性 · 任务拆解

**对应里程碑**：[`spec.md`](spec.md)  
**状态**：Ready（0.1.2 退出证据已达成；T001 仍需自动复核准入证据后才展开后续任务）

## 约定

- 0.1.3 检验结论对模型选择的敏感性，不以“找出显著结果”为目标；
- 所有扫描、消融、替代映射和留出复核方案必须在读取对应结果前冻结；
- 带 `[TDD]` 的任务先写失败测试；同一 Phase 内可并行项标 `[P]`；
- 负结果、方向反转和仅在狭窄区域成立都属于有效产出，不得触发事后改假设。

## Phase 2：参数空间扫描与失效边界

- [ ] **T201** `[A-005]` `[TDD]` 定义类型化扫描轴：杠杆上限分布、`maint_bp`、
      做市商厚度；校验概率和为 10000、`maint_bp < target_bp <= initial_bp` 及报价数量边界。
- [ ] **T202** `[FR-014]` `[TDD]` 实现确定性参数网格展开：规范化参数 JSON；
      `cell_id = H(规范化参数单元，含处理/映射字段；不含 seed、replicate_id)`
      标识“这是哪一个参数单元”，用于参数聚合去重；`run_id = H(cell_id + seed +
      replicate_id)` 标识“这是哪一次具体运行”，用于按 `run_id` 恢复执行、去重和
      产物路径——运行产物以 `run_id` 唯一，参数单元聚合以 `cell_id` 唯一；稳定
      遍历顺序，并行度不得改变输出顺序或摘要。`cell_id`/`run_id` 均**不用于**跨
      处理臂配对——配对连接键见 T402 的 `pair_id`/`arm_id`（二者概念不同：`cell_id`
      含处理字段取值本身，配对连接键必须处理字段无关，否则两个不同处理臂的运行
      永远算不出同一个 `cell_id`，无法配对）。
- [ ] **T203** `[方法论 §9.4]` 预注册粗扫与细扫规则，包括细化触发阈值、最大层数和
      总预算；细扫区域由冻结规则自动产生，不允许人工查看结果后挑选。
- [ ] **T204** `[指标字典 §6]` `[退化 §4]` `[TDD]` 每个参数单元输出锁定、发散、
      周期振荡、经济终点、技术无效与正常完成的互斥分类，并保留原始证据索引。
- [ ] **T205** `[0.1.3 E2]` 定位效应失效边界：输出首次越过预注册阈值的参数区间与
      分辨率，不把离散网格点插值成未经验证的精确临界值。
- [ ] **T206** `[方法论 §10.1]` 市场充分性门槛对每个 T006 预注册模型族分别执行；
      未通过第一层门槛的参数单元不得进入信念结论，只能进入失败/边界报告。
- [ ] **T207** `[0.1.3 E2]` 参数扫描与失效边界定位（T201—T205）对 T105 交叉矩阵的
      每个 `model_family_id × behavior_mapping_id` 单元独立执行；未通过 T206 市场
      充分性门槛的单元只进入失败/边界报告，不得进入跨单元的信念结论。若某个交叉
      单元不具可比语义（如某映射不适用于某模型族的结构），必须在预注册中声明原因
      并把 E1 降级为对应条件性结论，不得静默缺格、也不得用其余单元的结果替补。

## Phase 4：共同随机输入与单维度归因

- [ ] **T401** `[KR-004]` `[TDD]` 实现随机路径审计器：比较配对运行中每个共同
      语义键的随机值；区分“相同 master seed”和“共同随机冲击路径完整一致”。
- [ ] **T402** `[方法论 §9.2]` `[TDD]` 配对聚合器改按 `pair_id` 连接（不再是
      `cell_id + seed`）：
      - `pair_id = H(pair_family + 固定协变量 + seed + replicate_id)`——不含处理
        字段取值，同一处理家族下天然把两条处理臂映到同一个 `pair_id`；
      - `arm_id = H(pair_family + 处理字段差分)`——标识这条记录是对照臂还是处理臂；
      - 每个逻辑配对的唯一键是 `(pair_id, arm_id)`。
      必须 fail-closed 处理以下情形，不得静默丢弃或静默配对：同一 `(pair_id, arm_id)`
      重复出现（判为运行器故障，拒绝聚合）、`arm_id` 不在预注册处理家族集合内（拒绝）、
      配对中一侧技术无效另一侧有效（记为单侧缺失，不得当有效配对使用）、配对中一侧
      触发经济终点另一侧未触发（按 T602 两部分口径分别报告，不得合并成一个连续指标）、
      `pair_id` 只出现一侧的臂（记为缺失配对，进入 T606 的负结果报告，不得从分母静默
      剔除）。
- [ ] **T403** `[方法论 §10.5]` `[TDD]` 配置差分验证器证明每一对预注册对照只改变
      目标处理：同一模型族内的行为映射对照（T105）只允许映射 ID/版本及其预注册参数
      变化；同一行为映射下的模型族对照把 `model_family_id` 视为 T006 定义的复合处理，
      实际配置差分必须非空且只能落在 T006 为该模型族声明的 family-defining 字段集合
      内，所有共享字段逐字节一致——出现集合外额外字段时 fail-closed，仅修改
      `model_family_id/version` 而没有任何 family-defining 结构变化时也 fail-closed；
      参数扫描单元（T202）与消融处理（T303）仍只改变预注册的单一维度。回归测试至少
      覆盖“合法模型族结构差分通过”“额外字段漂移拒绝”“只改模型族 ID 不改结构拒绝”
      三类正反路径。不涉及资金/信息/速度/执行能力四个维度——0.1.3 不研究能力归因
      （见 E5）；其他多维联动变化只能标为探索性组合处理。
- [ ] **T404** `[KPI-008 空集校验]` `[TDD]` 0.1.3 未安排产出资金/信息/速度/执行能力
      归因所需的证据（处理字段差分、共同随机路径审计、配对样本数、效应量、置信
      区间），因此报告中该类归因集合必须为空。新增报告生成器测试：喂入一条缺少上述
      任一证据项的能力归因文本时必须拒绝生成（fail-closed），不得空集默认通过而在
      未来被静默绕过。
- [ ] **T405** `[KPI-010]` 报告生成器拒绝单次运行、单条价格路径或未满足最低配对
      样本量的结论性措辞，但允许以“探索性观察”单独列出。
