# 0.1.3：模型稳健性 · 任务拆解

**对应里程碑**：[`spec.md`](spec.md)  
**状态**：Ready after 0.1.2（仅当 0.1.2 全部退出条件通过后开始实现）

## 约定

- 0.1.3 检验结论对模型选择的敏感性，不以“找出显著结果”为目标；
- 所有扫描、消融、替代映射和留出复核方案必须在读取对应结果前冻结；
- 带 `[TDD]` 的任务先写失败测试；同一 Phase 内可并行项标 `[P]`；
- 负结果、方向反转和仅在狭窄区域成立都属于有效产出，不得触发事后改假设。

- [ ] **T002** `[方法论 §9.4/§10.3]` 冻结 0.1.2 基线：代码 commit、协议、配置、种子、
      行为映射和指标定义。后续变更必须产生新基线 ID，不得覆盖 0.1.2 结果。
- [ ] **T003** `[0.1.3 §2]` 编写稳健性预注册：至少一种替代行为映射、三类扫描维度、
      五因子消融、共同随机路径规则、留出验证区、主要效应量、区间估计和失败边界定义。
- [ ] **T004** `[方法论 §10.3]` 为校准区、探索扫描区、冻结验证区和最终报告区建立

- [ ] **T005** `[KPI-010]` 冻结最小种子数与停止规则；不得因中期效应不显著而增加

## Phase 1：可替换的行为映射

- [ ] **T101** `[计划 §2]` `[代理策略 §12]` 抽取 `BehaviorMapping` 接口：只消费
      已量化信号、风险权益和能力配置，输出目标仓位/订单意图；不得反向依赖订单簿内部
      或改变 L1 领域语义。
- [ ] **T102** `[0.1.3 §2]` `[TDD]` 保留 0.1.2 线性映射作为 `linear` 基线，并实现至少
      一种预注册替代映射（首选阈值型仓位映射）；阈值、滞回和边界舍入必须配置化且
      确定。
- [ ] **T103** `[代理策略 §7/§11]` `[TDD]` 所有映射共享同一订单对齐、
      `max_order_qty`、保证金准入、自成交阻止和全撤重报路径，避免把执行差异误算成
      行为差异。
- [ ] **T104** `[KR-004]` `[TDD]` 映射切换不得改变相同语义机制的随机输入；记录
      `behavior_mapping_id/version`，并验证其余处理配置逐字节一致。
- [ ] **T105** `[0.1.3 E1]` 建立行为映射对照矩阵：相同参数点和种子下运行基线与替代
      映射，预先声明“同向成立”“方向反转”“仅单一映射成立”的判定规则。

## Phase 2：参数空间扫描与失效边界

- [ ] **T201** `[A-005]` `[TDD]` 定义类型化扫描轴：杠杆上限分布、`maint_bp`、
      做市商厚度；校验概率和为 10000、`maint_bp < target_bp <= initial_bp` 及报价数量边界。
- [ ] **T202** `[FR-014]` `[TDD]` 实现确定性参数网格展开：规范化参数 JSON、稳定
      `cell_id`、稳定遍历顺序、按 cell/seed 可恢复执行；并行度不得改变输出顺序或摘要。
- [ ] **T203** `[方法论 §9.4]` 预注册粗扫与细扫规则，包括细化触发阈值、最大层数和
      总预算；细扫区域由冻结规则自动产生，不允许人工查看结果后挑选。
- [ ] **T204** `[指标字典 §6]` `[退化 §4]` `[TDD]` 每个参数单元输出锁定、发散、
      周期振荡、经济终点、技术无效与正常完成的互斥分类，并保留原始证据索引。
- [ ] **T205** `[0.1.3 E2]` 定位效应失效边界：输出首次越过预注册阈值的参数区间与
      分辨率，不把离散网格点插值成未经验证的精确临界值。
- [ ] **T206** `[方法论 §10.1]` 市场充分性门槛对每个模型族分别执行；未通过第一层
      门槛的参数单元不得进入信念结论，只能进入失败/边界报告。

## Phase 3：五因子消融与必要成分

- [ ] **T301** `[FR-010]` `[TDD]` 为 momentum、reversion、herding、book、noise
      建立独立启用开关；关闭一个因子时只将该因子从权重向量移除并按预注册规则重归一，
      其余配置和随机机制不变。
- [ ] **T302** `[KR-004]` `[TDD]` 消融不得造成其他因子随机流错位：未移除因子的
      `(mechanism,decision_index,draw_index)` 值须与基线逐位相同。
- [ ] **T303** `[方法论 §9.3]` `[P]` 每个基线参数单元运行五个 leave-one-out 处理，
      使用共同种子并输出配对差异；不得只挑选看似重要的因子。
- [ ] **T304** `[v0.1 / P-1]` `[P]` 输出因子相关矩阵及持续 `|ρ|>0.8` 告警；解释消融
      结果时必须披露高度相关因子，避免把可替代成分误称为必要成分。
- [ ] **T305** `[0.1.3 E3]` 按预注册标准把因子标为必要、非必要、可替代或证据不足；
      “移除后不显著”本身不得作为必要性的唯一判据，必须报告效应量与区间。

## Phase 4：共同随机输入与单维度归因

- [ ] **T401** `[KR-004]` `[TDD]` 实现随机路径审计器：比较配对运行中每个共同
      语义键的随机值；区分“相同 master seed”和“共同随机冲击路径完整一致”。
- [ ] **T402** `[方法论 §9.2]` `[TDD]` 配对聚合器按 `cell_id + seed` 一一连接；
      明确处理技术无效、经济终点和单侧缺失，不得静默删除不完整配对。
- [ ] **T403** `[方法论 §10.5]` `[TDD]` 配置差分验证器证明每个能力归因对照只改变
      资金、信息、速度或执行能力中的一个维度；多维变化只能标为探索性组合处理。
- [ ] **T404** `[KPI-008]` 对报告中每条能力归因建立证据索引：处理字段差分、共同
      随机路径审计、配对样本数、效应量和置信区间缺一不可。
- [ ] **T405** `[KPI-010]` 报告生成器拒绝单次运行、单条价格路径或未满足最低配对
      样本量的结论性措辞，但允许以“探索性观察”单独列出。

## Phase 5：冻结留出验证

- [ ] **T501** `[方法论 §10.3]` 在查看探索扫描结果前生成并封存留出区 manifest；
      记录参数点、种子、协议和摘要，执行账户不得修改该文件。
- [ ] **T502** `[TDD]` 数据污染检查：留出 cell/seed 不得出现在校准、模型选择、
      阈值选择或细扫输入中；发现交集即判定本轮验证作废。
- [ ] **T503** `[0.1.3 E4]` 使用冻结代码和分析计划一次性运行留出区；失败重跑只能针对
      技术故障，并必须保留失败尝试、原因与新 run ID，不得覆盖原记录。
- [ ] **T504** 比较探索区与留出区的方向、效应量和覆盖区间；预先定义的复核判据
      不通过时如实报告，不回到探索区修改假设后重复使用同一留出区。

## Phase 6：稳健性统计与报告

- [ ] **T601** `[0.1.3 E1/E2]` `[P]` 输出每种行为映射、参数单元和处理的效应量与
      置信区间，并给出跨参数趋势；图表数据必须能追溯到 run manifest 和原始日志摘要。
- [ ] **T602** `[退化 §4.2]` `[P]` 所有稳健性报告保持两部分结构：经济终点发生率/
      严重度，以及条件于未发生终点的连续指标；同时报告技术无效率和有效样本量。
- [ ] **T603** `[KPI-009]` `[TDD]` 对扫描、消融和替代映射的每个有效运行复核五项
      PnL 桥接残差为 0；任何单个代理残差非零都使该运行无资格进入统计报告。
- [ ] **T604** `[KPI-007]` 生成最终条件性结论：明确参与者结构、参数区间、行为映射、
      种子数、效应量、区间估计和失效边界；真实市场外推仍禁止。
- [ ] **T605** `[KPI-011]` 显式声明封闭市场零和恒等式，把“谁亏”拆到分布和五个
      PnL 渠道；不得把总 PnL 等于负费用当作研究发现。
- [ ] **T606** `[0.1.3 §4]` 把三类负面结果作为一等产物：极窄参数区、替代映射下消失、
      无杠杆同样崩盘。正文、摘要和机器可读结论必须一致，不得只放入附录。
- [ ] **T607** `[0.1.3 E1—E5]` 生成稳健性证据矩阵，逐项链接行为映射、参数边界、消融、
      留出复核、KPI-008 和 KPI-009 的机器可读产物。
