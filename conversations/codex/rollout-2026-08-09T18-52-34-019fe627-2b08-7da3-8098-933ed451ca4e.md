## 3. 把 Feature 生命周期完全机器化

`spec.md` frontmatter 是唯一状态真源：

```yaml
---
feature: F009
version: "0.3"
status: draft
gate_version: 1
updated: 2026-08-09
---
```

状态统一为：

```text
draft
→ ready-for-development
→ in-progress
→ review
→ done
```

机器门至少验证：

- 三件套齐全，ID、version、目录一致；
- design 未关闭问题会阻断 ready；
- tasks/AC 未完成会阻断 done；
- AC 必须引用真实 FR 和测试文件；
- BACKLOG 只包含且包含全部非 done Feature；
- release 只能收口全部 done 的版本。

BACKLOG 最好由 frontmatter生成；如果继续手工维护，就必须双向集合校验。
